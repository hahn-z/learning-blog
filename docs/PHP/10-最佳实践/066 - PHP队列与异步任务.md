# PHP队列与异步任务

邮件发送、报表生成、图片处理——耗时操作不应该阻塞用户请求。队列是PHP处理异步任务的标准方案。

## 队列选型

| 队列 | 吞吐量 | 持久化 | 复杂度 | 适用场景 |
|------|--------|--------|--------|----------|
| Redis | 10万+/s | 可配 | 低 | 大部分PHP项目 |
| RabbitMQ | 万级 | 是 | 中 | 需要路由/确认机制 |
| Kafka | 百万级 | 是 | 高 | 日志/事件流 |
| Database | 百级 | 是 | 极低 | 小项目原型 |

**PHP项目推荐**：先用Redis（简单高效），需要消息确认和复杂路由时换RabbitMQ。

## Job设计模式

### 基础Job类

```php
<?php
interface JobHandlerInterface
{
    public function handle(string $payload): void;
}

class Job
{
    public function __construct(
        public readonly string $handler,    // 处理器类名
        public readonly string $payload,    // JSON序列化的数据
        public readonly int $attempts = 0,
        public readonly int $maxAttempts = 3,
        public readonly ?int $delayUntil = null,
        public readonly ?string $queue = 'default',
    ) {}

    public function toArray(): array
    {
        return [
            'handler' => $this->handler,
            'payload' => $this->payload,
            'attempts' => $this->attempts,
            'max_attempts' => $this->maxAttempts,
            'delay_until' => $this->delayUntil,
            'queue' => $this->queue,
        ];
    }

    public static function fromArray(array $data): self
    {
        return new self(
            handler: $data['handler'],
            payload: $data['payload'],
            attempts: $data['attempts'] ?? 0,
            maxAttempts: $data['max_attempts'] ?? 3,
            delayUntil: $data['delay_until'] ?? null,
            queue: $data['queue'] ?? 'default',
        );
    }
}
```

### Redis队列实现

```php
<?php
class RedisQueue
{
    public function __construct(
        private Redis $redis,
        private string $prefix = 'queue:',
    ) {}

    // 推送任务
    public function push(Job $job, int $delay = 0): void
    {
        $data = json_encode($job->toArray());
        $queueKey = $this->prefix . $job->queue;

        if ($delay > 0) {
            // 延迟队列：用sorted set，score为执行时间戳
            $this->redis->zAdd(
                $queueKey . ':delayed',
                time() + $delay,
                $data
            );
        } else {
            // 即时队列：用list的LPUSH
            $this->redis->lPush($queueKey, $data);
        }
    }

    // 拉取任务
    public function pop(string $queue = 'default', int $timeout = 30): ?Job
    {
        // 1. 先将到期的延迟任务转移到即时队列
        $this->migrateDelayedJobs($queue);

        $queueKey = $this->prefix . $queue;

        // 2. 非阻塞弹出（BRPOP阻塞等待）
        $result = $this->redis->brPop([$queueKey], $timeout);
        
        if ($result === false || $result === []) {
            return null;
        }

        $data = json_decode($result[1], true);

        // 3. 放入"处理中"集合（防止worker崩溃丢任务）
        $job = Job::fromArray($data);
        $this->redis->hSet(
            $queueKey . ':reserved',
            md5($result[1]),
            json_encode(array_merge($data, ['reserved_at' => time()]))
        );

        return $job;
    }

    // 任务完成，从reserved中移除
    public function ack(Job $job): void
    {
        $queueKey = $this->prefix . $job->queue;
        $this->redis->hDel($queueKey . ':reserved', md5($job->payload));
    }

    // 任务失败，重新入队或进入死信队列
    public function fail(Job $job, \Throwable $e): void
    {
        $queueKey = $this->prefix . $job->queue;
        $this->redis->hDel($queueKey . ':reserved', md5($job->payload));

        if ($job->attempts < $job->maxAttempts) {
            // 重试：指数退避延迟
            $delay = (int)pow(2, $job->attempts) * 60; // 1min, 2min, 4min...
            $retryJob = new Job(
                handler: $job->handler,
                payload: $job->payload,
                attempts: $job->attempts + 1,
                maxAttempts: $job->maxAttempts,
                delayUntil: time() + $delay,
                queue: $job->queue,
            );
            $this->push($retryJob, $delay);
        } else {
            // 超过最大重试次数 → 死信队列
            $this->redis->lPush($queueKey . ':failed', json_encode([
                'job' => $job->toArray(),
                'error' => $e->getMessage(),
                'failed_at' => time(),
            ]));
        }
    }

    private function migrateDelayedJobs(string $queue): void
    {
        $now = time();
        $delayedKey = $this->prefix . $queue . ':delayed';
        $queueKey = $this->prefix . $queue;

        // 取出到期的延迟任务
        $jobs = $this->redis->zRangeByScore($delayedKey, 0, $now);
        foreach ($jobs as $jobData) {
            $this->redis->lPush($queueKey, $jobData);
            $this->redis->zRem($delayedKey, $jobData);
        }
    }
}
```

### 使用示例

```php
<?php
// 推送任务
class SendWelcomeEmail implements JobHandlerInterface
{
    public function __construct(
        private Mailer $mailer,
    ) {}

    public function handle(string $payload): void
    {
        $data = json_decode($payload, true);
        $this->mailer->send(
            to: $data['email'],
            subject: '欢迎注册',
            body: "你好 {$data['name']}，欢迎加入！"
        );
    }
}

// 在Controller中分发
class UserController
{
    public function register(RedisQueue $queue): void
    {
        // ... 创建用户 ...

            handler: SendWelcomeEmail::class,

            queue: 'emails',

    }
}
```

## 重试策略：指数退避

```php
<?php
// 指数退避 + 抖动
function calculateBackoff(int $attempt, int $baseDelay = 60, int $maxDelay = 3600): int
{
    // 基础延迟 * 2^attempt + 随机抖动
    $delay = $baseDelay * pow(2, $attempt);
    $jitter = random_int(0, (int)($delay * 0.1)); // ±10%抖动
    
    return min($delay + $jitter, $maxDelay);
}

// 重试间隔: 60s → 120s → 240s → 480s → 960s
```

## 幂等性保证

```php
<?php
// 幂等性：同一任务执行多次结果一致

// 方案1: 唯一Job ID + Redis去重
class IdempotentJobDispatcher
{
    public function dispatch(Job $job): void
    {
        $jobId = md5($job->handler . $job->payload);
        
        // SET NX：只在key不存在时设置
        $lockKey = "job_lock:{$jobId}";
        $locked = $this->redis->set($lockKey, '1', ['NX', 'EX' => 3600]);
        
        if (!$locked) {
            return; // 任务已在队列中或正在执行
        }
        
        $this->queue->push($job);
    }
}

// 方案2: 业务层幂等
class ProcessPaymentHandler implements JobHandlerInterface
{
    public function handle(string $payload): void
    {
        $data = json_decode($payload, true);
        
        // 检查是否已处理
        $payment = $this->paymentRepo->findByTransactionId($data['txn_id']);
        if ($payment && $payment->status === 'completed') {
            return; // 已处理，跳过
        }
        
        // 处理支付...
    }
}
```

## Supervisor管理Worker

```ini

[program:queue-worker-default]
process_name=%(program_name)s_%(process_num)02d
```

## 面试常见追问

**Q: Redis队列丢消息怎么办？**
A: 1) 开启Redis AOF持久化（appendonly yes）；2) reserved集合防止worker崩溃丢任务；3) 关键任务用RabbitMQ（消息确认机制更强）。Redis队列适合"允许少量丢失"的场景。

**Q: 如何保证消息顺序？**
A: 单队列单worker可以保证顺序，但吞吐量低。多worker场景下严格顺序很难保证。方案：相关消息路由到同一队列+单consumer（如同一用户的操作串行处理）。

**Q: Worker进程怎么优雅退出？**
A: 捕获SIGTERM信号，停止拉取新任务，等待当前任务完成后再退出。Supervisor的`stopwaitsecs`设置了最大等待时间。Laravel的`queue:work`内置了这个逻辑。

**Q: 队列堆积怎么处理？**
A: 1) 临时增加worker数量（Supervisor的numprocs）；2) 优化任务处理速度（批量处理、减少IO）；3) 高优先级队列单独处理；4) 设置告警（队列长度超过阈值触发通知）。
