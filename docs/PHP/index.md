# PHP

从基础语法到底层原理，系统整理 PHP 核心知识点。

## 目录结构

| 分类 | 说明 |
|------|------|
| 基础语法 | 类型系统、变量、运算符、控制流 |
| 函数与数组 | 函数特性、数组操作、回调与闭包 |
| OOP 面向对象 | 类、继承、接口、Trait、魔术方法 |
| 错误与异常 | 错误级别、异常链、自定义异常 |
| 文件与流 | 文件操作、流包装器、上传处理 |
| 数据库 | PDO、预处理、事务、连接池 |
| Web 与安全 | HTTP、Session、XSS/CSRF/SQL注入 |
| 性能与底层 | OPCache、内存管理、GC、FPM |
| Composer 与生态 | 包管理、自动加载、PSR 规范 |
| 最佳实践 | 编码规范、设计模式、测试 |
