# PHP文件操作完全指南

## 文件读写基础

### fopen/fread/fwrite/fclose

`fopen`是最底层的文件操作API，支持多种模式：

| 模式 | 说明 | 文件存在时 | 文件不存在时 |
|------|------|-----------|-------------|
| `r` | 只读 | 从头读 | 报错 |
| `r+` | 读写 | 从头读写 | 报错 |
| `w` | 只写 | 清空 | 创建 |
| `w+` | 读写 | 清空 | 创建 |
| `a` | 追加写 | 末尾追加 | 创建 |
| `a+` | 追加读写 | 末尾追加 | 创建 |
| `x` | 独占写 | 报错 | 创建 |
| `x+` | 独占读写 | 报错 | 创建 |

```php
<?php
// 写文件
$handle = fopen('/tmp/test.txt', 'w');
if ($handle === false) {
    throw new RuntimeException('无法打开文件');
}
try {
    fwrite($handle, "第一行\n");
    fwrite($handle, "第二行\n");
    fwrite($handle, "第三行\n");
} finally {
    fclose($handle);
}

// 读文件（逐行）
$handle = fopen('/tmp/test.txt', 'r');
try {
    while (($line = fgets($handle)) !== false) {
        echo "读入: " . trim($line);
    }
} finally {
    fclose($handle);
}

// 二进制安全读写
$handle = fopen('/tmp/image.png', 'rb'); // 注意b标记（Windows必须，Linux可选但推荐）
$size = filesize('/tmp/image.png');
$data = fread($handle, $size);
fclose($handle);

// 随机访问
$handle = fopen('/tmp/data.bin', 'r+b');
fseek($handle, 1024);       // 跳到1024字节处
fwrite($handle, pack('N', 42)); // 写入4字节大端整数
fseek($handle, 0, SEEK_END);   // 跳到末尾
$fileSize = ftell($handle);    // 获取文件大小
fclose($handle);
```

### file_get_contents/file_put_contents

简化版API，适合小文件：

```php
<?php
// 读取整个文件为字符串
$content = file_get_contents('/tmp/test.txt');

// 读取远程URL（通过HTTP）
$html = file_get_contents('https://example.com/api/data');

// 带超时的URL读取
$context = stream_context_create([
    'http' => [
        'timeout' => 5,
        'method' => 'GET',
        'header' => "Accept: application/json\r\n",
    ],
]);
$response = file_get_contents('https://api.example.com/data', false, $context);

// 写入文件
file_put_contents('/tmp/output.txt', 'Hello World');

// FILE_APPEND: 追加模式
file_put_contents('/tmp/log.txt', date('c') . " - 新日志\n", FILE_APPEND);

// LOCK_EX: 排他锁（防止并发写入冲突）
file_put_contents('/tmp/counter.txt', $count, LOCK_EX);

// 一次性读取为数组（每行一个元素）
$lines = file('/tmp/test.txt', FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES);
```

### 读取文件的高效方式对比

```php
<?php
// 1. file_get_contents：最简单，但大文件会撑爆内存
$content = file_get_contents('/var/log/large.log'); // ⚠️ 1GB文件=1GB内存

// 2. fopen+fgets：逐行读取，内存占用恒定
$handle = fopen('/var/log/large.log', 'r');
while (($line = fgets($handle)) !== false) {
    if (str_contains($line, 'ERROR')) {
        echo $line;
    }
}
fclose($handle);

// 3. file+array_filter：简洁但一次性加载
$errors = array_filter(
    file('/var/log/large.log'),
    fn($line) => str_contains($line, 'ERROR')
);

// 4. SplFileObject：面向对象方式（推荐）
$file = new SplFileObject('/var/log/large.log');
foreach ($file as $line) {
    if (str_contains($line, 'ERROR')) {
        echo $line;
    }
}
```

## 目录操作

```php
<?php
// 创建目录（递归创建）
mkdir('/tmp/a/b/c', 0755, true); // true表示递归创建父目录

// 检查
is_dir('/tmp/a');            // 是否是目录
is_file('/tmp/a/b.txt');     // 是否是文件
file_exists('/tmp/a');       // 是否存在（文件或目录）

// 遍历目录
// 方式1: scandir（返回数组）
$entries = scandir('/tmp');
$entries = array_diff($entries, ['.', '..']); // 过滤掉 . 和 ..

// 方式2: opendir/readdir（流式，适合大目录）
$dir = opendir('/tmp');
while (($entry = readdir($dir)) !== false) {
    if ($entry === '.' || $entry === '..') continue;
    echo $entry . "\n";
}
closedir($dir);

// 方式3: RecursiveDirectoryIterator（递归遍历子目录）
$iterator = new RecursiveIteratorIterator(
    new RecursiveDirectoryIterator('/tmp/a', FilesystemIterator::SKIP_DOTS),
    RecursiveIteratorIterator::SELF_FIRST
);
foreach ($iterator as $file) {
    echo $file->getPathname() . ($file->isDir() ? '/' : '') . "\n";
}

// 删除目录（递归）
function removeDir(string $dir): bool
{
    if (!is_dir($dir)) return false;
    $entries = scandir($dir);
    foreach ($entries as $entry) {
        if ($entry === '.' || $entry === '..') continue;
        $path = $dir . '/' . $entry;
        is_dir($path) ? removeDir($path) : unlink($path);
    }
    return rmdir($dir);
}
```

## 文件权限

```php
<?php
// 修改权限
chmod('/tmp/file.txt', 0644); // 所有者读写，组和其他只读
chmod('/tmp/script.sh', 0755); // 所有者全部权限，组和其他读+执行
chmod('/tmp/secret.key', 0600); // 仅所有者读写

// 修改所有者（需要root权限）
chown('/tmp/file.txt', 'www-data');
chgrp('/tmp/file.txt', 'www-data');

// 检查权限
is_readable('/tmp/file.txt');
is_writable('/tmp/file.txt');
is_executable('/tmp/script.sh');

// 获取文件信息
$stat = stat('/tmp/file.txt');
echo '大小: ' . $stat['size'] . ' bytes';
echo '修改时间: ' . date('Y-m-d H:i:s', $stat['mtime']);
echo '权限: ' . decoct($stat['mode'] & 0777);

// 磁盘信息
$free = disk_free_space('/');   // 剩余空间
$total = disk_total_space('/'); // 总空间
echo sprintf('磁盘使用率: %.1f%%', ($total - $free) / $total * 100);
```

### 常见权限问题排查

```php
<?php
// 检查文件/目录是否可写，包含详细诊断
function diagnosePermission(string $path): string
{
    $issues = [];

    if (!file_exists($path)) {
        return "路径不存在: {$path}";
    }

    $perms = fileperms($path);
    $owner = posix_getpwuid(fileowner($path));
    $group = posix_getgrgid(filegroup($path));
    $current = posix_getpwuid(posix_getuid());

    $issues[] = sprintf('权限: %s', substr(sprintf('%o', $perms), -4));
    $issues[] = sprintf('所有者: %s:%s', $owner['name'], $group['name']);
    $issues[] = sprintf('当前用户: %s', $current['name']);

    if (!is_writable($path)) {
        $issues[] = '⚠️ 不可写';
    }

    return implode("\n", $issues);
}

echo diagnosePermission('/var/www/html/uploads');
```

## 面试常见追问

**Q: fopen的x模式和w模式有什么区别？**
A: `w`模式会清空已存在的文件，`x`模式如果文件已存在会返回false并产生`E_WARNING`。`x`模式用于"排他性创建"——避免意外覆盖已有文件，常用于锁文件、临时文件的创建。

**Q: file_get_contents读取大文件时怎么控制内存？**
A: `file_get_contents`会将整个文件加载到内存。对于大文件，应该用`fopen`+`fread`分块读取，或者用`SplFileObject`逐行迭代。如果一定要用`file_get_contents`，可以通过`stream_filter`在读取时处理，但仍需注意内存。

**Q: 如何安全地写入文件避免并发问题？**
A: 三种方式：1) `file_put_contents`的`LOCK_EX`参数获取排他锁；2) `fopen`+`flock(LOCK_EX)`手动加锁；3) 先写入临时文件再`rename`（rename在Linux上是原子操作）。生产环境推荐第3种方式。
