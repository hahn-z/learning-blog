# PHP临时文件与内存映射

## tmpfile()与临时文件管理

```php
<?php
// tmpfile()：创建临时文件，关闭或脚本结束时自动删除
$temp = tmpfile();
fwrite($temp, "临时数据");
rewind($temp);
echo fread($temp, 1024); // "临时数据"
// 获取临时文件路径（某些场景需要）
$meta = stream_get_meta_data($temp);
echo $meta['uri']; // 如: /tmp/phpXxxxXX
fclose($temp); // 文件自动删除

// tempnam()：创建唯一命名的临时文件（需手动删除）
$tempPath = tempnam(sys_get_temp_dir(), 'myapp_');
// 如: /tmp/myapp_a1b2c3
file_put_contents($tempPath, '数据');
// ... 使用文件 ...
unlink($tempPath); // 手动清理

// php://temp：流式临时存储
$temp = fopen('php://temp/maxmemory:5242880', 'r+'); // 5MB内存阈值
fwrite($temp, str_repeat('x', 6 * 1024 * 1024)); // 超5MB后自动写入磁盘
rewind($temp);
echo ftell($temp); // 0
fclose($temp);
```

### 临时文件使用场景

```php
<?php
// 场景1：安全下载远程文件（不暴露路径）
function downloadToTemp(string $url): string
{
    $temp = tmpfile();
    $source = fopen($url, 'r');
    stream_copy_to_stream($source, $temp);
    fclose($source);

    $meta = stream_get_meta_data($temp);
    return $meta['uri']; // 返回路径给下游处理
}

// 场景2：原子写入（先写临时文件，再rename）
function atomicWrite(string $path, string $content): void
{
    $tempPath = tempnam(dirname($path), '.tmp_');
    file_put_contents($tempPath, $content);
    rename($tempPath, $path); // rename是原子操作（同文件系统）
}

// 场景3：多步骤处理中间结果
function processExport(PDO $pdo): string
{
    $step1 = tmpfile();
    // 步骤1：查询并写入临时文件
    $stmt = $pdo->query("SELECT * FROM large_table");
    while ($row = $stmt->fetch(PDO::FETCH_ASSOC)) {
        fputcsv($step1, $row);
    }

    // 步骤2：处理临时文件数据
    rewind($step1);
    $output = fopen('/tmp/result.csv', 'w');
    while (($line = fgetcsv($step1)) !== false) {
        // 转换处理...
        fputcsv($output, $line);
    }

    fclose($step1); // 自动清理
    fclose($output);
    return '/tmp/result.csv';
}
```

## SplFileObject面向对象接口

`SplFileObject`是PHP标准库中的文件操作类，提供了面向对象的文件读写接口：

```php
<?php
$file = new SplFileObject('/tmp/data.csv');

// 逐行迭代（最常用的功能）
foreach ($file as $lineNum => $line) {
    echo "行{$lineNum}: " . trim($line);
}

// CSV模式
$file->setFlags(SplFileObject::READ_CSV | SplFileObject::SKIP_EMPTY | SplFileObject::READ_AHEAD);
foreach ($file as $row) {
    // $row已经是数组
    var_dump($row);
}

// 随机访问
$file->seek(100); // 跳到第100行（注意：需要从头计数，大文件慢）
echo $file->current();

// 文件信息
echo $file->getFilename();     // 文件名
echo $file->getPathname();     // 完整路径
echo $file->getSize();         // 文件大小
echo $file->getMTime();        // 修改时间
echo $file->isFile();          // 是否是文件

// 写操作
$writer = new SplFileObject('/tmp/output.txt', 'w');
$writer->fwrite("写入一行\n");
$writer->fflush(); // 刷新缓冲
```

### SplFileObject vs fopen

```php

//SplFileObject的优势：

// 5. 内置CSV解析

    // $file是SplFileInfo对象

        $csv = $file->openFile('r');
        $csv->setFlags(SplFileObject::READ_CSV);
        foreach ($csv as $row) {
            // 处理每行
        }
    }
}
```

## 超大文件处理技巧

### 分块读取与流式处理

```php
<?php
// 技巧1：固定大小分块读取（适合二进制文件）
function readInChunks(string $path, int $chunkSize = 8192): Generator
{
    $fp = fopen($path, 'rb');
    while (!feof($fp)) {
        yield fread($fp, $chunkSize);
    }
    fclose($fp);
}

// 用Generator处理，内存占用恒定
foreach (readInChunks('/tmp/large_file.bin', 65536) as $chunk) {
    processChunk($chunk);
}

// 技巧2：逐行处理（适合文本/日志文件）
function readLines(string $path): Generator
{
    $fp = fopen($path, 'r');
    while (($line = fgets($fp)) !== false) {
        yield rtrim($line, "\n");
    }
    fclose($fp);
}

// 统计日志中ERROR出现次数（内存友好）
$errorCount = 0;
foreach (readLines('/var/log/app.log') as $line) {
    if (str_contains($line, 'ERROR')) {
        $errorCount++;
    }
}
echo "错误数: {$errorCount}\n";

// 技巧3：JSON流式解析（大JSON文件）
function readJsonLines(string $path): Generator
{
    $fp = fopen($path, 'r');
    while (($line = fgets($fp)) !== false) {
        $line = trim($line);
        if ($line === '' || $line === '[' || $line === ']' || $line === ',') {
            continue;
        }
        $line = rtrim($line, ',');
        yield json_decode($line, true, 512, JSON_THROW_ON_ERROR);
    }
    fclose($fp);
}

// 处理JSON Lines格式文件
foreach (readJsonLines('/tmp/users.jsonl') as $user) {
    $stmt->execute([$user['name'], $user['email']]);
}
```

### 文件指纹与校验

```php
<?php
// 大文件MD5/SHA1（不加载到内存）
function fileHash(string $path, string $algo = 'md5'): string
{
    $ctx = hash_init($algo);
    $fp = fopen($path, 'rb');
    while (!feof($fp)) {
        hash_update($ctx, fread($fp, 65536));
    }
    fclose($fp);
    return hash_final($ctx);
}

echo fileHash('/tmp/large.iso', 'sha256');

// 复制大文件并校验
function copyWithVerify(string $src, string $dst): bool
{
    $srcFp = fopen($src, 'rb');
    $dstFp = fopen($dst, 'wb');
    $bytes = stream_copy_to_stream($srcFp, $dstFp);
    fclose($srcFp);
    fclose($dstFp);

    return $bytes === filesize($src);
}
```

## 面试常见追问

**Q: tmpfile()和tempnam()怎么选？**
A: `tmpfile()`创建的文件在关闭时自动删除，适合不需要保留的中间数据。`tempnam()`创建的文件需要手动删除，适合需要传递文件路径给其他程序的场景（如调用外部命令处理文件）。优先用`tmpfile()`，避免忘记清理临时文件。

**Q: SplFileObject的seek()方法在大文件上性能如何？**
A: `seek(n)`需要从头逐行读取到第n行，时间复杂度O(n)。对于需要频繁随机访问的场景，应该建立索引（记录每行的偏移量）或者使用数据库。如果只需要顺序遍历，直接用foreach效率最高。

**Q: 如何处理超过内存限制的超大文件？**
A: 核心原则是"永远不要一次性加载"。使用`fopen`+`fread`分块读取、Generator逐行yield、`stream_copy_to_stream`流式复制。对于JSON/XML等结构化数据，考虑JSON Lines格式（每行一个JSON对象）或使用XML Pull Parser（XMLReader）流式解析。
