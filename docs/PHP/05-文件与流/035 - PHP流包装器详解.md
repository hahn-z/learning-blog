# PHP流包装器详解

## 什么是流包装器

PHP的流（Stream）是一套统一I/O操作的抽象层。**流包装器（Wrapper）**让不同类型的资源（文件、网络、内存、压缩包）使用相同的API操作：

```php
<?php
// 这些函数的用法完全相同，只是"协议"不同
file_get_contents('/path/to/file.txt');           // 本地文件
file_get_contents('https://example.com/api');     // HTTP请求
file_get_contents('php://input');                  // 请求体
file_get_contents('compress.zlib://file.gz');     // 压缩文件
file_get_contents('data://text/plain,Hello');     // 内联数据

// 查看系统注册的所有包装器
$wrappers = stream_get_wrappers();
// ['https', 'http', 'ftp', 'php', 'zlib', 'data', 'glob', 'phar', ...]
```

底层原理：当PHP遇到`fopen("scheme://...")`时，根据`scheme`找到对应的wrapper类，调用其`stream_open`方法。

## php://内置包装器

### php://input — 读取原始请求体

```php
<?php
// 获取POST原始数据（最常用场景：接收JSON请求体）
$rawInput = file_get_contents('php://input');
$data = json_decode($rawInput, true);

// 重要特性：
// 1. 可以多次读取（PHP 5.6+），之前版本只能读一次
// 2. 不受enctype影响（$_POST只支持form-data和x-www-form-urlencoded）
// 3. 不受post_max_size限制（但有memory_limit）

// 实战：API中间件中解析请求体
function getRequestBody(): array
{
    $contentType = $_SERVER['CONTENT_TYPE'] ?? '';

    if (str_contains($contentType, 'application/json')) {
        $raw = file_get_contents('php://input');
        return json_decode($raw, true, 512, JSON_THROW_ON_ERROR);
    }

    if (str_contains($contentType, 'multipart/form-data')) {
        return $_POST;
    }

    return [];
}
```

### php://output — 输出缓冲

```php
<?php
// php://output 等同于 echo/print，写入到输出缓冲区
$fp = fopen('php://output', 'w');
fwrite($fp, "直接输出到浏览器\n");
fclose($fp);

// 实用场景：流式输出大CSV文件（避免内存爆炸）
function exportCsv(PDO $pdo, string $sql): void
{
    header('Content-Type: text/csv');
    header('Content-Disposition: attachment; filename="export.csv"');

    $output = fopen('php://output', 'w');
    $stmt = $pdo->query($sql);

    // 写入表头
    fputcsv($output, ['ID', '名称', '金额', '时间']);

    // 逐行写入（内存占用恒定）
    while ($row = $stmt->fetch(PDO::FETCH_NUM)) {
        fputcsv($output, $row);
    }

    fclose($output);
}
```

### php://temp 和 php://memory

```php
<?php
// php://memory — 纯内存，不落盘
$memory = fopen('php://memory', 'r+');
fwrite($memory, "临时数据存储在内存中");
rewind($memory);
echo fread($memory, 1024); // 输出内容
fclose($memory); // 关闭后数据消失

// php://temp — 先内存，超过阈值自动落盘
// 默认阈值2MB，可自定义
$temp = fopen('php://temp/maxmemory:5242880', 'r+'); // 5MB阈值
fwrite($temp, str_repeat('x', 6 * 1024 * 1024)); // 写入6MB
// 前5MB在内存，超出的部分写入临时文件
rewind($temp);
echo ftell($temp); // 0

// 实战：生成PDF/Excel到内存再输出
function generateReport(): string
{
    $temp = fopen('php://temp/maxmemory:10485760', 'r+'); // 10MB阈值

    // 模拟写入报告数据
    fwrite($temp, "Report Header\n");
    for ($i = 0; $i < 100000; $i++) {
        fwrite($temp, "Row {$i}: data\n");
    }

    // 获取全部内容
    $size = ftell($temp);
    rewind($temp);
    $content = fread($temp, $size);
    fclose($temp);

    return $content;
}
```

### php://filter — 流过滤器

```php
<?php
// 读取时自动解密/编码
$content = file_get_contents('php://filter/read=convert.base64-encode/resource=/tmp/file.txt');
// 等价于 base64_encode(file_get_contents('/tmp/file.txt'))

// 写入时自动编码
file_put_contents(
    'php://filter/write=convert.base64-encode/resource=/tmp/encoded.txt',
    '原始数据'
);

// 常用过滤器
// convert.base64-encode/decode  — Base64编码
// string.rot13                   — ROT13加密
// string.toupper/tolower         — 大小写转换
// string.strip_tags              — 去除HTML标签
// convert.iconv.utf-8/gbk        — 字符编码转换
// zlib.deflate/inflate           — 压缩/解压

// 读取文件时自动转换编码
$utf8 = file_get_contents(
    'php://filter/read=convert.iconv.gbk:utf-8/resource=/tmp/gbk.txt'
);

// 链式过滤器（多个filter用|连接）
$filtered = file_get_contents(
    'php://filter/read=string.strip_tags|convert.base64-encode/resource=/tmp/html.txt'
);
```

## stream_context_create — 流上下文

```php
<?php
// HTTP POST请求
$context = stream_context_create([
    'http' => [
        'method' => 'POST',
        'header' => implode("\r\n", [
            'Content-Type: application/json',
            'Authorization: Bearer ' . $token,
        ]),
        'content' => json_encode(['name' => 'test']),
        'timeout' => 10,
        'ignore_errors' => true, // 不抛PHP错误，即使HTTP 4xx/5xx
        'follow_location' => true,
        'max_redirects' => 3,
    ],
]);
$response = file_get_contents('https://api.example.com/users', false, $context);

// 获取响应头
$ httpResponseCode = null;
foreach ($http_response_header as $header) {
    if (preg_match('#^HTTP/\d+\.\d+\s+(\d+)#', $header, $matches)) {
        $httpResponseCode = (int) $matches[1];
    }
}

// FTP上传
$ftpContext = stream_context_create([
    'ftp' => [
        'overwrite' => true,
    ],
]);
file_put_contents('ftp://user:pass@ftp.example.com/file.txt', $data, 0, $ftpContext);

// SSL配置
$sslContext = stream_context_create([
    'ssl' => [
        'verify_peer' => true,
        'verify_peer_name' => true,
        'cafile' => '/etc/ssl/certs/ca-certificates.crt',
    ],
]);
```

## 自定义流包装器

PHP允许注册自定义协议，让任何资源都能用文件函数操作：

```php
<?php
// 示例：注册redis://协议，用fread/fwrite操作Redis
class RedisStreamWrapper
{
    private ?Redis $redis = null;
    private string $key = '';
    private int $position = 0;
    private string $data = '';

    public function stream_open(string $path, string $mode, int $options, ?string &$opened_path): bool
    {
        $parsed = parse_url($path);
        $this->key = $parsed['host'] ?? '' ;

        $this->redis = new Redis();
        $this->redis->connect('127.0.0.1', 6379);
        $this->data = $this->redis->get($this->key) ?: '';
        $this->position = 0;

        return true;
    }

    public function stream_read(int $count): string
    {
        $result = substr($this->data, $this->position, $count);
        $this->position += strlen($result);
        return $result;
    }

    public function stream_write(string $data): int
    {
        $this->data = substr($this->data, 0, $this->position) . $data . substr($this->data, $this->position + strlen($data));
        $this->position += strlen($data);
        return strlen($data);
    }

    public function stream_eof(): bool
    {
        return $this->position >= strlen($this->data);
    }

    public function stream_tell(): int
    {
        return $this->position;
    }

    public function stream_seek(int $offset, int $whence = SEEK_SET): bool
    {
        switch ($whence) {
            case SEEK_SET: $this->position = $offset; break;
            case SEEK_CUR: $this->position += $offset; break;
            case SEEK_END: $this->position = strlen($this->data) + $offset; break;
            default: return false;
        }
        return true;
    }

    public function stream_close(): void
    {
        if ($this->redis && $this->key) {
            $this->redis->set($this->key, $this->data);
        }
    }

    public function stream_stat(): array|false
    {
        return ['size' => strlen($this->data)];
    }
}

// 注册
stream_wrapper_register('redis', RedisStreamWrapper::class);

// 使用
$fp = fopen('redis://user_session_123', 'r+');
fwrite($fp, '{"user_id": 1, "login_at": "2026-05-31"}');
fclose($fp); // 自动写入Redis

echo file_get_contents('redis://user_session_123');
```

## 面试常见追问

**Q: php://input和$_POST有什么区别？**
A: `$_POST`只能解析`application/x-www-form-urlencoded`和`multipart/form-data`两种Content-Type。`php://input`是原始请求体，不受限制。对于JSON API（`application/json`），必须用`php://input`读取。另外`$_POST`受`post_max_size`限制，`php://input`不受（但受`memory_limit`限制）。

**Q: 自定义流包装器有什么实际应用场景？**
A: 1) 虚拟文件系统：将S3/OSS封装为`s3://bucket/key`，让所有文件函数直接操作云存储；2) 单元测试：用`php://memory`替代真实文件；3) 透明加解密：`encrypt://`包装器自动加解密文件内容。Laravel的`Storage`门面底层就使用了类似的抽象。

**Q: php://temp和php://memory怎么选？**
A: 数据量确定较小（<2MB）用`php://memory`（纯内存，更快）；数据量不确定用`php://temp`（有溢出到文件的保险）。默认阈值2MB可通过`maxmemory`参数调整。
