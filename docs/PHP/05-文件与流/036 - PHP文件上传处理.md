# PHP文件上传处理

## $_FILES结构解析

PHP处理文件上传时会自动填充`$_FILES`超全局数组：

```php
<?php
// HTML: <input type="file" name="avatar">
// $_FILES结构：
[
    'avatar' => [
        'name'     => 'photo.jpg',        // 原始文件名
        'type'     => 'image/jpeg',        // 浏览器声明的MIME类型（不可信！）
        'tmp_name' => '/tmp/phpXXXXXX',    // 临时文件路径
        'error'    => UPLOAD_ERR_OK,       // 错误码
        'size'     => 102400,              // 文件大小（字节）
    ],
]

// 多文件上传: <input type="file" name="photos[]" multiple>
// $_FILES结构（注意嵌套方式不同）：
[
    'photos' => [
        'name'     => ['1.jpg', '2.jpg'],
        'type'     => ['image/jpeg', 'image/jpeg'],
        'tmp_name' => ['/tmp/phpA', '/tmp/phpB'],
        'error'    => [0, 0],
        'size'     => [1024, 2048],
    ],
]

// 错误码含义
$uploadErrors = [
    UPLOAD_ERR_OK         => '上传成功',
    UPLOAD_ERR_INI_SIZE   => '文件超过php.ini中upload_max_filesize限制',
    UPLOAD_ERR_FORM_SIZE  => '文件超过HTML表单MAX_FILE_SIZE限制',
    UPLOAD_ERR_PARTIAL    => '文件只有部分被上传',
    UPLOAD_ERR_NO_FILE    => '没有文件被上传',
    UPLOAD_ERR_NO_TMP_DIR => '临时目录不存在',
    UPLOAD_ERR_CANT_WRITE => '写入磁盘失败',
    UPLOAD_ERR_EXTENSION  => 'PHP扩展阻止了上传',
];
```

## 安全校验与move_uploaded_file

```php
<?php
class FileUploader
{
    private const ALLOWED_MIME = [
        'image/jpeg', 'image/png', 'image/gif', 'image/webp',
    ];
    private const MAX_SIZE = 5 * 1024 * 1024; // 5MB
    private const ALLOWED_EXTENSIONS = ['jpg', 'jpeg', 'png', 'gif', 'webp'];

    public function upload(string $field, string $destDir): string
    {
        // 1. 检查上传是否成功
        if (!isset($_FILES[$field])) {
            throw new InvalidArgumentException('没有找到上传文件');
        }

        $file = $_FILES[$field];

        if ($file['error'] !== UPLOAD_ERR_OK) {
            throw new RuntimeException("上传失败: 错误码 {$file['error']}");
        }

        // 2. 检查文件大小
        if ($file['size'] > self::MAX_SIZE) {
            throw new InvalidArgumentException('文件过大，最大允许5MB');
        }

        // 3. 真实MIME类型检测（不能依赖$_FILES['type']，它来自客户端）
        $finfo = new finfo(FILEINFO_MIME_TYPE);
        $mime = $finfo->file($file['tmp_name']);
        if (!in_array($mime, self::ALLOWED_MIME, true)) {
            throw new InvalidArgumentException("不支持的文件类型: {$mime}");
        }

        // 4. 扩展名白名单
        $ext = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
        if (!in_array($ext, self::ALLOWED_EXTENSIONS, true)) {
            throw new InvalidArgumentException("不支持的扩展名: {$ext}");
        }

        // 5. 图片额外验证：确认是真正的图片
        $imageInfo = getimagesize($file['tmp_name']);
        if ($imageInfo === false) {
            throw new InvalidArgumentException('文件不是有效的图片');
        }

        // 6. 生成安全的文件名（不使用原始文件名）
        $safeName = bin2hex(random_bytes(16)) . '.' . $ext;
        $destPath = rtrim($destDir, '/') . '/' . $safeName;

        // 7. move_uploaded_file（比rename/copy多了is_uploaded_file检查）
        if (!move_uploaded_file($file['tmp_name'], $destPath)) {
            throw new RuntimeException('文件保存失败');
        }

        // 8. 设置安全权限
        chmod($destPath, 0644);

        return $safeName;
    }
}

// 使用
try {
    $uploader = new FileUploader();
    $filename = $uploader->upload('avatar', '/var/www/uploads');
    echo json_encode(['url' => "/uploads/{$filename}"]);
} catch (Throwable $e) {
    http_response_code(400);
    echo json_encode(['error' => $e->getMessage()]);
}
```

### 安全要点总结

```php
<?php
// ⚠️ 绝对不要做的事
// 1. 不要用原始文件名
$dest = '/uploads/' . $_FILES['file']['name']; // ❌ 可能是 ../../../etc/passwd

// 2. 不要信任客户端MIME
if ($_FILES['file']['type'] === 'image/jpeg') { ... } // ❌ 客户端可以伪造

// 3. 不要只检查扩展名
if (str_ends_with($name, '.jpg')) { ... } // ❌ 可能是.php.jpg

// 4. 不要上传到web可访问目录且保留原始扩展名
// 恶意文件：shell.php.jpg → 如果Apache配置不当，会执行PHP

// ✅ 安全检查清单
// 1. finfo检测真实MIME
// 2. 扩展名白名单（不允许.php/.phtml/.htaccess等）
// 3. 生成随机文件名
// 4. move_uploaded_file而非copy/rename
// 5. 上传目录禁止执行PHP（.htaccess: php_flag engine off）
// 6. 限制文件大小
```

## 分块上传（大文件）

```php
<?php
/**
 * 分块上传服务端实现
 * 前端将大文件切割为固定大小的块，逐块上传
 */
class ChunkUploader
{
    private string $chunkDir;
    private int $maxChunkSize = 5 * 1024 * 1024; // 每块最大5MB

    public function __construct(string $chunkDir)
    {
        $this->chunkDir = rtrim($chunkDir, '/');
        if (!is_dir($this->chunkDir)) {
            mkdir($this->chunkDir, 0755, true);
        }
    }

    // 上传单个分块
    public function uploadChunk(
        string $fileId,
        int $chunkIndex,
        int $totalChunks,
        string $tmpPath
    ): array {
        $chunkPath = "{$this->chunkDir}/{$fileId}.part.{$chunkIndex}";

        move_uploaded_file($tmpPath, $chunkPath);

        // 检查是否所有块都已上传
        $uploadedChunks = 0;
        for ($i = 0; $i < $totalChunks; $i++) {
            if (file_exists("{$this->chunkDir}/{$fileId}.part.{$i}")) {
                $uploadedChunks++;
            }
        }

        return [
            'uploaded' => $uploadedChunks,
            'total' => $totalChunks,
            'complete' => $uploadedChunks === $totalChunks,
        ];
    }

    // 合并所有分块
    public function mergeChunks(string $fileId, int $totalChunks, string $destPath): string
    {
        $output = fopen($destPath, 'wb');

        for ($i = 0; $i < $totalChunks; $i++) {
            $chunkPath = "{$this->chunkDir}/{$fileId}.part.{$i}";
            $input = fopen($chunkPath, 'rb');
            stream_copy_to_stream($input, $output);
            fclose($input);
            unlink($chunkPath); // 合并后删除分块
        }

        fclose($output);
        chmod($destPath, 0644);

        return $destPath;
    }
}

// API路由处理
$fileId = $_POST['file_id'] ?? throw new InvalidArgumentException('缺少file_id');
$chunkIndex = (int)($_POST['chunk_index'] ?? 0);
$totalChunks = (int)($_POST['total_chunks'] ?? 0);

$uploader = new ChunkUploader('/tmp/chunks');
$result = $uploader->uploadChunk($fileId, $chunkIndex, $totalChunks, $_FILES['chunk']['tmp_name']);

if ($result['complete']) {
    $destPath = '/var/www/uploads/' . bin2hex(random_bytes(16));
    $uploader->mergeChunks($fileId, $totalChunks, $destPath);
    $result['file_path'] = $destPath;
}

echo json_encode($result);
```

### PHP上传配置

```ini
; php.ini 上传相关配置
file_uploads = On              ; 是否允许文件上传
upload_max_filesize = 50M      ; 单个文件最大大小
max_file_uploads = 20          ; 单次请求最大上传文件数
post_max_size = 100M           ; POST数据最大大小（必须 >= upload_max_filesize）
upload_tmp_dir = /tmp/php-upload ; 临时目录
max_input_time = 60            ; 解析输入数据的最大时间（秒）
memory_limit = 128M            ; 必须大于上传文件大小
```

## 面试常见追问

**Q: move_uploaded_file和rename有什么区别？**
A: `move_uploaded_file`会先调用`is_uploaded_file()`验证文件确实是HTTP POST上传的，防止通过构造文件路径将服务器上的任意文件移动。这是安全措施。`rename`没有这个检查。永远用`move_uploaded_file`处理上传文件。

**Q: 如何防止文件上传漏洞？**
A: 核心措施：1) `finfo`检测真实MIME（不信任客户端）；2) 生成随机文件名（不用原始名）；3) 扩展名白名单；4) 上传目录禁止执行脚本；5) 限制文件大小；6) 图片用GD库重新渲染（去除潜在的恶意payload）。

**Q: 分块上传如何实现断点续传？**
A: 前端维护已上传块列表，每次上传前先请求服务器查询已上传的块。服务器端通过检查分块文件是否存在来返回状态。使用文件的hash（如MD5前1MB）作为fileId确保唯一性。秒传功能则通过完整文件hash实现——上传前先查询服务器是否已有相同hash的文件。
