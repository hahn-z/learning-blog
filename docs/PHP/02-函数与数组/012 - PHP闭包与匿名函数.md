---# PHP闭包与匿名函数

闭包（Closure）是 PHP 函数式编程的核心基石。理解 Closure 类的内部机制、变量绑定策略、箭头函数的差异，是进阶 PHP 开发者的必修课。

## 匿名函数与 Closure 类

PHP 5.3 引入匿名函数，其本质是 `Closure` 类的实例化对象。

```php
<?php
$greet = function(string $name): string {
    return "Hello, $name";
};

echo $greet('World');        // Hello, World
echo get_class($greet);      // Closure
echo $greet instanceof Closure ? 'yes' : 'no'; // yes
```

**底层原理：** 匿名函数在编译时被转换为 `Closure` 类的实例。编译器创建一个内部类继承 `Closure`，实现 `__invoke()` 方法。opcache 会缓存编译结果。

## use 关键字：变量绑定

匿名函数默认无法访问外部变量。`use` 用于手动捕获（按值或按引用）。

```php
<?php
$prefix = 'Mr.';

// 按值捕获 — 捕获的是定义时的值
$format = function(string $name) use ($prefix): string {
    return "$prefix $name";
};

$prefix = 'Dr.'; // 不影响已捕获的值
echo $format('Smith'); // Mr. Smith

// 按引用捕获 — 捕获的是变量的引用
$count = 0;
$counter = function() use (&$count): int {
    return ++$count;
};

echo $counter(); // 1
echo $counter(); // 2
echo $count;     // 2 — 外部变量也被修改
```

**绑定时机：** `use` 在匿名函数**定义时**捕获变量值（除非用 `&`），不是调用时。这是与 JavaScript 闭包（基于作用域链）的关键区别。

## 箭头函数 fn()（PHP 7.4+）

箭头函数是匿名函数的简写形式，自动捕获外部变量（按值）。

```php
<?php
$multiplier = 3;

// 箭头函数自动捕获 $multiplier
$triple = fn($n) => $n * $multiplier;
echo $triple(5); // 15

// 等价的匿名函数写法
$triple2 = function($n) use ($multiplier) {
    return $n * $multiplier;
};

// 嵌套箭头函数 — 每层自动捕获
$add = fn($a) => fn($b) => $a + $b;
echo $add(3)(4); // 7

// 箭头函数中的 $this 自动绑定（和匿名函数不同）
class Calculator
{
    private int $tax = 10;

    public function getPrice(int $base): int
    {
        return fn() => $base + $this->tax;
    }
}
```

**箭头函数 vs 匿名函数的关键差异：**

| 特性 | 匿名函数 | 箭头函数 |
|------|---------|---------|
| 变量捕获 | `use` 手动 | 自动捕获 |
| 捕获方式 | 按值或按引用 | 始终按值 |
| 语句数 | 任意 | 单表达式 |
| `$this` 绑定 | 需要绑定或 `use ($this)` | 自动可用 |
| 返回多行逻辑 | 支持 | 不支持 |

## $this 绑定与 Closure::bind

在类方法内定义的匿名函数，`$this` 默认不可用。需要用 `Closure::bind` 或 `Closure::call` 绑定。

```php
<?php
class User
{
    private string $secret = 'hidden';

    public function getSecretExtractor(): Closure
    {
        // 匿名函数中 $this 默认不可用
        // 需要用 use ($this) 语法错误！
        // 正确方式：
        return Closure::bind(function() {
            return $this->secret;
        }, $this, self::class);
    }
}

$user = new User();
$extract = $user->getSecretExtractor();
echo $extract(); // hidden

// Closure::call — 更简洁的一次性绑定
$extractor = function() { return $this->secret; };
echo $extractor->call($user); // hidden
```

**`Closure::bind` 的三个参数：** (1) 闭包对象，(2) 绑定的 `$this` 对象（或 null），(3) 绑定的作用域（决定能访问哪些私有/受保护成员）。

## Callable 类型

`callable` 是 PHP 的伪类型，表示一切可调用的结构：

```php
<?php
function execute(callable $fn): mixed
{
    return $fn();
}

// 以下都是 callable：
execute('strlen');                           // 函数名字符串
execute([new ArrayObject(), 'count']);       // 对象方法数组
execute('ArrayObject::count');               // 静态方法字符串
execute(function() { return 'closure'; });   // 闭包
execute(fn() => 'arrow');                    // 箭头函数
execute(new class { function __invoke() { return 'invokable'; } }); // __invoke 对象

// is_callable 检查
var_dump(is_callable('strlen'));           // true
var_dump(is_callable('nonExistentFunc'));  // false
```

**`callable` vs `Closure`：** `Closure` 是 `callable` 的子集。`callable` 接受所有可调用形式；`Closure` 只接受匿名函数/箭头函数实例。类型提示用 `callable` 更宽松，用 `Closure` 更严格。

## 面试常见追问

**Q: PHP 闭包和 JavaScript 闭包有什么本质区别？**

A: JS 闭包基于词法作用域链，自动捕获所有外层变量，且捕获的是引用。PHP 匿名函数需要 `use` 显式声明捕获哪些变量（按值捕获），箭头函数虽然自动捕获但也是按值。JS 闭包在循环中经典坑（`var` 提升）在 PHP 中不存在，因为 PHP 的 `use` 捕获定义时的值。

**Q: 箭头函数能按引用捕获吗？**

A: 不能。`fn() => $var++` 不会修改外部 `$var`。如果需要修改外部变量，必须用传统匿名函数 + `use (&$var)`。这是 PHP 箭头函数的设计取舍——保持简单无副作用。

**Q: `Closure::bind` 的作用域参数有什么用？**

A: 作用域决定闭包能访问目标对象的哪些成员。`null` 表示只能访问 public；传类名则可以访问该类的 private/protected。框架常用此特性实现代理、Mock 等高级功能。

## 小结

PHP 闭包从 5.3 的基础支持到 7.4 的箭头函数，形成了完整的函数式编程基础。理解变量绑定机制是避免 Bug 的关键——`use` 按值、箭头函数自动按值、`&` 按引用，三者各有适用场景。
