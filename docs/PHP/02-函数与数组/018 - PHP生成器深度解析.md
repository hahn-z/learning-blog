---# PHP生成器深度解析

生成器（Generator）是 PHP 5.5 引入的强大特性，允许你用简单的函数语法实现迭代器，而无需在内存中构建整个数据集。理解生成器是处理大数据集和实现协程的基础。

## yield 基础

在函数中使用 `yield` 关键字，该函数就变成了生成器函数。每次 `yield` 暂停执行并返回一个值。

```php
<?php
function rangeGen(int $start, int $end): Generator
{
    for ($i = $start; $i <= $end; $i++) {
        yield $i;
    }
}

foreach (rangeGen(1, 5) as $num) {
    echo "$num "; // 1 2 3 4 5
}

// 生成器不会一次性计算所有值
$gen = rangeGen(1, 1000000); // 瞬间返回，不分配100万元素的数组
echo memory_get_usage(true); // 极小的内存占用
```

**核心原理：** 调用生成器函数不执行函数体，而是返回 `Generator` 对象。每次 `foreach` 迭代（或手动调用 `next()`）时，函数执行到下一个 `yield` 暂停。Generator 对象实现了 `Iterator` 接口。

## Generator 类的方法

```php
<?php
function fibonacci(): Generator
{
    $a = 0;
    $b = 1;
    while (true) {
        yield $a;
        [$a, $b] = [$b, $a + $b];
    }
}

$gen = fibonacci();

// 手动迭代
$gen->current();  // 0
$gen->next();
$gen->current();  // 1
$gen->next();
$gen->current();  // 1
$gen->next();
$gen->current();  // 2

// 获取键（yield 的表达式中可以指定键）
function kvGen(): Generator
{
    yield 'name' => 'Alice';
    yield 'age' => 25;
}

$g = kvGen();
$g->key();     // 'name'
$g->current(); // 'Alice'
```

## send() — 向生成器发送数据

`send()` 向生成器传入值，作为 `yield` 表达式的返回值：

```php
<?php
function accumulator(): Generator
{
    $sum = 0;
    while (true) {
        $value = yield $sum;
        if ($value === null) break;
        $sum += $value;
    }
    return $sum;
}

$acc = accumulator();
$acc->send(10); // 返回 10（同时启动生成器）
$acc->send(20); // 返回 30
$acc->send(30); // 返回 60
```

**`send()` 的执行流程：** (1) 将值传入生成器作为当前 `yield` 的结果；(2) 恢复执行到下一个 `yield`；(3) 返回新的 `yield` 值。第一次 `send()` 前如果没有 `current()`，会隐式执行到第一个 `yield`。

## throw() — 向生成器抛出异常

```php
<?php
function safeProcessor(): Generator
{
    try {
        while (true) {
            $data = yield;
            echo "Processing: $data\n";
        }
    } catch (RuntimeException $e) {
        echo "Caught in generator: " . $e->getMessage() . "\n";
    }
    yield 'recovered';
}

$gen = safeProcessor();
$gen->send('item1');   // Processing: item1
$gen->throw(new RuntimeException('Something went wrong'));
// Caught in generator: Something went wrong
echo $gen->current();  // 'recovered'
```

## return — 生成器的最终返回值

```php
<?php
function csvParser(string $file): Generator
{
    $handle = fopen($file, 'r');
    $count = 0;
    while (($row = fgetcsv($handle)) !== false) {
        $count++;
        yield $row;
    }
    fclose($handle);
    return $count; // 生成器的返回值
}

$parser = csvParser('/path/to/large.csv');
foreach ($parser as $row) {
    // 处理每一行
}
$totalRows = $parser->getReturn(); // 获取 return 的值
echo "Processed $totalRows rows";
```

## 内存优化实战

```php
<?php
// 处理大文件 — 逐行读取，不加载整个文件到内存
function readLines(string $path): Generator
{
    $handle = fopen($path, 'r');
    while (($line = fgets($handle)) !== false) {
        yield trim($line);
    }
    fclose($handle);
}

foreach (readLines('/var/log/large.log') as $line) {
    if (str_contains($line, 'ERROR')) {
        echo "$line\n";
    }
}

// 百万级数据处理对比
// 方式1：一次性加载（内存爆炸）
// $data = range(1, 10000000); // ~500MB+

// 方式2：生成器（几乎零内存）
function bigRange(int $start, int $end): Generator
{
    for ($i = $start; $i <= $end; $i++) {
        yield $i;
    }
}

$sum = 0;
foreach (bigRange(1, 10000000) as $n) {
    $sum += $n;
}
echo $sum; // ~4字节内存 vs 500MB
```

## 协程基础

生成器的 `yield`/`send()` 机制可以实现简单的协程——协作式多任务：

```php
<?php
function task1(): Generator
{
    for ($i = 0; $i < 3; $i++) {
        echo "Task 1: step $i\n";
        yield; // 让出控制权
    }
}

function task2(): Generator
{
    for ($i = 0; $i < 3; $i++) {
        echo "Task 2: step $i\n";
        yield;
    }
}

// 简单调度器
function scheduler(array $tasks): void
{
    $taskQueue = [];
    foreach ($tasks as $task) {
        $taskQueue[] = $task();
    }

    while (!empty($taskQueue)) {
        $nextQueue = [];
        foreach ($taskQueue as $gen) {
            $gen->next();
            if ($gen->valid()) {
                $nextQueue[] = $gen;
            }
        }
        $taskQueue = $nextQueue;
    }
}

scheduler([task1(...), task2(...)]);
// Task 1: step 0
// Task 2: step 0
// Task 1: step 1
// Task 2: step 1
// Task 1: step 2
// Task 2: step 2
```

## yield from 委托生成器

```php
<?php
function innerGen(): Generator
{
    yield 1;
    yield 2;
}

function outerGen(): Generator
{
    yield 0;
    yield from innerGen(); // 委托给子生成器
    yield 3;
}

foreach (outerGen() as $v) {
    echo "$v "; // 0 1 2 3
}
```

## 面试常见追问

**Q: 生成器和迭代器有什么区别？**

A: 生成器是实现迭代器的简便方式。Generator 类自动实现了 Iterator 接口，但用 `yield` 语法比手动实现 5 个 Iterator 方法简洁得多。生成器的独特优势是惰性求值和极低内存占用。

**Q: `yield` 和 `return` 的区别？**

A: `return` 终止函数执行并返回值，只能返回一次。`yield` 暂停函数执行保留状态，可以多次 yield。`return` 的值通过 `Generator::getReturn()` 获取，`yield` 的值通过 `current()` 获取。

**Q: 生成器能 rewind（回退）吗？**

A: 不能。Generator 的 `rewind()` 方法会抛出异常。生成器是一次性的正向迭代器。如果需要多次遍历，可以创建新的生成器实例，或用 `iterator_to_array()` 一次性收集。

**Q: 什么场景下必须用生成器？**

A: 没有必须用的场景，但以下场景强烈推荐：(1) 处理超大文件/数据集（内存敏感）；(2) 实现管道/中间件模式；(3) 协程/异步编程（Swoole/ReactPHP 底层原理类似）。

## 小结

生成器的核心价值是**惰性求值**和**内存优化**。`yield` 暂停函数执行，`send()` 向生成器传值，`throw()` 抛异常，`getReturn()` 获取最终返回值。处理大数据时，生成器能把内存从 GB 级降到 KB 级。
