---# PHP数组排序算法详解

PHP 提供了丰富的排序函数，每个都有特定的使用场景。理解它们的底层实现和稳定性差异，才能在正确的场景选择正确的函数。

## 排序函数全景

PHP 的排序函数命名有明确规律：

| 函数 | 键行为 | 值排序 | 关联 |
|------|--------|--------|------|
| `sort` | 重建数字索引 | 升序 | 否 |
| `rsort` | 重建数字索引 | 降序 | 否 |
| `asort` | 保留键 | 按值升序 | 是 |
| `arsort` | 保留键 | 按值降序 | 是 |
| `ksort` | 按键升序 | — | 是 |
| `krsort` | 按键降序 | — | 是 |
| `usort` | 重建数字索引 | 自定义 | 否 |
| `uasort` | 保留键 | 自定义 | 是 |
| `uksort` | 按键自定义 | — | 是 |

**命名规律：** `a` = 保持键值关联，`k` = 按键排序，`r` = 反向，`u` = 用户自定义比较。

## 基础排序

```php
<?php
// sort — 值排序，重建索引
$nums = [3, 1, 4, 1, 5, 9];
sort($nums);
var_dump($nums); // [1, 1, 3, 4, 5, 9] — 索引重建

// asort — 值排序，保留键
$scores = ['alice' => 90, 'bob' => 85, 'carol' => 95];
asort($scores);
var_dump($scores); // ['bob'=>85, 'alice'=>90, 'carol'=>95]

// ksort — 按键排序
$data = ['b' => 2, 'a' => 1, 'c' => 3];
ksort($data);
var_dump($data); // ['a'=>1, 'b'=>2, 'c'=>3]
```

**排序标志：**
```php
<?php
// SORT_NUMERIC — 数字比较
sort($mixed, SORT_NUMERIC);

// SORT_STRING — 字符串比较
sort($strings, SORT_STRING);

// SORT_NATURAL — 自然排序（file1, file2, file10）
$files = ['file10.txt', 'file2.txt', 'file1.txt'];
sort($files, SORT_NATURAL);
// ['file1.txt', 'file2.txt', 'file10.txt']

// SORT_FLAG_CASE — 不区分大小写（与 SORT_STRING|SORT_NATURAL 组合）
sort($names, SORT_STRING | SORT_FLAG_CASE);
```

## 用户自定义排序 usort/uasort/uksort

```php
<?php
// 按对象的某个属性排序
$users = [
    ['name' => 'Alice', 'age' => 30],
    ['name' => 'Bob', 'age' => 25],
    ['name' => 'Charlie', 'age' => 35],
];

usort($users, fn($a, $b) => $a['age'] <=> $b['age']);
// Bob(25), Alice(30), Charlie(35)

// 多字段排序
usort($users, function($a, $b) {
    return [$a['age'], $a['name']] <=> [$b['age'], $b['name']];
});

// 太空船运算符 <=> ：
// 返回 -1, 0, 1 分别对应 小于、等于、大于
```

## 多维排序 array_multisort

`array_multisort` 可以同时对多个数组排序，或按一列对二维数组排序：

```php
<?php
// 按列排序二维数组
$students = [
    ['name' => 'Alice', 'grade' => 'B', 'score' => 85],
    ['name' => 'Bob', 'grade' => 'A', 'score' => 95],
    ['name' => 'Charlie', 'grade' => 'B', 'score' => 78],
];

// 先按 grade 升序，再按 score 降序
$grades  = array_column($students, 'grade');
$scores  = array_column($students, 'score');

array_multisort(
    $grades, SORT_ASC,
    $scores, SORT_DESC,
    $students
);
// Alice(B,85), Charlie(B,78), Bob(A,95) — 等等，A<B 所以 Bob 在最后？
// 实际：Bob(A,95) 先排出来，然后 Charlie(B,78), Alice(B,85)

// 多个数组同步排序
$names  = ['Charlie', 'Alice', 'Bob'];
$ages   = [35, 30, 25];
array_multisort($names, $ages);
// names: ['Alice', 'Bob', 'Charlie']
// ages:  [30, 25, 35] — 跟随 names 的排序顺序
```

**`array_multisort` 的注意事项：** (1) 等价元素保留原始顺序（稳定排序的弱保证）；(2) 关联键保留但数字键重建索引；(3) 参数成对出现：数组 + 排序方向。

## 排序稳定性

PHP 的排序函数底层使用 **Quicksort**（快速排序），是**不稳定**的排序算法——相等元素的相对顺序可能改变。

```php
<?php
// 不稳定排序的例子
$data = [
    ['name' => 'A', 'score' => 100],
    ['name' => 'B', 'score' => 100],
    ['name' => 'C', 'score' => 90],
];

usort($data, fn($a, $b) => $a['score'] <=> $b['score']);
// A 和 B 都是 100 分，但排序后 A 和 B 的顺序不确定！

// 实现稳定排序的技巧 — 添加原始索引作为兜底
foreach ($data as $i => &$item) {
    $item['_orig'] = $i;
}
usort($data, function($a, $b) {
    $cmp = $a['score'] <=> $b['score'];
    return $cmp !== 0 ? $cmp : $a['_orig'] <=> $b['_orig'];
});
```

**PHP 8.0 的改进：** `sort`/`rsort`/`usort` 等函数改为稳定的排序算法（修改后的快速排序 + 插入排序混合），相等元素的原始顺序被保留。这是 PHP 8 的一个重要但容易被忽视的改进。

## 底层算法

PHP 8 之前使用标准 Quicksort（O(n log n) 平均，O(n²) 最坏）。PHP 8 改用 **PDSort**（Pattern-Defeating Quicksort），综合了以下优化：

1. 小数组用插入排序（n < 16）
2. 选取好的 pivot（median-of-three）
3. 处理重复元素的 "三路分区"
4. 检测已排序/逆序模式，退化为线性时间

## 面试常见追问

**Q: `usort` 和 `array_multisort` 分别适合什么场景？**

A: `usort` 适合自定义复杂比较逻辑（多字段、条件判断），代码更直观。`array_multisort` 适合按列排序二维数组，特别是同时按多列排序时效率更高（一次排序完成）。

**Q: PHP 8 的排序稳定了，还需要手动实现稳定排序吗？**

A: 如果确定运行环境是 PHP 8+，不需要。但如果需要兼容 PHP 7，或者使用自定义排序函数中调用其他排序函数（嵌套排序），仍需注意稳定性问题。

**Q: 排序大数组时如何优化？**

A: (1) 避免在比较函数中做重复计算，预计算后排序；(2) 用 `array_column` + `array_multisort` 代替 `usort` 中的字段访问；(3) 如果只需要 TopN，考虑用堆（`SplMinHeap`/`SplMaxHeap`）而非全排序。

## 小结

掌握 PHP 排序函数的关键：理解命名规律（`a`/`k`/`r`/`u` 前缀），知道 PHP 8 排序已稳定，多维排序用 `array_multisort`，自定义比较用太空船运算符 `<=>`。
