---# PHP数组遍历与迭代器

遍历是数组最频繁的操作。理解 `foreach` 的内部指针机制、SPL 迭代器体系、自定义迭代器，是从初级到高级 PHP 开发者的分水岭。

## foreach 与内部指针机制

```php
<?php
$arr = ['a', 'b', 'c', 'd', 'e'];

// foreach 在遍历前会创建数组副本的指针位置快照
foreach ($arr as $key => $value) {
    echo "$key: $value\n";
}

// foreach 内部机制：
// 1. 创建内部指针副本（refcount 增加或 copy-on-write）
// 2. 每次迭代移动指针
// 3. 遍历完成后重置指针

// 重要：foreach 不影响数组外部指针
echo current($arr); // 'a' — 指针未被 foreach 移动
```

**PHP 7 的关键变化：** `foreach` 不再依赖数组内部指针（`current()`/`next()` 那套）。PHP 7 使用自己的内部迭代器（`zend_hash_internal_pointer_reset` 的变体），遍历期间修改原数组不会导致未定义行为。

### 遍历中修改数组

```php
<?php
// PHP 7+ 安全的遍历中修改
$arr = [1, 2, 3, 4, 5];
foreach ($arr as $key => $value) {
    if ($value === 3) {
        unset($arr[$key]); // 安全：不影响当前遍历
    }
}
var_dump($arr); // [0=>1, 1=>2, 3=>4, 4=>5]

// 但新增元素可能不会被遍历到（取决于实现）
$arr2 = ['a', 'b'];
foreach ($arr2 as $v) {
    $arr2[] = strtoupper($v); // 可能无限循环！
}
```

## ArrayObject

`ArrayObject` 是 SPL 提供的数组包装类，让数组可以像对象一样操作：

```php
<?php
$arrObj = new ArrayObject(['name' => 'Alice', 'age' => 25]);

// 像数组一样访问
echo $arrObj['name'];       // Alice
$arrObj['city'] = 'Beijing';

// 像对象一样访问
echo $arrObj->count();      // 3

// 遍历
foreach ($arrObj as $key => $value) {
    echo "$key: $value\n";
}

// ArrayObject 实现了 IteratorAggregate，可获取独立迭代器
$iter1 = $arrObj->getIterator();
$iter2 = $arrObj->getIterator(); // 独立的迭代器，互不影响
```

**ArrayObject 的 flag 常量：**
- `ArrayObject::STD_PROP_LIST`：属性访问走对象属性
- `ArrayObject::ARRAY_AS_PROPS`：允许 `$obj->key` 访问数组元素

## Iterator 接口

自定义迭代器必须实现 5 个方法：

```php
<?php
class RangeIterator implements Iterator
{
    private int $position;
    
    public function __construct(
        private int $start,
        private int $end,
        private int $step = 1
    ) {
        $this->position = $start;
    }

    public function current(): int   { return $this->position; }
    public function key(): int       { return $this->position; }
    public function next(): void     { $this->position += $this->step; }
    public function rewind(): void   { $this->position = $this->start; }
    public function valid(): bool    { return $this->position <= $this->end; }
}

$range = new RangeIterator(1, 10, 2);
foreach ($range as $num) {
    echo "$num "; // 1 3 5 7 9
}
```

**调用顺序：** `rewind()` → `valid()` → `current()`/`key()` → 循环体 → `next()` → `valid()` → ...

## IteratorAggregate

只需实现 `getIterator()` 方法，将迭代逻辑委托出去：

```php
<?php
class StudentGroup implements IteratorAggregate
{
    private array $students = [];

    public function addStudent(string $name): void
    {
        $this->students[] = $name;
    }

    public function getIterator(): ArrayIterator
    {
        return new ArrayIterator($this->students);
    }
}

$group = new StudentGroup();
$group->addStudent('Alice');
$group->addStudent('Bob');

foreach ($group as $student) {
    echo "$student\n";
}
```

**Iterator vs IteratorAggregate：** 简单场景用 `IteratorAggregate` + 内置迭代器；需要复杂遍历逻辑（如递归、延迟加载、分页）时实现 `Iterator`。

## 常用 SPL 迭代器

```php
<?php
// ArrayIterator — 数组包装
$ai = new ArrayIterator(['a', 'b', 'c']);

// RecursiveArrayIterator — 递归遍历多维数组
$multi = [['a', 'b'], ['c', ['d', 'e']]];
$iter = new RecursiveIteratorIterator(
    new RecursiveArrayIterator($multi),
    RecursiveIteratorIterator::LEAVES_ONLY
);
foreach ($iter as $leaf) {
    echo "$leaf "; // a b c d e
}

// FilterIterator — 过滤迭代器
class EvenFilter extends FilterIterator
{
    public function accept(): bool
    {
        return $this->current() % 2 === 0;
    }
}

$nums = new ArrayIterator([1, 2, 3, 4, 5, 6]);
$evens = new EvenFilter($nums);
foreach ($evens as $n) {
    echo "$n "; // 2 4 6
}

// LimitIterator — 分页
$page = new LimitIterator(new ArrayIterator(range(1, 100)), 20, 10);
foreach ($page as $item) {
    echo "$item "; // 21 22 23 ... 30
}
```

## 面试常见追问

**Q: `foreach` 遍历对象时，遍历的是什么？**

A: 默认遍历对象的所有**可见属性**（按定义顺序）。如果对象实现了 `Iterator` 或 `IteratorAggregate`，则使用自定义迭代逻辑。

**Q: 为什么 `foreach` 比手动 `for` + `count` 遍历数组更快？**

A: `foreach` 在引擎层面直接遍历 HashTable 的 Bucket 双向链表，O(n) 操作且无额外函数调用。`for` + `$arr[$i]` 每次都要做哈希查找（即使数字键），且有函数调用开销。

**Q: 什么时候该用迭代器而不是数组？**

A: (1) 数据量大且不需要全部加载（分页、文件行、数据库游标）；(2) 数据源是惰性的（生成器、API 流）；(3) 需要封装遍历逻辑（过滤、递归、去重）。

**Q: `IteratorAggregate` 比 `Iterator` 好在哪里？**

A: `IteratorAggregate` 将数据存储和迭代逻辑分离，类本身不需要维护迭代状态（`$position` 等）。多个迭代器可以同时独立遍历同一个数据源。

## 小结

PHP 的迭代体系从简单的 `foreach` 到完整的 SPL 迭代器模式，覆盖了所有遍历场景。日常开发 90% 用 `foreach` + 数组即可；处理大数据集或复杂遍历时选择合适的迭代器。
