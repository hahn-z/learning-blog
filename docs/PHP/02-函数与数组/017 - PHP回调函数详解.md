# PHP回调函数详解

回调函数是 PHP 实现事件驱动、策略模式和延迟执行的核心机制。理解 `callable` 类型、各种回调形式、以及 PHP 内置的回调注册函数，是进阶 PHP 开发的基本功。

## callable 类型与回调形式

PHP 中一切可被调用的结构都可以作为回调：

```php
<?php
class MyClass
{
    public static function staticMethod(string $msg): string {
        return "static: $msg";
    }

    public function instanceMethod(string $msg): string {
        return "instance: $msg";
    }

    public function __invoke(string $msg): string {
        return "invokable: $msg";
    }
}

$obj = new MyClass();

// 1. 函数名字符串
call_user_func('strlen', 'hello'); // 5

// 2. 闭包/匿名函数
call_user_func(function($n) { return $n * 2; }, 5); // 10

// 3. 箭头函数
call_user_func(fn($n) => $n * 3, 5); // 15

// 4. 类静态方法 — 字符串形式
call_user_func('MyClass::staticMethod', 'hi');

// 5. 类静态方法 — 数组形式
call_user_func(['MyClass', 'staticMethod'], 'hi');

// 6. 对象实例方法 — 数组形式
call_user_func([$obj, 'instanceMethod'], 'hi');

// 7. __invoke 对象
call_user_func($obj, 'hi');
```

## is_callable 验证

```php
<?php
// is_callable 两重功能：检查语法有效性和实际可调用性
var_dump(is_callable('strlen'));              // true — 函数存在
var_dump(is_callable('nonExistent'));         // false
var_dump(is_callable([$obj, 'instanceMethod'])); // true

// 第二个参数：只检查语法不验证是否真正存在
var_dump(is_callable('nonExistent', true));   // true — 语法合法
var_dump(is_callable('nonExistent', false));  // false — 实际不存在

// callable 类型提示自动验证
function execute(callable $fn): mixed {
    return $fn();
}
execute('nonExistent'); // TypeError: Argument #1 must be of type callable
```

## call_user_func 与 call_user_func_array

```php
<?php
// call_user_func — 直接传参数
function greet(string $name, string $greeting = 'Hello'): string {
    return "$greeting, $name!";
}

echo call_user_func('greet', 'Alice', 'Hi'); // Hi, Alice!

// call_user_func_array — 参数打包为数组
$params = ['Bob', 'Good morning'];
echo call_user_func_array('greet', $params); // Good morning, Bob!

// PHP 5.6+ 推荐用 ... 展开替代 call_user_func_array
echo greet(...$params); // Good morning, Bob!
```

**`call_user_func_array` 的实际价值：** 动态调用时参数数量不确定（如框架的路由分发、事件系统的参数传递）。但在已知参数数量的场景下，直接 `...` 展开更简洁高效。

## 匿名类作为回调

```php
<?php
// 匿名类实现 __invoke 作为回调
$comparator = new class {
    public function __invoke($a, $b): int {
        return $a <=> $b;
    }
};

$nums = [3, 1, 4, 1, 5];
usort($nums, $comparator);
var_dump($nums); // [1, 1, 3, 4, 5]
```

## 系统回调注册函数

PHP 提供了多个在特定时机触发回调的注册函数：

```php
<?php
// register_shutdown_function — 脚本结束时执行
register_shutdown_function(function() {
    $error = error_get_last();
    if ($error) {
        error_log("Fatal: {$error['message']}");
    }
});

// set_error_handler — 自定义错误处理
set_error_handler(function(int $errno, string $errstr, string $errfile, int $errline): bool {
    error_log("Error [$errno]: $errstr in $errfile:$errline");
    return true; // 阻止默认错误处理
});

// set_exception_handler — 未捕获异常处理
set_exception_handler(function(Throwable $e) {
    error_log("Uncaught: " . $e->getMessage());
    http_response_code(500);
    echo json_encode(['error' => 'Internal Server Error']);
});

// spl_autoload_register — 自动加载
spl_autoload_register(function(string $class) {
    $file = str_replace('\\', '/', $class) . '.php';
    if (file_exists($file)) {
        require $file;
    }
});

// ob_start 回调 — 输出缓冲处理
ob_start(function(string $buffer): string {
    return str_replace('<!-- SECRET -->', '[REDACTED]', $buffer);
});
```

## 回调在实战中的典型应用

```php
<?php
// 1. 策略模式 — 通过回调实现运行时策略切换
class PriceCalculator
{
    public function calculate(float $base, callable $discountStrategy): float
    {
        return $base - $discountStrategy($base);
    }
}

$calc = new PriceCalculator();
$vipPrice = $calc->calculate(100, fn($price) => $price * 0.2);      // VIP 8折
$memberPrice = $calc->calculate(100, fn($price) => $price * 0.1);   // 会员 9折

// 2. 中间件管道
function middleware(array $handlers, callable $final): callable
{
    return array_reduce(
        array_reverse($handlers),
        fn($next, $handler) => fn($request) => $handler($request, $next),
        $final
    );
}
```

## 面试常见追问

**Q: `callable` 和 `Closure` 类型提示的区别？**

A: `callable` 接受所有可调用形式（函数名、数组、闭包、`__invoke` 对象）。`Closure` 只接受匿名函数/箭头函数实例。`callable` 是伪类型，`Closure` 是真正的类。

**Q: `call_user_func` 和直接调用的区别？**

A: (1) `call_user_func` 支持动态函数名和参数；(2) 直接调用性能更好（少一层函数调用）；(3) `call_user_func` 不支持引用传递参数（PHP 5.4+ 的废弃特性），需要引用时直接调用。

**Q: `register_shutdown_function` 和 `__destruct` 的区别？**

A: `register_shutdown_function` 在脚本结束时触发（包括 `exit`/`die`、致命错误），执行顺序按注册顺序。`__destruct` 在对象销毁时触发，可能是脚本结束前或引用计数归零时。致命错误时 `__destruct` 不一定执行。

**Q: 为什么 `is_callable('nonExistent', true)` 返回 true？**

A: 第二个参数为 `true` 时只做语法检查（是否是合法的回调格式），不验证函数/方法是否实际存在。这在框架中用于验证用户配置的回调格式是否正确。

## 小结

PHP 回调机制覆盖了从简单的函数名传递到复杂的闭包绑定。日常开发中优先用 `callable` 类型提示 + 匿名函数，系统级回调用 `register_shutdown_function`/`set_error_handler` 处理异常和清理。
