---# PHP函数参数与返回值进阶

PHP 函数的参数和返回值机制从 PHP 5 到 PHP 8 经历了巨大的演进。从最基础的值传递到命名参数、联合类型、返回类型声明，理解这些机制不仅能写出更健壮的代码，也是面试中的高频考点。

## 默认参数值

默认参数必须放在参数列表的右侧，且必须是常量表达式（不能是变量或函数调用）。

```php
<?php
// 基础默认参数
function createUser(string $name, string $role = 'user', int $timeout = 3600): array
{
    return [
        'name' => $name,
        'role' => $role,
        'timeout' => $timeout,
    ];
}

echo createUser('Alice')['role'];        // user
echo createUser('Bob', 'admin')['role']; // admin

// PHP 8.1+ 默认值可以是 new 表达式（构造器提升）
function setLogger(Logger $logger = new NullLogger()): void {
    $this->logger = $logger;
}
```

**坑点：** 默认参数在函数定义时求值，不是调用时。如果默认值是 `[]`，每次调用都会得到新数组。

## 可变参数 ...$args

PHP 5.6 引入 `...` 运算符（splat operator），用于收集剩余参数或展开数组。

```php
<?php
// 收集可变参数
function sum(int ...$numbers): int
{
    return array_sum($numbers);
}

echo sum(1, 2, 3, 4, 5); // 15

// 类型约束同样生效 — 每个参数都会检查
function concat(string ...$parts): string
{
    return implode('-', $parts);
}

echo concat('a', 'b', 'c'); // a-b-c

// 展开数组传参
$nums = [10, 20, 30];
echo sum(...$nums); // 60
```

**底层机制：** `...$args` 将参数打包为数组，`...$array` 在调用时解包。PHP 内部通过 `zend_parse_parameters` 处理，可变参数存储在 `zend_array`（HashTable）中。

## 命名参数（PHP 8+）

PHP 8 引入命名参数，通过参数名而非位置传参，极大提升了可读性。

```php
<?php
function createOrder(
    string $product,
    int $quantity = 1,
    float $discount = 0.0,
    string $currency = 'CNY',
): array {
    return compact('product', 'quantity', 'discount', 'currency');
}

// 只传需要的参数，跳过中间的默认值
$order = createOrder(
    product: 'MacBook',
    discount: 0.1,        // 跳过 quantity
    currency: 'USD',
);

// 位置参数和命名参数混用 — 位置参数必须在前
$order2 = createOrder('iPhone', quantity: 2);
```

**关键约束：** 命名参数不能在位置参数之前；`...` 展开时可以用命名参数 `func(...['a' => 1])`。

## 引用传递与引用返回

默认情况下 PHP 函数参数是值传递。要修改外部变量，需用 `&` 声明引用传递。

```php
<?php
// 引用传递
function increment(int &$value): void
{
    $value++;
}

$count = 5;
increment($count);
echo $count; // 6

// 引用返回 — 函数返回对变量的引用
class Registry
{
    private array $items = [];

    public function &get(string $key): mixed
    {
        return $this->items[$key];
    }

    public function set(string $key, mixed $value): void
    {
        $this->items[$key] = $value;
    }
}

$reg = new Registry();
$reg->set('count', 10);
$reg->get('count') = 20; // 通过引用返回修改原值
echo $reg->get('count'); // 20
```

**引用返回的声明要求：** 函数签名必须有 `&`，调用时也必须有 `$val = &func()`。漏掉任何一个都只得到值的拷贝。

## 返回类型声明

PHP 7 引入返回类型声明，PHP 8 持续增强：

```php
<?php
// 基本返回类型
function add(int $a, int $b): int
{
    return $a + $b;
}

// 可空返回类型
function findUser(int $id): ?User
{
    return $this->repository->find($id); // 可能返回 null
}

// void — 不返回值
function log(string $message): void
{
    error_log($message);
    // 不能有 return 语句（或只能 return;）
}

// never (PHP 8.1) — 函数永远不会正常返回
function redirect(string $url): never
{
    header("Location: $url");
    exit;
}

// 联合类型 (PHP 8.0)
function process(int|string $input): int|string
{
    return is_int($input) ? $input * 2 : strtoupper($input);
}

// 交集类型 (PHP 8.1)
function execute(Countable&Iterator $collection): int
{
    return count($collection);
}
```

## 严格模式与类型强制转换

```php
<?php
declare(strict_types=1); // 必须在文件第一行

function multiply(float $a, float $b): float
{
    return $a * $b;
}

// 没有严格模式：multiply(2, 3) 自动转 float，正常执行
// 严格模式下：multiply(2, 3) 抛出 TypeError，因为 int ≠ float
```

**注意：** 严格模式只影响调用方的类型检查，函数内部的自动转换不受影响。

## 面试常见追问

**Q: `...$args` 和 `func_get_args()` 有什么区别？**

A: `func_get_args()` 返回所有参数（含已声明的），`...$args` 只收集未声明的剩余参数。`...$args` 支持类型约束，`func_get_args()` 不支持。PHP 8.0+ 推荐用 `...$args`。

**Q: 引用返回有什么陷阱？**

A: (1) 返回的引用在调用者没有用 `&` 接收时会退化为值拷贝；(2) 返回局部变量的引用会导致悬垂引用（PHP 中变量销毁后引用指向未定义值）；(3) `__toString()`、`__clone()` 等魔术方法的返回值不能是引用。

**Q: PHP 8 的命名参数对向后兼容性有什么影响？**

A: 修改函数参数名会变成破坏性变更。建议框架/库开发者不要频繁改参数名，或用 `#[\SensitiveParameter]` 等属性标注不希望暴露的参数。

**Q: `never` 和 `void` 的区别？**

A: `void` 表示函数不返回值但正常结束；`never` 表示函数永远不会到达结尾（总是 throw、exit 或死循环）。`never` 是所有类型的子类型（底层类型），在类型系统中非常有用。

## 小结

| 特性 | PHP 版本 | 核心价值 |
|------|---------|---------|
| 默认参数 | 5.0+ | 简化可选参数 |
| `...$args` | 5.6+ | 类型安全的可变参数 |
| 返回类型声明 | 7.0+ | 接口契约、静态分析 |
| `?Type` 可空类型 | 7.1+ | 明确表达可能返回 null |
| 命名参数 | 8.0+ | 跳过默认值、可读性 |
| `never` 类型 | 8.1+ | 类型系统完整性 |
