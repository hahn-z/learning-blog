# PHP类型声明与严格模式

## 参数类型声明完整列表

### 标量类型（PHP 7.0+）

```php
function calculate(
    bool $flag,
    int $count,
    float $price,
    string $name,
): mixed {
    return compact('flag', 'count', 'price', 'name');
}
```

### 复合类型

```php
function process(
    array $items,
    object $instance,
    callable $callback,
    iterable $collection,
    ClassName $typedObject,
): void {
    // ...
}

// callable 接受以下形式：
// 'functionName'
// [$object, 'methodName']
// [ClassName::class, 'staticMethod']
// Closure 实例
// 实现了 __invoke 的对象
```

### 特殊类型

```php
// mixed（PHP 8.0+）— 接受任何类型
function dump(mixed $value): void
{
    var_dump($value);
}

// 注意：mixed是所有类型的联合类型的简写
// 等价于：array|bool|callable|int|float|null|object|resource|string
```

## 返回类型声明

### 基本返回类型

```php
function add(int $a, int $b): int
{
    return $a + $b;
}

function getName(): string
{
    return 'Hahn';
}

function isEnabled(): bool
{
    return true;
}

function getItems(): array
{
    return [1, 2, 3];
}
```

### self / parent / static

```php
class Base
{
    public function create(): static   // PHP 8.0+ 晚静态绑定
    {
        return new static();
    }
    
    public function copy(): self
    {
        return new self(); // 总是返回声明类的实例
    }
}

class Child extends Base
{
    public function create(): static
    {
        return new static(); // 返回Child实例
    }
}

$child = new Child();
echo get_class($child->create()); // "Child"（static绑定到实际类）
echo get_class($child->copy());   // "Base"（self绑定到声明类）
```

### nullable类型 ?Type

```php
// ?Type 是 Type|null 的简写
function findUser(int $id): ?User
{
    $user = User::findById($id);
    return $user ?: null; // 返回User或null
}

// 参数也可用
function greet(?string $name): string
{
    return 'Hello, ' . ($name ?? 'Guest');
}

greet('Hahn');  // OK
greet(null);    // OK - ?string允许null
greet();        // OK - 参数默认为null（仅当有默认值时）
```

### never vs void

```php
// void — 函数不返回值（正常结束）
function log(string $msg): void
{
    echo $msg;
    // 可以return; 但不能return $value;
}

// never — 函数永远不会返回（PHP 8.1+）
function redirect(string $url): never
{
    header("Location: $url");
    exit; // 或 throw exception
}

function fail(string $msg): never
{
    throw new RuntimeException($msg);
}
```

**区别：**

| 特性 | void | never |
|------|------|-------|
| 函数结束 | 正常返回 | 抛异常/exit/die |
| `return;` | 允许 | 不允许 |
| 用途 | 无返回值的操作 | 终止执行流程 |
| 继承规则 | 子类可以返回具体类型 | 子类只能返回never |

## strict_types=1 详解

### 作用域规则

```php
<?php
// file: math.php
declare(strict_types=1); // 只影响本文件的函数调用

function add(int $a, int $b): int
{
    return $a + $b;
}
```

```php
<?php
// file: main.php（没有strict_types）

include 'math.php';

add(1.5, 2.5); // 正常运行！因为调用在非strict文件中
// 1.5被截断为1，2.5被截断为2，返回3
```

```php
<?php
// file: strict_main.php
declare(strict_types=1);

include 'math.php';

add(1.5, 2.5); // TypeError! strict_types=1在调用文件中生效
```

**核心规则：** `strict_types=1`影响的是**调用点的文件**，而不是函数定义的文件。

### 严格模式下的类型转换

```php
<?php
declare(strict_types=1);

function foo(int $a): void { var_dump($a); }

foo(1);        // ✅ int → int
foo(1.0);      // ❌ TypeError（float → int 窄化）
foo(1.5);      // ❌ TypeError
foo('1');      // ❌ TypeError（string → int）
foo(true);     // ❌ TypeError（bool → int）

// 但宽化转换在严格模式下仍然允许
function bar(float $a): void { var_dump($a); }
bar(1);        // ✅ int → float 宽化
bar(1.5);      // ✅ float → float
```

### strict_types的局限

1. **只影响函数调用**，不影响赋值、运算等
2. **只影响标量类型**（int/float/string/bool），类类型始终严格
3. **不能在函数内部声明**，必须是文件顶部第一条语句
4. **对内置函数同样生效**

```php
<?php
declare(strict_types=1);

$a = '1';
$b = $a + 1;    // 2 — 赋值/运算不受影响！
echo strlen(123); // TypeError! strict下内置函数也要严格类型
```

## 代码示例

### 示例1：类型安全工具函数

```php
<?php
declare(strict_types=1);

class TypeSafe
{
    // 安全获取数组值（带类型检查）
    public static function getArrayValue(array $array, string $key, string $expectedType): mixed
    {
        if (!array_key_exists($key, $array)) {
            throw new InvalidArgumentException("Key '$key' not found");
        }
        
        $value = $array[$key];
        $actualType = gettype($value);
        
        if ($actualType !== $expectedType && !self::isCompatibleType($actualType, $expectedType)) {
            throw new TypeError("Expected '$expectedType' for key '$key', got '$actualType'");
        }
        
        return $value;
    }
    
    private static function isCompatibleType(string $actual, string $expected): bool
    {
        return match ($expected) {
            'float' => $actual === 'integer',  // int兼容float
            default => false,
        };
    }
    
    // 类型安全的事件调度器
    public static function dispatch(string $event, array $data, string $handlerClass): mixed
    {
        if (!class_exists($handlerClass)) {
            throw new TypeError("Handler class '$handlerClass' does not exist");
        }
        
        $handler = new $handlerClass();
        if (!method_exists($handler, 'handle')) {
            throw new TypeError("Handler must implement handle() method");
        }
        
        return $handler->handle($event, $data);
    }
}
```

### 示例2：严格模式下的类型约束系统

```php
<?php
declare(strict_types=1);

/**
 * 严格的参数验证器
 */
class StrictValidator
{
    // 验证所有参数类型
    public static function validateMethodArgs(
        string $class,
        string $method,
        array $args
    ): void {
        $ref = new ReflectionMethod($class, $method);
        $params = $ref->getParameters();
        
        foreach ($params as $i => $param) {
            if (!isset($args[$i]) && !$param->isDefaultValueAvailable()) {
                throw new ArgumentCountError(
                    "Missing argument \${$param->getName()} for {$class}::{$method}()"
                );
            }
            
            if (!isset($args[$i])) continue;
            
            $type = $param->getType();
            if ($type === null) continue;
            
            $typeName = $type instanceof ReflectionNamedType ? $type->getName() : (string)$type;
            $actualType = gettype($args[$i]);
            
            // 简化的类型检查
            $typeMap = [
                'int' => 'integer',
                'float' => 'double',
                'string' => 'string',
                'bool' => 'boolean',
                'array' => 'array',
            ];
            
            $expected = $typeMap[$typeName] ?? $typeName;
            if ($actualType !== $expected && $typeName !== 'mixed') {
                throw new TypeError(
                    "Argument \${$param->getName()} expects {$typeName}, {$actualType} given"
                );
            }
        }
    }
}
```

### 示例3：返回类型协变与逆变

```php
<?php
declare(strict_types=1);

// 返回类型协变：子类可以返回更具体的类型
abstract class Animal
{
    abstract public function reproduce(): Animal;
}

class Cat extends Animal
{
    public function reproduce(): Cat // ✅ 协变：Cat是Animal的子类型
    {
        return new Cat();
    }
}

// 参数类型逆变：子类可以接受更宽泛的类型
interface Logger
{
    public function log(string $message): void;
}

class FileLogger implements Logger
{
    public function log(string $message): void
    {
        file_put_contents('app.log', $message, FILE_APPEND);
    }
}

// PHP 8中参数类型可以协变（实际是 invariant check被放宽）
```

## 面试常见追问

**Q1: `mixed`和没有类型声明有什么区别？**
A: 语义上相同，但`mixed`是显式声明，表达"我确实接受任何类型"。没有类型声明可能是遗漏。`mixed`禁止子类添加更宽泛的类型（本身已经最宽了），而且IDE能识别这个声明。

**Q2: `static`作为返回类型是什么意思？**
A: `static`返回类型表示返回当前实际类的实例（晚静态绑定）。在继承链中，`static`绑定到调用方法的实际类，而`self`绑定到声明方法的类。这在工厂模式和链式调用中非常有用。

**Q3: 为什么`declare(strict_types=1)`按文件而不是全局生效？**
A: 兼容性。如果全局生效，引入的第三方库可能会因为调用方的strict模式而崩溃。按文件控制确保每个文件的严格性是独立的，库作者不需要担心调用方的设置。

**Q4: PHP的类型系统和TypeScript/Java有什么差距？**
A: PHP缺少泛型（generics），这是最大的差距。没有`List<int>`这种参数化类型，数组元素的类型无法约束。此外PHP没有类型擦除问题（运行时类型完整），但也没有编译时类型检查。PHP 8的Union/Intersection/Enum正在缩小差距。
