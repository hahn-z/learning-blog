---# PHP变量作用域与引用机制

## 四种变量作用域

### 全局变量

在函数外部定义的变量，函数内部**不可直接访问**（与C/Java不同）。

```php
$name = 'Hahn';

function greet(): void
{
    // echo $name; // Undefined variable!
    
    // 方式1：global关键字
    global $name;
    echo $name; // OK
    
    // 方式2：$GLOBALS超全局数组
    echo $GLOBALS['name']; // OK
}
```

### 局部变量

函数内部定义的变量，函数执行完毕后销毁。

### 静态变量

```php
function counter(): int
{
    static $count = 0; // 只初始化一次，值在调用间保持
    return ++$count;
}

counter(); // 1
counter(); // 2
counter(); // 3
```

**底层原理：** 静态变量存储在**持久化内存池**中，不在函数栈上。PHP引擎在编译时识别`static`声明，将该变量的zval分配到持久化区域，函数返回时不释放。

### 超全局变量

始终可用，不受作用域限制：

| 超全局 | 用途 |
|--------|------|
| `$GLOBALS` | 所有全局变量的引用 |
| `$_GET` / `$_POST` | HTTP请求参数 |
| `$_SERVER` | 服务器和执行环境信息 |
| `$_SESSION` | 会话变量 |
| `$_COOKIE` | Cookie变量 |
| `$_FILES` | 上传文件信息 |
| `$_REQUEST` | GET+POST+COOKIE合并 |
| `$_ENV` | 环境变量 |

## 引用传递 vs 值传递

### 基本概念

```php
// 值传递 - 复制值
$a = 1;
$b = $a;  // $b是$a的副本
$b = 2;
echo $a;  // 1 - $a未变

// 引用传递 - 共享同一份数据
$a = 1;
$b = &$a; // $b和$a指向同一个zval
$b = 2;
echo $a;  // 2 - $a跟着变了
```

### 函数参数引用

```php
function addPrefix(string &$name): void
{
    $name = 'Mr. ' . $name;
}

$user = 'Hahn';
addPrefix($user);
echo $user; // "Mr. Hahn"
```

### 引用返回

```php
class Config
{
    private array $data = [];
    
    public function &get(string $key): mixed
    {
        return $this->data[$key];
    }
}

$cfg = new Config();
$cfg->get('debug') = true; // 直接修改内部数据
```

## 写时复制（Copy-On-Write）原理

PHP的核心优化策略：变量赋值时不立即复制数据，等到**修改时**才复制。

```php
$a = str_repeat('x', 1000000); // 1MB字符串
$b = $a;  // 此时不复制！$a和$b共享同一块内存
echo memory_get_usage(); // 几乎没变

$b[0] = 'y'; // 触发COW，此时才复制
echo memory_get_usage(); // 增加约1MB
```

### COW触发条件

1. 对变量进行**写操作**（修改、追加、unset元素）
2. 该变量有**多个引用**指向同一zval
3. 两个条件同时满足时才触发复制

## zval结构体演变

### PHP 5.x 的 zval

```c
// PHP 5 - 24字节（64位）
typedef struct _zval_struct {
    zvalue_value value;    // 值（16字节union）
    zend_uint refcount__gc; // 引用计数
    zend_uchar type;        // 类型标记
    zend_uchar is_ref__gc;  // 是否引用
} zval;
```

问题：
- 所有类型占用同样大小（16字节union），小类型浪费空间
- 每个zval都有refcount，简单类型（int/bool）根本不需要
- 复杂类型（string/array/object）还需额外嵌套

### PHP 7+ 的 zval

```c
// PHP 7 - 16字节（64位）
typedef struct _zval_struct {
    zend_value value;  // 8字节（指针或内联值）
    union {
        struct {
            ZEND_ENDIAN_LOHI_4(
                zend_uchar type,
                zend_uchar type_flags,
                zend_uchar const_flags,
                zend_uchar reserved)
        } v;
        uint32_t type_info;
    } u1;
    union {
        uint32_t next;       // 哈希表冲突链
        uint32_t cache_slot; // 运行时缓存
        uint32_t opline_num; // 跳转指令
        uint32_t lineno;     // 行号
        uint32_t num_args;   // 函数参数个数
        uint32_t fe_pos;     // foreach迭代器位置
        uint32_t access_flags;
    } u2;
} zval;
```

**关键改进：**

| 对比项 | PHP 5 | PHP 7+ |
|--------|-------|--------|
| zval大小 | 24字节 | 16字节 |
| 引用计数 | 在zval中 | 移到值本身（string/array/object各自管理） |
| 简单类型 | 也要refcount | 内联存储，无需refcount |
| 引用标记 | is_ref在zval中 | 引用本身是一个zval（间接引用） |

PHP 7中，int/float/bool/null直接存在zval的8字节value中，无需额外分配内存，也无refcount开销。

## 代码示例

### 示例1：引用计数实验

```php
<?php
$a = str_repeat('x', 100);
debug_zval_dump($a); // refcount(2) - 多1是因为debug_zval_dump本身传参

$b = $a;
debug_zval_dump($a); // refcount(3) - $a, $b, 加上debug参数

$c = $a;
debug_zval_dump($a); // refcount(4)

unset($b);
debug_zval_dump($a); // refcount(3)

unset($c);
debug_zval_dump($a); // refcount(2) - 回到初始状态
```

### 示例2：COW验证

```php
<?php
function showMemory(string $label): void
{
    echo sprintf("%-30s %.2f MB\n", $label, memory_get_usage() / 1024 / 1024);
}

$big = range(1, 1000000);
showMemory('创建大数组后');

$copy = $big;
showMemory('赋值后（未修改）');

$copy[0] = 999; // 触发COW
showMemory('修改副本后');

unset($copy);
showMemory('释放副本后');
```

### 示例3：引用陷阱

```php
<?php
// 经典陷阱：foreach中的引用
$arr = ['a', 'b', 'c'];

foreach ($arr as &$v) {
    // 最后一次迭代后，$v仍然引用 $arr[2]
}
// 此时 $v 是 $arr[2] 的引用！

foreach ($arr as $v) {
    // $v = $arr[0] → 'a' 赋给 $arr[2]（因为$v还是$arr[2]的引用）
    // $arr 变成 ['a', 'b', 'a']
    // $v = $arr[1] → 'b' 赋给 $arr[2]
    // $arr 变成 ['a', 'b', 'b']
    // $v = $arr[2] → 'b' 赋给 $arr[2]
    // $arr 变成 ['a', 'b', 'b']
}
print_r($arr); // ['a', 'b', 'b'] 而不是预期的 ['a', 'b', 'c']

// 正确做法：用完引用后立即unset
$arr = ['a', 'b', 'c'];
foreach ($arr as &$v) { /* ... */ }
unset($v); // 解除引用！
foreach ($arr as $v) { /* ... */ }
print_r($arr); // ['a', 'b', 'c'] ✅
```

## 面试常见追问

**Q1: PHP中对象是按引用传递的吗？**
A: 严格来说不是。PHP 5+中对象变量存储的是**对象标识符**（类似指针），传递时复制的是标识符，但指向同一个对象。这叫"引用语义"但不是真正的引用（`&`）。区别在于：`$b = $a`后unset `$a`不影响`$b`，而`$b = &$a`后unset `$a`会使`$b`也变为null。

**Q2: 什么场景下应该使用引用传递？**
A: 需要修改原始变量时（如数组排序函数`usort`回调）；需要返回多个值时。但现代PHP更推荐返回数组或对象，避免引用带来的副作用。

**Q3: PHP 7为什么把refcount从zval移到值本身？**
A: 因为int/bool/float/null这些标量类型不需要引用计数——它们直接存在zval中，复制代价极低。只有string/array/object这种"大块头"才需要共享和引用计数。分离后，标量赋值零开销，整体内存减少约1/3。
