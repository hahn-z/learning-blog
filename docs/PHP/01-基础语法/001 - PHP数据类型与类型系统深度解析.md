# PHP数据类型与类型系统深度解析

## PHP八大数据类型

PHP的数据类型分为三大类：**标量类型**、**复合类型**和**特殊类型**。

### 标量类型（4种）

| 类型 | 说明 | 示例 |
|------|------|------|
| `bool` | 布尔值 | `true` / `false` |
| `int` | 整数（64位平台为64位） | `42`, `0xFF`, `0b1010` |
| `float` | 浮点数（IEEE 754双精度） | `3.14`, `1.2e3` |
| `string` | 字符串（二进制安全） | `"hello"`, `'world'` |

### 复合类型（4种）

| 类型 | 说明 |
|------|------|
| `array` | 有序映射，兼兂数组和哈希表功能 |
| `object` | 类实例 |
| `callable` | 可调用结构（函数名、闭包、数组回调） |
| `iterable` | `array` 或 `Traversable` 的超类型（PHP 7.1+） |

### 特殊类型（2种）

- `resource`：外部资源句柄（文件、数据库连接等）
- `null`：表示变量无值

注意：PHP 8.0中`resource`正逐步被`object`替代（如`GdImage`替代`gd resource`）。

## 弱类型转换规则

PHP是弱类型语言，在比较和运算时会进行隐式类型转换。这是面试的高频考点。

### 类型转换优先级

运算时的转换规则：`string` → `float` → `int` → `bool`（比较时方向相反）。

### `==` vs `===` 真值表（重点）

```
// 经典陷阱
var_dump(0 == 'foo');    // true  → 'foo'转为0
var_dump(0 === 'foo');   // false → 类型不同
var_dump('' == null);    // true
var_dump('0' == false);  // true
var_dump('php' == 0);    // true  → 字符串转数字得到0
var_dump('1php' == 1);   // true  → 前缀数字提取
var_dump('php1' == 0);   // true  → 非数字前缀转0
var_dump([] == false);   // true
var_dump([0] == false);  // false → 非空数组
var_dump('0e123' == '0e456'); // true → 被解释为科学计数法0
```

**`==` 松散比较完整规则表：**

| | null | bool | int | float | string | array |
|---|---|---|---|---|---|---|
| **null** | = | =bool | ≠0 | ≠0 | ""= | []= |
| **bool** | =bool | = | bool | bool | bool | bool |
| **int** | ≠0 | bool | = | =float | num cmp | ≠ |
| **float** | ≠0 | bool | =float | = | num cmp | ≠ |
| **string** | ""= | bool | num cmp | num cmp | = | ≠ |
| **array** | []= | bool | ≠ | ≠ | ≠ | = |

核心规则：
1. `null`只与`false`、`""`、`[]`、`0`松散相等
2. 有`bool`参与时，另一边转`bool`再比较
3. `string`与`int/float`比较时，字符串转数字
4. 数组之间比较时先比长度再比键值

## PHP 8的类型系统增强

### Union Types（PHP 8.0）

```php
function processInput(int|string $input): string
{
    return is_int($input) ? "Number: $input" : "Text: $input";
}

// 还可以包含 false（但不能单独用 false 作为类型）
function findUser(int $id): User|false
{
    return User::findById($id) ?: false;
}
```

### Intersection Types（PHP 8.1）

```php
function processEntity(Countable&Iterator $collection): void
{
    // $collection 必须同时实现 Countable 和 Iterator
    echo count($collection);
    foreach ($collection as $item) { /* ... */ }
}
```

**Union vs Intersection 区别：** Union是"或"关系，Intersection是"且"关系。Intersection不能包含标量类型。

### DNF类型（PHP 8.2）

析取范式（Disjunctive Normal Form），允许Intersection和Union组合：

```php
function process((Countable&Iterator)|ArrayObject $data): void
{
    // 接受同时实现Countable+Iterator的对象，或ArrayObject实例
}
```

## strict_types=1 的影响范围

```php
<?php
declare(strict_types=1);
// 仅影响当前文件！不影响被调用文件或调用者文件

function add(int $a, int $b): int
{
    return $a + $b;
}

add(1, 2);       // OK
add(1.0, 2.0);   // TypeError! float不能隐式转int
add('1', '2');   // TypeError! string不能隐式转int
```

**关键要点：**
- `declare(strict_types=1)`只影响**它所在的文件**
- 必须放在文件顶部（`<?php`之后第一条语句）
- 只影响**函数调用所在文件**的严格性，不影响函数定义所在文件
- 类型转换的窄化（float→int）在严格模式下报错，宽化（int→float）不报错

## 代码示例

### 示例1：类型判断工具函数

```php
<?php
declare(strict_types=1);

/**
 * 获取变量的详细类型信息（调试用）
 */
function getDetailedType(mixed $value): string
{
    if (is_resource($value)) {
        return 'resource(' . get_resource_type($value) . ')';
    }
    if (is_object($value)) {
        return 'object(' . get_class($value) . ')';
    }
    if (is_array($value)) {
        return 'array(' . count($value) . ')';
    }
    
    $type = gettype($value);
    if ($type === 'string') {
        return "string({$value})";
    }
    if ($type === 'integer' || $type === 'double') {
        return "{$type}({$value})";
    }
    return $type;
}

// 使用
echo getDetailedType(42);              // integer(42)
echo getDetailedType([1, 2]);          // array(2)
echo getDetailedType(fopen('php://memory', 'r')); // resource(stream)
```

### 示例2：类型转换陷阱

```php
<?php
// 浮点精度陷阱
$a = 0.1 + 0.2;
var_dump($a == 0.3);           // false!
var_dump(abs($a - 0.3) < 0.00001); // true - 正确的比较方式

// 字符串数字比较陷阱
var_dump('10 apples' == 10);   // true - PHP 7; PHP 8中仍为true
var_dump('apples 10' == 0);    // true - 非数字前缀

// 数组比较
var_dump([1, 2] == [2, 1]);    // false - 顺序敏感
var_dump([1, 2] === [2, 1]);   // false

// null参与的运算
var_dump(null + 1);             // int(1) - null转0
var_dump(null . 'text');        // string("text") - null转""
var_dump((int) null);           // int(0)
```

### 示例3：PHP 8类型系统综合运用

```php
<?php
declare(strict_types=1);

// Union Types + nullable
function search(string $query, int|null $limit = null): array|string
{
    $results = performSearch($query);
    
    if ($limit !== null) {
        $results = array_slice($results, 0, $limit);
    }
    
    return count($results) === 1 ? $results[0] : $results;
}

// mixed 是所有类型的 Union：array|bool|callable|int|float|null|object|resource|string
function logValue(mixed $value): void
{
    $type = match (true) {
        is_int($value) => 'integer',
        is_float($value) => 'float',
        is_string($value) => 'string',
        is_bool($value) => 'boolean',
        is_array($value) => 'array',
        is_null($value) => 'null',
        is_object($value) => 'object:' . get_class($value),
        is_resource($value) => 'resource',
        default => 'unknown',
    };
    
    echo "[{$type}] " . json_encode($value, JSON_UNESCAPED_UNICODE) . PHP_EOL;
}
```

## 面试常见追问

**Q1: PHP 8中`0 == 'foo'`的结果是什么？**
A: 仍然是`true`。PHP 8改变了数字与非数字字符串的比较——`0 == 'foo'`中`'foo'`转为`0`，所以相等。但`0 == ''`在PHP 8中变为`false`（PHP 7中是`true`）。PHP 8的核心变化是：当字符串是**纯非数字**时，比较改为字符串转数字而不是数字转字符串。

**Q2: `mixed`和`object`有什么区别？**
A: `mixed`包含所有类型（包括标量、数组、null等），`object`只接受对象实例。`mixed`等价于所有类型的Union。

**Q3: 为什么`declare(strict_types=1)`只影响当前文件？**
A: 这是PHP的设计决策。如果严格模式影响全局，那么一个库的严格模式可能导致调用方代码出错。按文件控制使得每个文件可以独立决定严格性，保证库的兼容性。

**Q4: PHP的资源类型为什么逐渐被淘汰？**
A: `resource`是不透明的、无法类型提示的、无法用IDE自动补全的。PHP 8将许多resource迁移为对象（如`GdImage`、`FTP\Connection`），这样可以利用类型系统、面向对象特性，并提高代码可读性。
