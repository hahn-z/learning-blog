---# PHP常量与枚举实战

## define() vs const

### 语法对比

```php
// define() — 运行时定义
define('MAX_USERS', 100);
define('APP_NAME', 'MyApp');
define('CONFIG', ['debug' => true, 'version' => '1.0']); // PHP 7+
define('DYNAMIC_CONST', $someValue); // ✅ 可以用变量/表达式

// const — 编译时定义
const MAX_USERS = 100;
const APP_NAME = 'MyApp';
const CONFIG = ['debug' => true, 'version' => '1.0'];
// const DYNAMIC = $value; // ❌ 不能用变量
```

### 关键区别

| 特性 | `define()` | `const` |
|------|-----------|---------|
| 定义时机 | 运行时 | 编译时 |
| 作用域 | 全局 | 遵循作用域规则 |
| 类中使用 | ❌ | ✅（类常量） |
| 条件语句中 | ✅ | ❌ |
| 动态名称 | ✅ `define($name, $val)` | ❌ |
| 性能 | 略慢 | 略快 |

```php
// const在条件中不可用
if ($debug) {
    const DEBUG_MODE = true; // ❌ Parse error
}
if ($debug) {
    define('DEBUG_MODE', true); // ✅
}

// 类常量只能用const
class Config
{
    const VERSION = '1.0';
    // define('VERSION', '1.0'); // ❌ 不能在类中用define
}
```

## 预定义常量与魔术常量

### 魔术常量（值随位置变化）

| 常量 | 含义 | 示例 |
|------|------|------|
| `__LINE__` | 当前行号 | `42` |
| `__FILE__` | 当前文件完整路径 | `/var/www/app.php` |
| `__DIR__` | 当前文件目录 | `/var/www` |
| `__FUNCTION__` | 当前函数名 | `calculate` |
| `__CLASS__` | 当前类名 | `User` |
| `__METHOD__` | 当前方法名 | `User::save` |
| `__NAMESPACE__` | 当前命名空间 | `App\Models` |
| `__TRAIT__` | 当前trait名 | `HasTimestamps` |

### 实用预定义常量

```php
// PHP版本
PHP_VERSION       // '8.3.0'
PHP_MAJOR_VERSION // 8

// 运行环境

// 路径

DIRECTORY_SEPARATOR // '/' or '\'

// 常用检查

```


## PHP 8.1 Enum完整语法

### 基础枚举（Unit Enum）

```php
enum Color
{
    case Red;
    case Green;
    case Blue;
}

$color = Color::Red;
echo $color->name; // 'Red'
```

### Backed Enum（有值枚举）

```php
// int-backed
enum HttpStatus: int
{
    case OK = 200;
    case Created = 201;
    case BadRequest = 400;
    case NotFound = 404;
    case InternalError = 500;
    
    public function isSuccessful(): bool
    {
        return $this->value >= 200 && $this->value < 300;
    }
    
    public function description(): string
    {
        return match ($this) {
            self::OK => 'OK',
            self::Created => 'Created',
            self::BadRequest => 'Bad Request',
            self::NotFound => 'Not Found',
            self::InternalError => 'Internal Server Error',
        };
    }
}

$status = HttpStatus::NotFound;
echo $status->value;        // 404
echo $status->description(); // 'Not Found'
echo $status->isSuccessful(); // false
```

### string-backed枚举

```php
enum UserRole: string
{
    case Admin = 'admin';
    case Editor = 'editor';
    case Viewer = 'viewer';
}
```

### from()与tryFrom()

```php
// from() — 找不到抛 ValueError
$status = HttpStatus::from(404);       // HttpStatus::NotFound
$status = HttpStatus::from(999);       // ValueError!

// tryFrom() — 找不到返回 null
$status = HttpStatus::tryFrom(999);    // null
$status = HttpStatus::tryFrom(404);    // HttpStatus::NotFound

// 实用：从数据库/API映射
$role = UserRole::tryFrom($request->input('role')) ?? UserRole::Viewer;
```

### 枚举的静态方法

```php
enum Priority: int
{
    case Low = 1;
    case Medium = 2;
    case High = 3;
    case Critical = 4;
    
    // 枚举values常量由PHP自动生成，但我们可以添加辅助方法
    public function label(): string
    {
        return match ($this) {
            self::Low => '低',
            self::Medium => '中',
            self::High => '高',
            self::Critical => '紧急',
        };
    }
    
    // 所有枚举自动拥有 cases() 方法
    // Priority::cases() → [Low, Medium, High, Critical]
    
    // 自定义映射方法
    public static function fromLabel(string $label): ?self
    {
        foreach (self::cases() as $case) {
            if ($case->label() === $label) {
                return $case;
            }
        }
        return null;
    }
}
```

## Enum实现接口与使用trait

### 实现接口

```php
interface HasLabel
{
    public function label(): string;
}

enum PaymentStatus: string implements HasLabel
{
    case Pending = 'pending';
    case Completed = 'completed';
    case Failed = 'failed';
    case Refunded = 'refunded';
    
    public function label(): string
    {
        return match ($this) {
            self::Pending => '待支付',
            self::Completed => '已完成',
            self::Failed => '支付失败',
            self::Refunded => '已退款',
        };
    }
}
```

### 使用trait

```php
trait EnumExtras
{
    public static function values(): array
    {
        return array_map(fn($case) => $case->value, self::cases());
    }
    
    public static function names(): array
    {
        return array_map(fn($case) => $case->name, self::cases());
    }
    
    public static function toArray(): array
    {
        return array_combine(
            array_map(fn($c) => $c->name, self::cases()),
            array_map(fn($c) => $c->value, self::cases()),
        );
    }
}

enum Permission: string
{
    use EnumExtras;
    
    case Read = 'read';
    case Write = 'write';
    case Delete = 'delete';
    case Admin = 'admin';
}

Permission::values();  // ['read', 'write', 'delete', 'admin']
Permission::names();   // ['Read', 'Write', 'Delete', 'Admin']
Permission::toArray(); // ['Read' => 'read', 'Write' => 'write', ...]
```

## 代码示例

### 示例1：状态机枚举

```php
<?php
declare(strict_types=1);

enum OrderStatus: string
{
    case Draft = 'draft';
    case Pending = 'pending';
    case Paid = 'paid';
    case Processing = 'processing';
    case Shipped = 'shipped';
    case Delivered = 'delivered';
    case Cancelled = 'cancelled';
    case Refunded = 'refunded';
    
    /**
     * 判断是否可以转换到目标状态
     */
    public function canTransitionTo(self $target): bool
    {
        return in_array($target, $this->allowedTransitions(), true);
    }
    
    private function allowedTransitions(): array
    {
        return match ($this) {
            self::Draft      => [self::Pending, self::Cancelled],
            self::Pending    => [self::Paid, self::Cancelled],
            self::Paid       => [self::Processing, self::Refunded],
            self::Processing => [self::Shipped, self::Cancelled],
            self::Shipped    => [self::Delivered],
            self::Delivered  => [self::Refunded],
            self::Cancelled, self::Refunded => [],
        };
    }
    
    public function isFinal(): bool
    {
        return in_array($this, [self::Delivered, self::Cancelled, self::Refunded], true);
    }
    
    public function badgeColor(): string
    {
        return match ($this) {
            self::Paid, self::Delivered => 'green',
            self::Pending, self::Processing => 'yellow',
            self::Shipped => 'blue',
            self::Cancelled, self::Refunded => 'red',
            self::Draft => 'gray',
        };
    }
}

// 使用
$status = OrderStatus::Pending;
if ($status->canTransitionTo(OrderStatus::Paid)) {
    echo "可以支付"; // ✅
}
if (!$status->canTransitionTo(OrderStatus::Shipped)) {
    echo "不能直接发货"; // ✅
}
```

### 示例2：权限枚举（位运算）

```php
<?php
declare(strict_types=1);

enum Permission: int
{
    case Read    = 1 << 0; // 1
    case Write   = 1 << 1; // 2
    case Delete  = 1 << 2; // 4
    case Manage  = 1 << 3; // 8
    case Admin   = 1 << 4; // 16
    
    // 组合权限
    public static function combine(self ...$permissions): int
    {
        return array_reduce(
            $permissions,
            fn(int $carry, self $p) => $carry | $p->value,
            0
        );
    }
    
    // 检查权限
    public static function has(int $mask, self $permission): bool
    {
        return ($mask & $permission->value) === $permission->value;
    }
    
    // 添加权限
    public static function grant(int $mask, self $permission): int
    {
        return $mask | $permission->value;
    }
    
    // 移除权限
    public static function revoke(int $mask, self $permission): int
    {
        return $mask & ~$permission->value;
    }
}

// 使用
$userPermissions = Permission::combine(
    Permission::Read,
    Permission::Write,
);
// $userPermissions = 3 (1 | 2)

Permission::has($userPermissions, Permission::Read);   // true
Permission::has($userPermissions, Permission::Delete); // false

// 授予删除权限
$userPermissions = Permission::grant($userPermissions, Permission::Delete);
Permission::has($userPermissions, Permission::Delete); // true
```

### 示列3：枚举与数据库映射

```php
<?php
declare(strict_types=1);

enum ArticleStatus: string
{
    use EnumExtras;
    
    case Draft = 'draft';
    case Published = 'published';
    case Archived = 'archived';
    
    // 从数据库值安全转换
    public static function fromDb(?string $value): self
    {
        return self::tryFrom($value ?? '') ?? self::Draft;
    }
}

// 数据库模型中使用
class Article
{
    public ArticleStatus $status {
        set(ArticleStatus|string $value) {
            $this->status = $value instanceof ArticleStatus 
                ? $value 
                : ArticleStatus::fromDb($value);
        }
    }
    
    public function canPublish(): bool
    {
        return $this->status === ArticleStatus::Draft;
    }
}
```

## 面试常见追问

**Q1: Backed Enum的值可以重复吗？**
A: 不可以。两个case不能有相同的value，否则会Fatal Error。但不同枚举可以有相同值（它们是不同类型）。

**Q2: Enum可以继承吗？**
A: 不可以。Enum不支持继承，但可以通过实现接口和trait来复用代码。这是设计决策：枚举是有限值的封闭集合，继承会破坏这个约束。

**Q3: Enum序列化到JSON会怎样？**
A: 默认情况下`json_encode(Enum::Case)`会报错。需要实现`JsonSerializable`接口或在PHP 8.1+中，Backed Enum自动支持通过`->value`序列化。Laravel/Symfony等框架已自动处理枚举序列化。

**Q4: const和define在性能上有区别吗？**
A: `const`在编译时处理，查找更快；`define`在运行时处理，略慢。但OPcache下差异可忽略。选择标准：类中用const，动态/条件中用define。
