# PHP字符串处理完全指南

## 四种字符串定义方式

### 单引号 vs 双引号

```php
$name = 'World';

// 单引号：不解析变量，只转义 \' 和 \\
echo 'Hello $name\n';   // Hello $name\n（原样输出）
echo 'It\'s mine';      // It's mine

// 双引号：解析变量和转义序列
echo "Hello $name\n";   // Hello World（换行）
echo "Hello {$name}!";  // Hello World!（复杂变量用花括号）
echo "Price: \${$price}"; // Price: $100
```

### Heredoc vs Nowdoc

```php
// Heredoc：类似双引号，解析变量
$html = <<<HTML
<div class="card">
    <h2>{$title}</h2>
    <p>{$content}</p>
</div>
HTML;

// Nowdoc：类似单引号，不解析变量（PHP 5.3+）
$raw = <<<'SQL'
SELECT * FROM users WHERE name = '$name' AND age > 18
SQL;
// $name不会被解析，原样保留
```

**性能差异：** 单引号理论上略快（无需解析），但实际差异可忽略不计。选择依据是**语义**：需要解析用双引号，否则用单引号。

## 字符串函数分类速查

### 查找类

```php
strpos($str, $needle);          // 返回位置或false
strrpos($str, $needle);         // 从末尾查找
stripos($str, $needle);         // 大小写不敏感
strstr($str, $needle);          // 返回needle及之后部分
str_contains($str, $needle);    // PHP 8 - 返回bool
str_starts_with($str, $needle); // PHP 8
str_ends_with($str, $needle);   // PHP 8
substr_count($str, $needle);    // 出现次数
```

### 截取与替换

```php
substr($str, 0, 10);              // 截取
str_replace('a', 'b', $str);     // 替换
str_ireplace('A', 'b', $str);    // 不敏感替换
strtr($str, ['hello' => 'hi']);  // 批量替换
trim($str);                       // 去首尾空白
ltrim($str, '/');                 // 去左侧指定字符
rtrim($str, ',');                 // 去右侧
```

### 格式化与转换

```php
strtoupper($str);               // 转大写（ASCII only）
strtolower($str);               // 转小写
ucfirst($str);                  // 首字母大写
lcfirst($str);                  // 首字母小写
ucwords($str);                  // 每个单词首字母大写
number_format(1234.56, 2);     // 1,234.56
nl2br($str);                    // \n → <br>
wordwrap($str, 80);             // 自动换行
```

### 分割与连接

```php
explode(',', $str);              // 字符串→数组
implode(',', $arr);              // 数组→字符串
str_split($str, 3);              // 按长度切割
chunk_split($str, 76, "\r\n");  // MIME编码用
str_word_count($str);            // 单词计数
```

### 安全与编码

```php
htmlspecialchars($str, ENT_QUOTES, 'UTF-8'); // HTML转义
htmlentities($str);               // 转义所有HTML实体
urlencode($str);                  // URL编码
urldecode($str);                  // URL解码
base64_encode($str);              // Base64编码
addslashes($str);                 // 转义引号（不推荐用于SQL）
```

## 多字节处理 mb_* 函数

处理中文、日文等多字节字符必须用`mb_*`系列：

```php
// strlen vs mb_strlen
$str = '你好世界';
echo strlen($str);     // 12（UTF-8每个中文字3字节）
echo mb_strlen($str);  // 4（字符数）✅

// 截取
echo substr($str, 0, 6);     // '你好'（可能截断字符！）
echo mb_substr($str, 0, 2);  // '你好' ✅

// 大小写（支持Unicode）
echo mb_strtoupper('hello 世界'); // HELLO 世界

// 查找
echo mb_strpos($str, '世界'); // 2

// 关键：设置内部编码
mb_internal_encoding('UTF-8');
```

### 必须设置的mbstring配置

```php
// php.ini 推荐
mbstring.language = UTF-8
mbstring.internal_encoding = UTF-8
mbstring.http_input = UTF-8
mbstring.http_output = UTF-8
mbstring.substitute_character = none
```

## 字符串与编码（UTF-8处理）

### UTF-8 编码常识

UTF-8是变长编码：ASCII字符占1字节，中文占3字节，emoji占4字节。

```php
// 验证UTF-8
function isValidUtf8(string $str): bool
{
    return mb_check_encoding($str, 'UTF-8');
}

// 安全截取（不会截断多字节字符）
function safeTruncate(string $str, int $length, string $suffix = '...'): string
{
    if (mb_strlen($str) <= $length) {
        return $str;
    }
    return mb_substr($str, 0, $length) . $suffix;
}

echo safeTruncate('这是一段很长的中文内容', 5); // 这是一段很...
```

$data = ['name' => '汉哥', 'msg' => '你好世界'];

## 代码示例

### 示例1：简易模板引擎

```php
<?php
class MiniTemplate
{
    public static function render(string $template, array $data): string
    {
        // {{ variable }} 替换
        $result = preg_replace_callback('/\{\{\s*(\w+)\s*\}\}/', function ($m) use ($data) {
            return htmlspecialchars((string)($data[$m[1]] ?? ''), ENT_QUOTES, 'UTF-8');
        }, $template);
        
        // {% if condition %} ... {% endif %} 简易条件
        $result = preg_replace_callback(
            '/\{%\s*if\s+(\w+)\s*%\}(.*?)\{%\s*endif\s*%\}/s',
            fn($m) => !empty($data[$m[1]]) ? $m[2] : '',
            $result
        );
        
        return $result;
    }
}

$tpl = 'Hello {{ name }}! {% if vip %}Welcome VIP!{% endif %}';
echo MiniTemplate::render($tpl, ['name' => '汉哥', 'vip' => true]);
// Hello 汉哥! Welcome VIP!
```

### 示例2：字符串工具函数集

```php
<?php
class StrUtil
{
    // 生成随机字符串
    public static function random(int $length = 32, string $chars = 'alnum'): string
    {
        $pool = match($chars) {
            'alpha'  => 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ',
            'alnum'  => '0123456789abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ',
            'digit'  => '0123456789',
            'hex'    => '0123456789abcdef',
            default  => $chars,
        };
        return substr(str_shuffle(str_repeat($pool, (int)ceil($length / strlen($pool)))), 0, $length);
    }
    
    // 驼峰转下划线
    public static function camelToSnake(string $str): string
    {
        return strtolower(preg_replace('/[A-Z]/', '_$0', lcfirst($str)));
    }
    
    // 下划线转驼峰
    public static function snakeToCamel(string $str): string
    {
        return lcfirst(str_replace('_', '', ucwords($str, '_')));
    }
    
    // 模糊匹配（高亮关键词）
    public static function highlight(string $text, string $keyword): string
    {
        if (empty($keyword)) return $text;
        $escaped = preg_quote($keyword, '/');
        return preg_replace("/({$escaped})/iu", '<mark>$1</mark>', $text);
    }
}

echo StrUtil::camelToSnake('getUserById');  // get_user_by_id
echo StrUtil::snakeToCamel('get_user_by_id'); // getUserById
echo StrUtil::highlight('PHP是最好的语言', 'PHP'); // <mark>PHP</mark>是最好的语言
```

### 示例3：安全输出与编码处理

```php
<?php
class SafeOutput
{
    // HTML安全输出
    public static function html(mixed $value): string
    {
        return htmlspecialchars((string)$value, ENT_QUOTES | ENT_HTML5, 'UTF-8');
    }
    
    // JavaScript安全输出
    public static function js(mixed $value): string
    {
        return json_encode($value, JSON_UNESCAPED_UNICODE | JSON_HEX_TAG | JSON_HEX_APOS);
    }
    
    // 属性安全输出
    public static function attr(string $value): string
    {
        return htmlspecialchars($value, ENT_QUOTES, 'UTF-8');
    }
}

// 模板中使用
$input = '<script>alert("xss")</script>';
echo '<div title="' . SafeOutput::attr($input) . '">';
echo SafeOutput::html($input);
// 输出: &lt;script&gt;alert(&quot;xss&quot;)&lt;/script&gt;
```

## 面试常见追问

**Q1: `strlen()`和`mb_strlen()`的区别？**
A: `strlen()`返回字节长度，`mb_strlen()`返回字符长度。UTF-8下中文一个字3字节，`strlen('你好')`返回6，`mb_strlen('你好')`返回2。处理用户输入的字符串长度限制时必须用`mb_strlen`。

**Q2: 单引号和双引号字符串哪个快？**
A: 理论上单引号略快（不需要解析转义序列和变量），但OPcache下差异几乎为零。以代码可读性为准：需要变量插值用双引号，纯文本用单引号。

**Q3: 如何正确截取中文字符串避免乱码？**
A: 使用`mb_substr()`而非`substr()`，并确保设置了`mb_internal_encoding('UTF-8')`。如果必须用`substr`，可以先用`mb_strcut`，它按字节截取但不会切断多字节字符。

**Q4: `htmlspecialchars`的参数应该怎么传？**
A: 推荐`htmlspecialchars($str, ENT_QUOTES | ENT_HTML5, 'UTF-8')`。默认的`ENT_COMPAT`不转义单引号，存在XSS风险。必须指定编码为UTF-8避免编码攻击。
