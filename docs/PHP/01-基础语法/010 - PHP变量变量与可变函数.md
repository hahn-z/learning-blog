---# PHP变量变量与可变函数

## 可变变量 `$$`

### 基本用法

```php
$name = 'hello';
$$name = 'world';

echo $hello;    // 'world'
echo $$name;    // 'world'
echo ${$name};  // 'world'（花括号形式，更清晰）
```

### 花括号消除歧义

```php
// 不用花括号可能有歧义
$$name[0];     // 是 ${$name}[0] 还是 ${$name[0]}？

// 明确写法
${$name}[0];   // $hello[0]
${$name . '_suffix'}; // $hello_suffix
```

### 实际应用：动态配置映射

```php
// 将配置数组映射为变量（类似extract）
$config = [
    'host' => 'localhost',
    'port' => 3306,
    'debug' => true,
];

foreach ($config as $key => $value) {
    ${$key} = $value;
}

echo $host;  // 'localhost'
echo $port;  // 3306
echo $debug; // true
```

### 注意：优先用数组而非可变变量

```php
// ❌ 不推荐：可变变量（不安全、难调试、IDE不支持）
foreach ($input as $key => $value) {
    $$key = $value; // 如果$key是'_SESSION'呢？
}

// ✅ 推荐：用数组
$config = [];
foreach ($input as $key => $value) {
    $config[$key] = $value;
}
```

## 可变函数 `$func()`

### 基本用法

```php
function hello(): string { return 'Hello'; }
function world(): string { return 'World'; }

$func = 'hello';
echo $func(); // 'Hello'

$func = 'world';
echo $func(); // 'World'
```

### 对象方法调用

```php
class UserController
{
    public function list(): string { return 'user list'; }
    public function show(): string { return 'user detail'; }
}

$controller = new UserController();
$action = 'list';
echo $controller->$action(); // 'user list'

// 静态方法
$method = 'show';
echo UserController::$method(); // 也支持
```

### 可变函数的限制

```php
// 不能用于语言结构
$func = 'echo';
$func('hello'); // ❌ Fatal error: echo是语言结构不是函数

// 以下语言结构都不能通过可变函数调用：
// echo, print, isset, empty, unset, eval, list, die, exit
```

## call_user_func / call_user_func_array

### 基本用法

```php
// call_user_func — 调用回调函数
function greet(string $name): string
{
    return "Hello, $name!";
}

echo call_user_func('greet', 'Hahn'); // 'Hello, Hahn!'

// call_user_func_array — 参数以数组传递
function add(int $a, int $b, int $c): int
{
    return $a + $b + $c;
}

echo call_user_func_array('add', [1, 2, 3]); // 6
```

### 各种回调形式

```php
class Math
{
    public static function square(int $n): int { return $n * $n; }
    public function cube(int $n): int { return $n * $n * $n; }
}

// 1. 函数名
call_user_func('greet', 'Hahn');

// 2. 静态方法（字符串形式）
call_user_func('Math::square', 5); // 25

// 3. 静态方法（数组形式）
call_user_func([Math::class, 'square'], 5); // 25

// 4. 实例方法
$math = new Math();
call_user_func([$math, 'cube'], 3); // 27

// 5. 闭包
call_user_func(fn($n) => $n * 10, 5); // 50

// 6. __invoke对象
class Multiplier
{
    public function __construct(private int $factor) {}
    public function __invoke(int $n): int { return $n * $this->factor; }
}
call_user_func(new Multiplier(3), 5); // 15
```

### 可变参数展开（PHP 5.6+）

```php
// 现代 PHP 更推荐用 ... 展开运算符
$args = [1, 2, 3];

// 旧写法
call_user_func_array('add', $args);

// 新写法（更清晰）
add(...$args);
```

## 动态创建函数

### create_function（已废弃）

```php
// PHP 7.2废弃，PHP 8.0移除
$func = create_function('$x', 'return $x * 2;');
echo $func(5); // 10

// 本质是eval，不安全且性能差
```

### Closure（推荐）

```php
// 匿名函数/闭包
$double = function (int $x): int {
    return $x * 2;
};
echo $double(5); // 10

// 箭头函数（PHP 7.4+）
$double = fn(int $x): int => $x * 2;
echo $double(5); // 10

// 闭包捕获变量
$factor = 3;
$multiply = fn(int $x): int => $x * $factor; // 自动捕获$factor

// 手动绑定作用域
$factor = 3;
$multiply = function (int $x) use ($factor): int {
    return $x * $factor;
};

// Closure::fromCallable — 将命名函数转为闭包
$callable = Closure::fromCallable('strlen');
echo $callable('hello'); // 5
```

### Closure::bind — 绑定$this和作用域

```php
class Secret
{
    private string $data = 'classified';
}

$secret = new Secret();

// 绑定闭包到对象实例，访问私有属性
$getSecret = Closure::bind(function (): string {
    return $this->data;
}, $secret, Secret::class);

echo $getSecret(); // 'classified'
```

## 代码示例

### 示例1：动态路由实现

```php
<?php
declare(strict_types=1);

class Router
{
    private array $routes = [];
    
    // 注册路由
    public function addRoute(string $method, string $path, callable|array $handler): void
    {
        $this->routes[strtoupper($method) . ':' . $path] = $handler;
    }
    
    // 快捷方法
    public function get(string $path, callable|array $handler): void
    {
        $this->addRoute('GET', $path, $handler);
    }
    
    public function post(string $path, callable|array $handler): void
    {
        $this->addRoute('POST', $path, $handler);
    }
    
    // 分发请求
    public function dispatch(string $method, string $path): mixed
    {
        $key = strtoupper($method) . ':' . $path;
        
        if (!isset($this->routes[$key])) {
            http_response_code(404);
            return ['error' => 'Not Found'];
        }
        
        $handler = $this->routes[$key];
        
        // 数组形式 [Controller::class, 'method'] 或 [$instance, 'method']
        if (is_array($handler)) {
            [$controller, $action] = $handler;
            
            if (is_string($controller)) {
                $controller = new $controller();
            }
            
            if (!method_exists($controller, $action)) {
                throw new RuntimeException("Method $action not found");
            }
            
            return $controller->$action();
        }
        
        // 闭包形式
        return $handler();
    }
}

// 使用
$router = new Router();

// 闭包路由
$router->get('/', fn() => ['message' => 'Welcome']);

// 控制器路由
$router->get('/users', [UserController::class, 'list']);
$router->post('/users', [UserController::class, 'create']);
$router->get('/users/profile', [UserController::class, 'profile']);

// 分发
$result = $router->dispatch('GET', '/users');
```

### 示例2：插件机制

```php
<?php
declare(strict_types=1);

class PluginManager
{
    private array $hooks = [];
    
    // 注册钩子
    public function registerHook(string $hookName, callable $callback, int $priority = 10): void
    {
        $this->hooks[$hookName][] = [
            'callback' => $callback,
            'priority' => $priority,
        ];
    }
    
    // 触发钩子
    public function trigger(string $hookName, mixed $payload = null): mixed
    {
        if (!isset($this->hooks[$hookName])) {
            return $payload;
        }
        
        // 按优先级排序
        $callbacks = $this->hooks[$hookName];
        usort($callbacks, fn($a, $b) => $a['priority'] <=> $b['priority']);
        
        // 链式执行
        foreach ($callbacks as $hook) {
            $payload = call_user_func($hook['callback'], $payload);
        }
        
        return $payload;
    }
    
    // 从目录加载插件
    public function loadPlugins(string $dir): void
    {
        foreach (glob($dir . '/*.php') as $file) {
            $plugin = require $file;
            if (is_callable($plugin)) {
                $plugin($this);
            }
        }
    }
}

// 插件文件：plugins/seo.php
return function (PluginManager $pm): void {
    $pm->registerHook('page_title', function (?string $title): string {
        return ($title ?? 'MyApp') . ' | MyApp';
    }, priority: 10);
    
    $pm->registerHook('page_title', function (string $title): string {
        // 添加SEO后缀（优先级更低，后执行）
        return $title . ' - 最佳PHP教程';
    }, priority: 20);
};

// 使用
$pm = new PluginManager();
$pm->loadPlugins('plugins');
$title = $pm->trigger('page_title', 'PHP教程');
// "PHP教程 | MyApp - 最佳PHP教程"
```

### 示例3：策略模式动态选择

```php
<?php
declare(strict_types=1);

interface PaymentStrategy
{
    public function pay(float $amount): array;
}

class AlipayStrategy implements PaymentStrategy
{
    public function pay(float $amount): array
    {
        return ['method' => 'alipay', 'amount' => $amount, 'status' => 'success'];
    }
}

class WechatPayStrategy implements PaymentStrategy
{
    public function pay(float $amount): array
    {
        return ['method' => 'wechat', 'amount' => $amount, 'status' => 'success'];
    }
}

class PaymentFactory
{
    private static array $strategies = [];
    
    public static function register(string $name, string $class): void
    {
        self::$strategies[$name] = $class;
    }
    
    public static function create(string $name): PaymentStrategy
    {
        if (!isset(self::$strategies[$name])) {
            throw new InvalidArgumentException("Unknown payment method: $name");
        }
        
        $class = self::$strategies[$name];
        return new $class();
    }
}

// 注册策略
PaymentFactory::register('alipay', AlipayStrategy::class);
PaymentFactory::register('wechat', WechatPayStrategy::class);

// 动态选择（可变函数+工厂模式）
$method = $_POST['payment_method'] ?? 'alipay';
$payment = PaymentFactory::create($method);
$result = $payment->pay(99.9);
```

## 面试常见追问

**Q1: `$$`可变变量有什么安全风险？**
A: 用户输入可能覆盖超全局变量或已有变量。如`$$key`中`$key`来自用户输入`_SERVER`，就会覆盖`$_SERVER`。**永远不要对用户输入用可变变量**，用数组代替。

**Q2: 可变函数和`call_user_func`哪个好？**
A: 现代 PHP 中，直接用`$func()`更清晰更快。`call_user_func_array`的主要用途是动态参数列表，但 PHP 5.6+的`...`展开运算符已经替代了这个需求。`call_user_func`在需要传递回调作为参数时仍有价值。

**Q3: `create_function`为什么被废弃？**
A: 三个原因：1）本质是`eval()`，存在代码注入风险；2）性能差（每次调用都解析字符串）；3）闭包（Closure）提供了更好的替代方案。PHP 8.0已移除此函数。

**Q4: 如何安全地实现动态方法调用？**
A: 使用白名单过滤方法名：

```php
$allowed = ['list', 'show', 'create'];
$action = $_GET['action'] ?? 'list';
if (!in_array($action, $allowed, true)) {
    throw new RuntimeException('Invalid action');
}
$controller->$action(); // 安全
```

---

_动态特性是PHP的强大武器，但越灵活越需要安全意识。白名单优于黑名单，数组优于可变变量。_
