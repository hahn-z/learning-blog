# PHP 8.x新特性完全指南

## PHP 8.0 — 里程碑版本

### JIT编译器（Just-In-Time）

JIT将热点代码在运行时编译为机器码，直接执行而不经过VM解释。

```php
// php.ini 配置
// opcache.jit=1255      // 推荐配置
// opcache.jit_buffer_size=64M

// JIT对纯计算密集型任务提升显著
function mandelbrot(int $width, int $height): array
{
    $result = [];
    for ($y = 0; $y < $height; $y++) {
        for ($x = 0; $x < $width; $x++) {
            $cx = ($x - $width / 2) / ($width / 4);
            $cy = ($y - $height / 2) / ($height / 4);
            $zx = $zy = 0;
            $iter = 0;
            while ($zx * $zx + $zy * $zy < 4 && $iter < 255) {
                $tmp = $zx * $zx - $zy * $zy + $cx;
                $zy = 2 * $zx * $zy + $cy;
                $zx = $tmp;
                $iter++;
            }
            $result[$y][$x] = $iter;
        }
    }
    return $result;
}
```

**注意：** JIT对Web应用（I/O密集）提升有限（约0-5%），对CLI脚本/计算密集型提升明显（20-200%）。

```php
{
```

```php
    public function __construct(public string $name) {}
}

{
    #[Route('/api/users', method: 'GET')]
    #[Middleware('auth')]

// 通过反射读取
```


### Nullsafe运算符

```php
// PHP 7 — 繁琐的null检查
$country = null;
if ($session !== null) {
    $user = $session->user;
    if ($user !== null) {
        $address = $user->address;
        if ($address !== null) {
            $country = $address->country;
        }
    }
}

// PHP 8 — Nullsafe
$country = $session?->user?->address?->country;
// 链中任何一环为null，整个表达式返回null
```

## PHP 8.1 — 枚举与Fiber

### 枚举（Enum）

```php
enum Status: string
{
    case Active = 'active';
    case Inactive = 'inactive';
    case Pending = 'pending';
    
    public function badge(): string
    {
        return match ($this) {
            self::Active => '🟢',
            self::Inactive => '🔴',
            self::Pending => '🟡',
        };
    }
}

$status = Status::Active;
echo $status->value;  // 'active'
echo $status->badge(); // 🟢
echo Status::from('active'); // Status::Active
echo Status::tryFrom('unknown'); // null
```

### Fiber

```php
$fiber = new Fiber(function (): void {
    $value = Fiber::suspend('fiber started');
    echo "Fiber received: $value\n";
    Fiber::suspend('fiber resumed');
});

$result = $fiber->start();     // 'fiber started'
$fiber->resume('hello');       // 打印 "Fiber received: hello"，挂起返回 'fiber resumed'
$fiber->resume();              // Fiber结束
```

## 面试常见追问

**Q1: JIT什么时候应该开启？**
A: CLI脚本、计算密集型任务（图像处理、数学计算、AI推理）建议开启。普通Web应用（I/O密集、数据库查询为主）开启JIT提升有限，甚至可能因JIT编译开销略降性能。配置建议：`opcache.jit=1255`。

**Q2: readonly属性和构造函数属性提升结合有什么好处？**
A: 可以一行代码声明、初始化和设置不可变属性。`public readonly int $id` 替代了传统的声明、构造函数赋值、getter三个部分。DTO/值对象变得极其简洁。

**Q3: 属性（Attribute）有什么实际应用场景？**
A: 路由定义、依赖注入标注、ORM映射、验证规则、序列化配置、中间件绑定等。框架广泛使用：Symfony Route、Doctrine ORM、Laravel验证规则等。

**Q4: Fiber和Generator的区别？**
A: Generator是单方向的（只能yield暂停、resume继续），Fiber是真正的协程——可以从任意位置暂停和恢复，支持双向通信。Fiber是异步编程的底层基础，但通常不直接使用，而是通过Swoole/ReactPHP等框架。
