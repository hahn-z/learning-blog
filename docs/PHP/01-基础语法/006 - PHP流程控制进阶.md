---# PHP流程控制进阶

## match表达式（PHP 8）vs switch

### switch的传统写法

```php
$status = 200;

switch ($status) {
    case 200:
        $message = 'OK';
        break;  // 必须break，否则贯穿
    case 404:
        $message = 'Not Found';
        break;
    default:
        $message = 'Unknown';
}
```

### match表达式（PHP 8+）

```php
$message = match ($status) {
    200 => 'OK',
    301, 302 => 'Redirect',  // 多值匹配
    404 => 'Not Found',
    500, 502, 503 => 'Server Error',
    default => 'Unknown',
};
```

### 关键区别

| 特性 | switch | match |
|------|--------|-------|
| 返回值 | 无（是语句） | 有（是表达式） |
| 比较方式 | `==`（松散） | `===`（严格） |
| 贯穿 | 需要`break`防止 | 不会贯穿 |
| 未匹配 | 静默跳过 | 抛出`UnhandledMatchError` |
| 多值匹配 | 多个case | 逗号分隔 |

```php
// match的严格比较
$value = '1';
$result = match ($value) {
    1 => 'integer one',  // 不匹配！'1' !== 1
    '1' => 'string one', // 匹配
};
```

### match的条件表达式用法

```php
$grade = 85;

$result = match (true) {
    $grade >= 90 => 'A',
    $grade >= 80 => 'B',
    $grade >= 70 => 'C',
    $grade >= 60 => 'D',
    default => 'F',
};
// $result = 'B'
```

## 生成器基础（yield）

### 基本用法

```php
function rangeGenerator(int $start, int $end): Generator
{
    for ($i = $start; $i <= $end; $i++) {
        yield $i;
    }
}

foreach (rangeGenerator(1, 1000000) as $num) {
    // 内存占用恒定！不会创建100万元素的数组
    if ($num > 10) break;
}
```

### yield key => value

```php
function csvReader(string $file): Generator
{
    $handle = fopen($file, 'r');
    $headers = fgetcsv($handle);
    
    while ($row = fgetcsv($handle)) {
        yield array_combine($headers, $row);
    }
    fclose($handle);
}

foreach (csvReader('large_file.csv') as $line => $record) {
    // 逐行读取，不占大量内存
}
```

### yield from 委托生成器

```php
function innerGen(): Generator
{
    yield 1;
    yield 2;
}

function outerGen(): Generator
{
    yield 'start';
    yield from innerGen(); // 委托给子生成器
    yield 'end';
}

// start, 1, 2, end
```

### 生成器发送值（双向通信）

```php
function logger(): Generator
{
    while (true) {
        $message = yield;
        echo "[" . date('H:i:s') . "] $message\n";
    }
}

$log = logger();
$log->send('Application started'); // 向生成器发送值
$log->send('Processing...');
```

### 生成器返回值

```php
function pipeline(): Generator
{
    $total = 0;
    for ($i = 1; $i <= 100; $i++) {
        $total += $i;
        yield $i;
    }
    return $total; // 生成器的返回值
}

$gen = pipeline();
foreach ($gen as $value) { /* ... */ }
echo $gen->getReturn(); // 5050
```

## goto的使用场景与禁忌

### 基本语法

```php
goto label;
// ...
label:
echo 'Jumped here!';
```

### 合理使用场景：嵌套循环跳出

```php
// 在多层嵌套循环中，goto比break+flag更清晰
foreach ($matrix as $row) {
    foreach ($row as $cell) {
        if ($cell === $target) {
            goto found;
        }
    }
}
found:
echo "Found at some position";
```

### 禁忌

1. **不能跨函数跳转**
2. **不能跳入循环或switch**
3. **不能跳过类声明**
4. 不能用于替代正常的控制流

```php
// ❌ 错误：不能跳入循环
goto inside;
for ($i = 0; $i < 10; $i++) {
    inside:
    echo $i;
}
```

## 代码示例

### 示例1：状态机实现

```php
<?php
enum OrderState: string
{
    case Created = 'created';
    case Paid = 'paid';
    case Shipped = 'shipped';
    case Completed = 'completed';
    case Cancelled = 'cancelled';
    
    public function canTransitionTo(self $next): bool
    {
        return match ($this) {
            self::Created   => in_array($next, [self::Paid, self::Cancelled]),
            self::Paid      => in_array($next, [self::Shipped, self::Cancelled]),
            self::Shipped   => $next === self::Completed,
            self::Completed, self::Cancelled => false,
        };
    }
}

// 使用
$state = OrderState::Created;
echo $state->canTransitionTo(OrderState::Paid);      // true
echo $state->canTransitionTo(OrderState::Shipped);    // false
```

### 示例2：生成器Pipeline

```php
<?php
// 函数式数据处理管道
function filter(Generator $gen, callable $fn): Generator
{
    foreach ($gen as $key => $value) {
        if ($fn($value, $key)) {
            yield $key => $value;
        }
    }
}

function map(Generator $gen, callable $fn): Generator
{
    foreach ($gen as $key => $value) {
        yield $key => $fn($value, $key);
    }
}

function take(Generator $gen, int $n): Generator
{
    $count = 0;
    foreach ($gen as $key => $value) {
        if ($count++ >= $n) break;
        yield $key => $value;
    }
}

// 数据源：无限序列
function fibonacci(): Generator
{
    $a = 0;
    $b = 1;
    while (true) {
        yield $a;
        [$a, $b] = [$b, $a + $b];
    }
}

// 组合管道：取前20个偶数斐波那契数，每个平方
$result = take(
    map(
        filter(fibonacci(), fn($n) => $n % 2 === 0),
        fn($n) => $n * $n
    ),
    10
);

foreach ($result as $value) {
    echo $value . ' ';
}
// 0 4 64 1444 20736 ...
```

### 示例3：高级match用法

```php
<?php
// HTTP路由匹配
function matchRoute(string $method, string $path): array
{
    return match (true) {
        $method === 'GET' && $path === '/' => ['controller' => 'Home', 'action' => 'index'],
        $method === 'GET' && preg_match('#^/user/(\d+)$#', $path, $m) => ['controller' => 'User', 'action' => 'show', 'id' => $m[1]],
        $method === 'POST' && $path === '/user' => ['controller' => 'User', 'action' => 'create'],
        $method === 'GET' && preg_match('#^/api/(.+)$#', $path, $m) => ['controller' => 'Api', 'path' => $m[1]],
        default => ['controller' => 'Error', 'action' => 'notFound'],
    };
}
```

## 面试常见追问

**Q1: match和switch的适用场景？**
A: match适合**值映射**（一个输入对应一个输出），switch适合**执行多行逻辑**。match是表达式可以赋值，switch是语句。match自动严格比较且不会贯穿，更安全。

**Q2: 生成器的内存优势具体有多大？**
A: 处理100万行CSV文件，`file()`加载到数组约需200MB+，而生成器逐行读取只需要几KB。生成器本质是在暂停和恢复间切换执行上下文，不需要保存所有数据。

**Q3: Generator实现了哪些接口？**
A: `Generator`实现了`Iterator`接口（`current()`, `key()`, `next()`, `rewind()`, `valid()`），所以可以在任何接受`iterable`的地方使用。但注意`rewind()`只能调用一次（生成器不可回退）。

**Q4: 为什么说goto是有害的？**
A: 滥用goto会导致"面条代码"——执行流跳来跳去，难以追踪逻辑。但跳出多层嵌套循环是goto公认的合理场景，比用flag变量更清晰。原则：**可以跳出去，不能跳进来**。
