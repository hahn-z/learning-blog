# PHP运算符与类型比较

## 运算符优先级表（从高到低）

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1（最高） | `clone new` | 创建对象 |
| 2 | `**` | 幂运算（右结合） |
| 3 | `++` `--` `(int)` `(float)` `(string)` `(array)` `(object)` `(bool)` `@` | 单目/类型转换/错误抑制 |
| 4 | `instanceof` | 类型检查 |
| 5 | `!` | 逻辑非 |
| 6 | `*` `/` `%` | 乘除取模 |
| 7 | `+` `-` `.` | 加减字符串连接 |
| 8 | `<<` `>>` | 位移 |
| 9 | `<` `<=` `>` `>=` | 比较 |
| 10 | `==` `!=` `===` `!==` `<>` `<=>` | 相等比较 |
| 11 | `&` | 按位与 / 引用 |
| 12 | `^` | 按位异或 |
| 13 | `\|` | 按位或 |
| 14 | `&&` | 逻辑与（短路） |
| 15 | `\|\|` | 逻辑或（短路） |
| 16 | `??` | null合并 |
| 17 | `?.` | null安全（PHP 8） |
| 18 | `? :` | 三元（左结合！） |
| 19 | `=` `+=` `-=` `.=` 等 | 赋值（右结合） |
| 20 | `yield` `yield from` | 生成器 |
| 21 | `and` | 低优先级逻辑与 |
| 22 | `xor` | 低优先级逻辑异或 |
| 23 | `or` | 低优先级逻辑或 |
| 24（最低） | `,` | 逗号 |

**易错点：** `and`/`or`的优先级比`=`还低！

```php
$result = true and false;
// 等价于 ($result = true) and false;
// $result = true ❌ 不是预期的 false

$result = (true and false);
// $result = false ✅
```

## 松散比较 `==` 真值表（重点难点）

```php
// 以下全为 true（容易出bug的case）
0 == false
'' == false
'0' == false
null == false
[] == false
0 == 'php'        // 字符串转数字→0
'0e999' == '0e1'  // 都解释为0的科学技术法
false == '0'
null == ''
null == []
```

**PHP 8的重要变化：**

| 比较 | PHP 7 | PHP 8 |
|------|-------|-------|
| `0 == ''` | `true` | `false` |
| `0 == 'foo'` | `true` | `true`（保持） |
| `'' == null` | `true` | `true`（保持） |
| `'0' == null` | `true` | `false` |
| `[] == null` | `true` | `true`（保持） |

PHP 8的规则：数字与字符串比较时，如果字符串是**数字字符串**则转数字比较，否则将**数字转字符串**做字符串比较。

## 三元运算符的结合方向

**PHP中三元运算符是左结合的**（这与其他语言不同！）

```php
// 左结合导致的问题
$x = 1;
echo $x == 1 ? 'one' : $x == 2 ? 'two' : 'other';
// PHP解析为：(($x == 1 ? 'one' : $x == 2) ? 'two' : 'other')
// 结果：'two'  ❌ 不是预期的 'one'

// 正确写法：加括号
echo ($x == 1) ? 'one' : (($x == 2) ? 'two' : 'other');
// 结果：'one' ✅

// PHP 8.4+ 嵌套三元不加括号会报 deprecated warning
```

## 太空船运算符 `<=>` 与 null合并 `??`

### `<=>` 太空船运算符（PHP 7+）

```php
// 返回 -1, 0, 1
1 <=> 2;    // -1
2 <=> 1;    // 1
1 <=> 1;    // 0

// 排序利器
$users = [['name' => 'Bob', 'age' => 30], ['name' => 'Alice', 'age' => 25]];
usort($users, fn($a, $b) => $a['age'] <=> $b['age']);
```

### `??` null合并运算符（PHP 7+）

```php
// 链式使用
$name = $_GET['name'] ?? $_POST['name'] ?? 'Guest';

// 区别于 ?:
$a = 0;
$b = $a ?? 'default';  // '0' - 只检查null
$c = $a ?: 'default';  // 'default' - 检查所有falsy值
```

## 代码示例

### 示例1：经典比较陷阱

```php
<?php
// 密码比较漏洞（松散比较导致安全问题）
$expected = '0e123456789';
$input    = '0e987654321';

if ($expected == $input) {
    echo "登录成功！"; // 会执行！两个都是0的科学技术法
}

// 正确做法
if (hash_equals($expected, $input)) {
    echo "安全比较";
}

// JSON解析陷阱
$json = '{"is_admin": true}';
$data = json_decode($json, true);
if ($data['is_admin'] == 'yes') { // true == 'yes' → true
    echo "管理员"; // 会执行！
}
```

### 示例2：优先级坑

```php
<?php
// 坑1：and/or vs &&/||
$canAccess = $isAdmin = true and false;
var_dump($canAccess); // true - and比=优先级低

// 坑2：字符串连接 vs 加法
echo '1' + '2' . '3'; // '33' - 先算1+2=3，再连接'3'
echo '1' . ('2' + '3'); // '15' - 先算2+3=5，再连接

// 坑3：位运算优先级
if ($flags & 0x01 == 0x01) { /* ... */ }
// 等价于 $flags & (0x01 == 0x01) → $flags & true → $flags & 1
// 看似正确但逻辑不同！应该：
if (($flags & 0x01) === 0x01) { /* ... */ }
```

### 示例3：综合类型比较工具

```php
<?php

/**
 * 安全比较函数集合
 */
function safeEquals(mixed $a, mixed $b): bool
{
    return $a === $b;
}

function compareWithCoercion(mixed $a, mixed $b): int
{
    return $a <=> $b;
}

// 展示所有比较结果
function showComparison(mixed $a, mixed $b): void
{
    $loose = var_export($a == $b, true);
    $strict = var_export($a === $b, true);
    $spaceship = match($a <=> $b) {
        -1 => 'less',
        0 => 'equal',
        1 => 'greater',
    };
    
    printf("==: %-5s  ===: %-5s  <=>: %s\n", $loose, $strict, $spaceship);
}

// 测试
$pairs = [
    [0, false],
    [0, ''],
    [0, '0'],
    [null, ''],
    [null, []],
    [false, []],
    ['0e100', '0e200'],
];

foreach ($pairs as [$a, $b]) {
    echo str_pad(json_encode($a) . ' vs ' . json_encode($b), 30);
    showComparison($a, $b);
}
```

## 面试常见追问

**Q1: `??`和`?:`的区别？**
A: `??`只检查`null`，`?:`检查所有falsy值（`0`、`""`、`false`、`null`、`[]`）。`$a ?? 'b'`等价于`isset($a) ? $a : 'b'`，不会对未定义变量报warning。

**Q2: 为什么`'0e123' == '0e456'`是true？**
A: PHP在做字符串比较时，如果两边都是**数字字符串**（numeric string），会转为数字比较。`'0e123'`被解析为`0 × 10^123 = 0`，所以两个都是0。这是MD5碰撞攻击的理论基础——找两个MD5值都以`0e`开头的字符串即可绕过`==`比较。

**Q3: PHP 8对比较行为做了哪些改变？**
A: 核心改变在数字与字符串比较：PHP 7中字符串总转为数字；PHP 8中，当字符串是纯非数字字符串时（如`"foo"`），数字转字符串做字符串比较。`0 == "foo"`仍是true（`"foo"`转0），但`0 == ""`变成false（`""`不再是数字字符串）。
