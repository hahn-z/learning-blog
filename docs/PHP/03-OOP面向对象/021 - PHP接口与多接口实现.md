# PHP接口与多接口实现

接口是 OOP 中"契约编程"的核心机制。PHP 的接口比 Java/C# 更灵活——支持默认方法（PHP 8+）、多接口实现、以及与 Trait 配合使用。

## 接口基础

```php
<?php
interface Renderable
{
    // 所有方法默认 public
    public function render(): string;
}

interface Loggable
{
    public function log(string $message): void;
    public function getLogLevel(): string;
}

class HtmlReport implements Renderable, Loggable
{
    public function __construct(
        private string $content,
        private string $logLevel = 'info',
    ) {}

    public function render(): string
    {
        return "<div>{$this->content}</div>";
    }

    public function log(string $message): void
    {
        echo "[{$this->logLevel}] $message\n";
    }

    public function getLogLevel(): string
    {
        return $this->logLevel;
    }
}
```

**接口可以包含：** 公共抽象方法、公共常量。PHP 8.0+ 接口可以包含 `public function method(): void;` 签名，PHP 8.1+ 支持 带默认实现的方法。

## 接口中的常量

```php
<?php
interface CacheInterface
{
    public const DEFAULT_TTL = 3600;

    public function get(string $key): mixed;
    public function set(string $key, mixed $value, ?int $ttl = null): bool;
    public function delete(string $key): bool;
}

class RedisCache implements CacheInterface
{
    public function get(string $key): mixed { /* ... */ }
    public function set(string $key, mixed $value, ?int $ttl = null): bool
    {
        $ttl ??= self::DEFAULT_TTL; // 使用接口常量
        // ...
        return true;
    }
    public function delete(string $key): bool { /* ... */ }
}

echo CacheInterface::DEFAULT_TTL; // 3600
```

## 契约编程实战

```php
<?php
// 定义存储契约
interface StorageDriver
{
    public function read(string $path): string;
    public function write(string $path, string $content): bool;
    public function exists(string $path): bool;
    public function delete(string $path): bool;
}

// 本地文件实现
class LocalStorage implements StorageDriver
{
    public function __construct(private string $basePath) {}

    public function read(string $path): string
    {
        return file_get_contents($this->basePath . '/' . $path);
    }

    public function write(string $path, string $content): bool
    {
        return file_put_contents($this->basePath . '/' . $path, $content) !== false;
    }

    public function exists(string $path): bool
    {
        return file_exists($this->basePath . '/' . $path);
    }

    public function delete(string $path): bool
    {
        return unlink($this->basePath . '/' . $path);
    }
}

// S3 实现
class S3Storage implements StorageDriver
{
    public function __construct(
        private string $bucket,
        private S3Client $client,
    ) {}

    public function read(string $path): string
    {
        return $this->client->getObject($this->bucket, $path);
    }
    // ... 其他方法实现
}

// 依赖接口而非具体实现
class DocumentService
{
    public function __construct(
        private StorageDriver $storage, // 依赖接口
    ) {}

    public function saveDocument(string $name, string $content): bool
    {
        return $this->storage->write("docs/$name", $content);
    }
}

// 可以轻松切换实现
$service = new DocumentService(new LocalStorage('/data'));
$service = new DocumentService(new S3Storage('my-bucket', $s3Client));
```

## 多态实现

```php
<?php
interface Sortable
{
    public function sort(array $items): array;
}

class BubbleSort implements Sortable { /* ... */ }
class QuickSort implements Sortable { /* ... */ }
class MergeSort implements Sortable { /* ... */ }

class SortManager
{
    public function __construct(private Sortable $strategy) {}

    public function execute(array $data): array
    {
        return $this->strategy->sort($data);
    }

    // 运行时切换策略
    public function setStrategy(Sortable $strategy): void
    {
        $this->strategy = $strategy;
    }
}

$manager = new SortManager(new QuickSort());
$sorted = $manager->execute([3, 1, 4, 1, 5]);
$manager->setStrategy(new MergeSort()); // 切换策略
```

## 接口 vs 抽象类选择指南

| 维度 | 接口 | 抽象类 |
|------|------|--------|
| 继承数量 | 实现多个 | 只继承一个 |
| 属性 | 只能有常量 | 可以有属性 |
| 方法实现 | PHP 8.1+ 可有默认方法 | 可以有具体方法 |
| 构造函数 | 不能有 | 可以有 |
| 关系 | "can-do" 能力 | "is-a" 关系 |
| 适用场景 | 定义行为契约 | 共享状态和实现 |

**决策原则：**
- 需要共享代码（属性、具体方法）→ 抽象类
- 定义能力/行为契约 → 接口
- 类已经有父类 → 只能用接口
- 不确定 → 先用接口（更灵活）

```php
<?php
// 抽象类提供共享状态，接口定义能力
abstract class Vehicle
{
    public function __construct(
        protected string $brand,
        protected float $speed = 0,
    ) {}

    public function accelerate(float $delta): void
    {
        $this->speed += $delta;
    }
}

interface Flyable
{
    public function takeOff(): void;
    public function land(): void;
}

interface Sailable
{
    public function anchor(): void;
}

class FlyingCar extends Vehicle implements Flyable, Sailable
{
    public function takeOff(): void { $this->speed = 200; }
    public function land(): void { $this->speed = 0; }
    public function anchor(): void { /* ... */ }
}
```

## 面试常见追问

**Q: 接口能继承接口吗？**

A: 可以，而且支持多继承。`interface C extends A, B {}` 要求实现 C 的类必须实现 A、B、C 的所有方法。这在设计分层接口时很有用。

**Q: PHP 8.1 的枚举（Enum）和接口有什么关系？**

A: Enum 可以实现接口。例如 `enum Status implements Renderable { case Active; case Inactive; public function render(): string { ... } }`。这让枚举既能参与多态，又保持类型安全。

**Q: 接口的方法签名必须和实现完全一致吗？**

A: 返回类型可以协变（收窄），参数类型可以逆变（放宽）。实现类可以给参数加默认值。但方法名、访问修饰符（必须 public）不能改变。

**Q: 为什么推荐"面向接口编程"？**

A: (1) 解耦——依赖抽象而非具体实现；(2) 可测试——Mock 接口比 Mock 具体类容易；(3) 可扩展——新增实现不影响已有代码（开闭原则）。

## 小结

接口是 PHP OOP 中实现多态和契约编程的核心工具。一个类只能继承一个父类，但可以实现多个接口。优先用接口定义行为契约，用抽象类共享状态和实现，两者配合使用是最佳实践。
