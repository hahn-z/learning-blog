---# PHP创建型设计模式

创建型模式关注对象的创建机制，将对象创建与使用解耦。PHP 中常用的创建型模式有：单例、工厂方法、抽象工厂、建造者、原型。

## 单例模式（Singleton）

确保一个类只有一个实例，并提供全局访问点。

```php
<?php
class Database
{
    private static ?self $instance = null;

    private function __construct(
        private string $dsn,
        private string $user = '',
        private string $pass = '',
    ) {
        echo "Connected to $dsn\n";
    }

    // 禁止克隆和反序列化
    private function __clone() {}
    private function __wakeup(): void {}

    public static function getInstance(string $dsn = '', string $user = '', string $pass = ''): static
    {
        return self::$instance ??= new static($dsn, $user, $pass);
    }
}

$db1 = Database::getInstance('mysql:host=localhost');
$db2 = Database::getInstance('mysql:host=localhost');
var_dump($db1 === $db2); // true
```

**线程安全：** PHP 是单线程的（传统 PHP-FPM 模式），不存在多线程竞态问题。但 Swoole/ReactPHP 等常驻内存环境下需要注意——每个 Worker 进程有独立实例。

**单例的争议：** 引入全局状态，难以测试（无法 Mock），违反单一职责。现代框架更倾向于用 DI 容器管理单例（如 Laravel 的 `singleton()` 绑定）。

## 工厂方法（Factory Method）

定义创建对象的接口，让子类决定实例化哪个类。

```php
<?php
abstract class Notification
{
    abstract public function send(string $message): void;
}

class EmailNotification extends Notification
{
    public function send(string $message): void
    {
        echo "Email: $message\n";
    }
}

class SmsNotification extends Notification
{
    public function send(string $message): void
    {
        echo "SMS: $message\n";
    }
}

abstract class NotificationFactory
{
    abstract public function createNotification(): Notification;

    public function notify(string $message): void
    {
        $notification = $this->createNotification();
        $notification->send($message);
    }
}

class EmailFactory extends NotificationFactory
{
    public function createNotification(): Notification
    {
        return new EmailNotification();
    }
}

class SmsFactory extends NotificationFactory
{
    public function createNotification(): Notification
    {
        return new SmsNotification();
    }
}

(new EmailFactory())->notify('Welcome!');
(new SmsFactory())->notify('Your code is 1234');
```

## 抽象工厂（Abstract Factory）

创建一系列相关对象的接口，而不指定具体类。

```php
<?php
interface UIComponentFactory
{
    public function createButton(): Button;
    public function createInput(): Input;
}

interface Button
{
    public function render(): string;
}

interface Input
{
    public function render(): string;
}

// Dark 主题系列
class DarkButton implements Button
{
    public function render(): string { return '<button class="dark-btn">Click</button>'; }
}

class DarkInput implements Input
{
    public function render(): string { return '<input class="dark-input" />'; }
}

class DarkUIFactory implements UIComponentFactory
{
    public function createButton(): Button { return new DarkButton(); }
    public function createInput(): Input { return new DarkInput(); }
}

// Light 主题系列
class LightButton implements Button
{
    public function render(): string { return '<button class="light-btn">Click</button>'; }
}

class LightInput implements Input
{
    public function render(): string { return '<input class="light-input" />'; }
}

class LightUIFactory implements UIComponentFactory
{
    public function createButton(): Button { return new LightButton(); }
    public function createInput(): Input { return new LightInput(); }
}

// 使用
function buildForm(UIComponentFactory $factory): string
{
    return $factory->createButton()->render() . $factory->createInput()->render();
}

echo buildForm(new DarkUIFactory());  // 暗色主题表单
echo buildForm(new LightUIFactory()); // 亮色主题表单
```

## 建造者模式（Builder）

将复杂对象的构建过程与表示分离，支持链式调用。

```php
<?php
class QueryBuilder
{
    private string $table = '';
    private array $columns = ['*'];
    private array $wheres = [];
    private array $orderBy = [];
    private ?int $limit = null;
    private ?int $offset = null;

    public function select(array $columns): static
    {
        $this->columns = $columns;
        return $this;
    }

    public function from(string $table): static
    {
        $this->table = $table;
        return $this;
    }

    public function where(string $column, mixed $value, string $op = '='): static
    {
        $this->wheres[] = "$column $op " . (is_string($value) ? "'$value'" : $value);
        return $this;
    }

    public function orderBy(string $column, string $direction = 'ASC'): static
    {
        $this->orderBy[] = "$column $direction";
        return $this;
    }

    public function limit(int $limit): static
    {
        $this->limit = $limit;
        return $this;
    }

    public function offset(int $offset): static
    {
        $this->offset = $offset;
        return $this;
    }

    public function toSql(): string
    {
        $sql = 'SELECT ' . implode(', ', $this->columns);
        $sql .= ' FROM ' . $this->table;

        if ($this->wheres) {
            $sql .= ' WHERE ' . implode(' AND ', $this->wheres);
        }
        if ($this->orderBy) {
            $sql .= ' ORDER BY ' . implode(', ', $this->orderBy);
        }
        if ($this->limit !== null) {
            $sql .= " LIMIT $this->limit";
        }
        if ($this->offset !== null) {
            $sql .= " OFFSET $this->offset";
        }

        return $sql;
    }
}

$sql = (new QueryBuilder())
    ->select(['id', 'name', 'email'])
    ->from('users')
    ->where('status', 'active')
    ->where('age', 18, '>=')
    ->orderBy('created_at', 'DESC')
    ->limit(10)
    ->offset(20)
    ->toSql();

echo $sql;
// SELECT id, name, email FROM users WHERE status = 'active' AND age >= 18 ORDER BY created_at DESC LIMIT 10 OFFSET 20
```

## 原型模式（Prototype）

通过克隆已有对象创建新对象，避免昂贵的初始化。

```php
<?php
class PageTemplate
{
    public function __construct(
        public string $layout = 'default',
        public string $theme = 'light',
        public array $blocks = [],
        public array $meta = [],
    ) {}

    public function __clone()
    {
        // 深拷贝数组
        $this->blocks = array_map(fn($b) => clone $b, $this->blocks);
        $this->meta = [...$this->meta];
    }

    public function addBlock(Block $block): void
    {
        $this->blocks[] = $block;
    }
}

class Block
{
    public function __construct(
        public string $type,
        public string $content,
    ) {}
}

// 原型
$prototype = new PageTemplate('two-column', 'dark');
$prototype->addBlock(new Block('header', 'Welcome'));
$prototype->addBlock(new Block('footer', 'Copyright 2026'));

// 克隆创建新页面
$page1 = clone $prototype;
$page1->meta['title'] = 'Page 1';

$page2 = clone $prototype;
$page2->meta['title'] = 'Page 2';

// 各自独立，互不影响
```

## 面试常见追问

**Q: 单例模式在 PHP 中有什么特殊考虑？**

A: PHP 传统模式（PHP-FPM）每次请求是独立进程，天然实现了请求级别的单例。Swoole 等常驻内存框架中，单例跨请求共享，可能造成数据泄露。建议用 DI 容器管理生命周期。

**Q: 工厂方法和简单工厂的区别？**

A: 简单工厂是一个类通过条件判断创建不同对象（违反开闭原则）。工厂方法将创建逻辑委托给子类，新增类型只需新增子类，符合开闭原则。

**Q: 建造者模式和工厂模式的区别？**

A: 工厂关注"创建什么"，建造者关注"怎么创建"（分步骤构建复杂对象）。建造者适合有多个可选参数和配置步骤的对象。

**Q: PHP 的 `clone` 和原型模式有什么关系？**

A: 原型模式核心就是 `clone`。PHP 的 `clone` 做浅拷贝，配合 `__clone` 魔术方法实现深拷贝，正好满足原型模式的需求。

## 小结

| 模式 | 核心意图 | PHP 实现要点 |
|------|---------|-------------|
| 单例 | 全局唯一实例 | `static` + 私有构造 + 禁克隆 |
| 工厂方法 | 子类决定创建什么 | 抽象工厂方法 + 具体子类 |
| 抽象工厂 | 创建一系列相关对象 | 接口 + 多个具体工厂 |
| 建造者 | 分步构建复杂对象 | 链式调用 + `toSql()`/`build()` |
| 原型 | 克隆创建对象 | `clone` + `__clone` 深拷贝 |
