---# PHP类与对象基础

类与对象是 PHP OOP 的基石。理解属性、方法、访问修饰符、`$this`/`self`/`static`/`parent` 的区别和静态绑定机制，是面向对象编程的第一步。

## 属性与方法

```php
<?php
class User
{
    // 属性（PHP 8+ 可省略初始化，配合构造器提升）
    private string $name;
    private int $age;
    private static int $count = 0;

    // 构造器属性提升（PHP 8+ 简写）
    public function __construct(
        string $name,
        private readonly string $email, // 直接声明属性
        int $age = 18,
    ) {
        $this->name = $name;
        $this->age = $age;
        self::$count++;
    }

    // 实例方法
    public function greet(): string
    {
        return "I'm {$this->name}, age {$this->age}";
    }

    // 静态方法
    public static function getCount(): int
    {
        return self::$count;
    }

    // 析构函数
    public function __destruct()
    {
        self::$count--;
    }
}

$user = new User('Alice', 'alice@example.com', 25);
echo $user->greet();   // I'm Alice, age 25
echo User::getCount(); // 1
```

## 访问修饰符

```php
<?php
class Example
{
    public    string $pub  = 'public';    // 任何地方可访问
    protected string $pro  = 'protected'; // 本类及子类
    private   string $pri  = 'private';   // 仅本类

    public function test(): void
    {
        echo $this->pub;  // ✅
        echo $this->pro;  // ✅
        echo $this->pri;  // ✅
    }
}

class Child extends Example
{
    public function childTest(): void
    {
        echo $this->pub;  // ✅
        echo $this->pro;  // ✅
        // echo $this->pri; // ❌ Fatal Error
    }
}

$obj = new Child();
echo $obj->pub;   // ✅
// echo $obj->pro; // ❌
// echo $obj->pri; // ❌
```

**PHP 8.1 readonly 属性：** 只能在初始化时赋值（构造函数），之后不可修改。`readonly` 隐含 `private` 的可见性设置，但可以显式声明为 `public readonly`。

## $this vs self vs static vs parent

这是面试必考的知识点：

```php
<?php
class Base
{
    protected static string $label = 'Base';

    public static function getLabelSelf(): string
    {
        return self::$label; // 绑定到声明时的类
    }

    public static function getLabelStatic(): string
    {
        return static::$label; // 绑定到运行时调用的类（后期静态绑定）
    }
}

class Derived extends Base
{
    protected static string $label = 'Derived';
}

echo Derived::getLabelSelf();   // 'Base'  — self 指向 Base
echo Derived::getLabelStatic(); // 'Derived' — static 指向 Derived
```

### 后期静态绑定（Late Static Binding）

`static::` 实现了后期静态绑定（LSB），是 PHP 5.3 引入的特性：

```php
<?php
abstract class Model
{
    protected static string $table = '';

    public static function find(int $id): ?static
    {
        $table = static::$table; // 使用调用类的 $table
        // 模拟查询
        echo "SELECT * FROM $table WHERE id = $id\n";
        return new static(); // 创建调用类的实例
    }

    public static function factory(mixed ...$args): static
    {
        return new static(...$args); // 创建调用类的实例
    }
}

class User extends Model
{
    protected static string $table = 'users';
}

class Post extends Model
{
    protected static string $table = 'posts';
}

User::find(1);  // SELECT * FROM users WHERE id = 1
Post::find(5);  // SELECT * FROM posts WHERE id = 5
```

**PHP 8.0 返回 `static` 类型（返回类型声明）：** `static` 作为返回类型表示返回当前类（或子类）的实例，比 `self` 更灵活。

### parent 关键字

```php
<?php
class ParentClass
{
    protected function getConfig(): array
    {
        return ['timeout' => 30, 'retry' => 3];
    }
}

class ChildClass extends ParentClass
{
    protected function getConfig(): array
    {
        // 先获取父类配置，再合并覆盖
        return array_merge(
            parent::getConfig(),
            ['retry' => 5, 'debug' => true]
        );
    }
}
```

## 静态属性与方法

```php
<?php
class Counter
{
    private static int $count = 0;

    public static function increment(): void
    {
        self::$count++;
    }

    public static function getCount(): int
    {
        return self::$count;
    }

    // 静态方法中不能用 $this
    // public function wrong(): void { echo $this->count; } // Error
}

Counter::increment();
Counter::increment();
echo Counter::getCount(); // 2
```

## 面试常见追问

**Q: `self` 和 `static` 的区别？**

A: `self` 指向定义方法的类（编译时绑定），`static` 指向实际调用方法的类（运行时绑定，后期静态绑定）。在继承场景下 `static` 更灵活，是实现工厂模式和 ActiveRecord 模式的关键。

**Q: `$this` 和 `self` 分别什么时候用？**

A: `$this` 用于访问实例属性和方法（需要对象上下文），`self` 用于访问静态成员和常量。`$this` 是一个引用，指向当前对象实例。

**Q: `readonly` 和 `private set` 的区别？**

A: `readonly` 只能初始化一次（构造函数中），之后完全不可修改。PHP 8.4 的 asymmetric visibility（`private set`）允许类外部读、内部写，比 `readonly` 更灵活。

**Q: PHP 构造器属性提升的原理？**

A: `public function __construct(private string $name)` 等价于声明 `private string $name` 属性 + 构造函数中 `$this->name = $name`。是语法糖，编译后与手写完全相同。

## 小结

| 关键字 | 绑定时机 | 指向 |
|--------|---------|------|
| `$this` | 运行时 | 当前对象实例 |
| `self` | 编译时 | 定义方法的类 |
| `static` | 运行时 | 实际调用的类 |
| `parent` | 编译时 | 父类 |

掌握 `$this`/`self`/`static`/`parent` 的区别是 PHP OOP 的基本功，特别是后期静态绑定在框架中大量使用。
