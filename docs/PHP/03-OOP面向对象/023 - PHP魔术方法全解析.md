# PHP魔术方法全解析

PHP 的魔术方法以双下划线 `__` 开头，在特定事件发生时自动调用。它们是 PHP 元编程的核心——拦截属性访问、方法调用、类型转换、序列化等操作。

## __construct 与 __destruct

```php
<?php
class DatabaseConnection
{
    private PDO $pdo;

    public function __construct(
        string $dsn,
        string $user = '',
        string $pass = '',
    ) {
        $this->pdo = new PDO($dsn, $user, $pass);
        $this->pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    }

    public function query(string $sql): array
    {
        return $this->pdo->query($sql)->fetchAll();
    }

    public function __destruct()
    {
        // 释放资源
        unset($this->pdo);
    }
}

$db = new DatabaseConnection('sqlite::memory:');
// $db 离开作用域或脚本结束时 __destruct 自动调用
```

**注意：** `__destruct` 不保证调用时机（依赖垃圾回收），不能用于关键资源释放。显式 `close()`/`dispose()` 模式更可靠。

## __get、__set、__isset、__unset — 属性拦截

```php
<?php
class Config
{
    private array $data = [];

    public function __construct(array $defaults = [])
    {
        $this->data = $defaults;
    }

    // 访问不存在的属性时触发
    public function __get(string $name): mixed
    {
        return $this->data[$name] ?? throw new RuntimeException("Config '$name' not found");
    }

    // 设置不存在的属性时触发
    public function __set(string $name, mixed $value): void
    {
        $this->data[$name] = $value;
    }

    // isset() 检查不存在的属性时触发
    public function __isset(string $name): bool
    {
        return isset($this->data[$name]);
    }

    // unset() 不存在的属性时触发
    public function __unset(string $name): void
    {
        unset($this->data[$name]);
    }
}

$config = new Config(['debug' => false]);
echo $config->debug;        // false（__get）
$config->env = 'production'; // __set
isset($config->env);         // true（__isset）
unset($config->env);         // __unset
```

## __call 与 __callStatic — 方法拦截

```php
<?php
class Facade
{
    private static object $instance;

    public static function setInstance(object $instance): void
    {
        self::$instance = $instance;
    }

    // 调用不存在的方法时触发
    public function __call(string $method, array $args): mixed
    {
        if (method_exists(self::$instance, $method)) {
            return self::$instance->$method(...$args);
        }
        throw new BadMethodCallException("Method $method not found");
    }

    // 调用不存在的静态方法时触发
    public static function __callStatic(string $method, array $args): mixed
    {
        return (new static())->$method(...$args);
    }
}
```

## __toString — 字符串转换

```php
<?php
class Money
{
    public function __construct(
        private float $amount,
        private string $currency = 'CNY',
    ) {}

    public function __toString(): string
    {
        return sprintf('%.2f %s', $this->amount, $this->currency);
    }
}

$price = new Money(99.5, 'CNY');
echo "Price: $price"; // Price: 99.50 CNY

// 注意：__toString 中不能抛异常（PHP 7.4+ 会触发 Fatal Error）
```

## __invoke — 对象当函数调用

```php
<?php
class Multiplier
{
    public function __construct(private float $factor) {}

    public function __invoke(float $value): float
    {
        return $value * $this->factor;
    }
}

$double = new Multiplier(2);
echo $double(5); // 10 — 对象可以直接调用

// __invoke 让对象变成 callable
array_map(new Multiplier(3), [1, 2, 3]); // [3, 6, 9]
```

## __clone — 克隆控制

```php
<?php
class Order
{
    private DateTimeImmutable $createdAt;

    public function __construct(
        private array $items = [],
    ) {
        $this->createdAt = new DateTimeImmutable();
    }

    public function __clone()
    {
        // 深拷贝：为新克隆对象创建新的时间戳
        $this->createdAt = new DateTimeImmutable();
        // 深拷贝数组
        $this->items = array_map(fn($item) => clone $item, $this->items);
    }
}

$order = new Order([new Item('Apple')]);
$copy = clone $order; // 触发 __clone
// $copy 的 createdAt 是新的时间，items 是新的克隆
```

**浅拷贝 vs 深拷贝：** `clone` 默认做浅拷贝（对象属性共享引用）。`__clone` 中手动 `clone` 嵌套对象实现深拷贝。

## __debugInfo — var_dump 自定义

```php
<?php
class LargeDataset
{
    private array $data;
    private int $totalRecords;

    public function __construct(array $data)
    {
        $this->data = $data;
        $this->totalRecords = count($data);
    }

    public function __debugInfo(): array
    {
        // var_dump 时只显示摘要，不打印全部数据
        return [
            'totalRecords' => $this->totalRecords,
            'sample' => array_slice($this->data, 0, 3),
        ];
    }
}

$ds = new LargeDataset(range(1, 10000));
var_dump($ds);
// 只显示 totalRecords 和 sample，不会打印10000条
```

## __sleep 与 __wakeup — 序列化控制

```php
<?php
class UserSession
{
    public function __construct(
        private string $userId,
        private PDO $db,           // 不可序列化
        private array $cache = [],
    ) {}

    public function __sleep(): array
    {
        // 只序列化这些属性
        return ['userId', 'cache'];
        // $db 被排除（PDO 不可序列化）
    }

    public function __wakeup(): void
    {
        // 反序列化后重建资源
        $this->db = new PDO('mysql:host=localhost', 'root', '');
    }
}

$session = new UserSession('user123', $pdo, ['key' => 'value']);
$serialized = serialize($session);
$restored = unserialize($serialized); // 触发 __wakeup 重建 PDO
```

**PHP 7.4+ 推荐用 `__serialize`/`__unserialize` 替代 `__sleep`/`__wakeup`：**

```php
<?php
public function __serialize(): array
{
    return ['userId' => $this->userId, 'cache' => $this->cache];
}

public function __unserialize(array $data): void
{
    $this->userId = $data['userId'];
    $this->cache = $data['cache'];
    $this->db = new PDO('mysql:host=localhost', 'root', '');
}
```

## __set_state — var_export 支持

```php
<?php
class Point
{
    public function __construct(
        public float $x,
        public float $y,
    ) {}

    public static function __set_state(array $properties): static
    {
        return new static($properties['x'], $properties['y']);
    }
}

$p = new Point(3, 4);
$code = var_export($p, true);
// Point::__set_state(array('x' => 3, 'y' => 4))
$restored = eval("return $code;"); // 通过 __set_state 重建对象
```

## 面试常见追问

**Q: 魔术方法对性能有什么影响？**

A: 魔术方法比直接调用慢 2-10 倍（需要额外的拦截层查找）。但在实际应用中通常不是瓶颈。避免在热路径（如循环百万次）中频繁触发 `__get`/`__set`。

**Q: `__toString` 为什么不能抛异常？**

A: 因为 `__toString` 在字符串上下文中隐式调用（`echo $obj`、字符串拼接），异常无法被合理处理。PHP 7.4+ 抛出异常会导致 Fatal Error。PHP 8.2 讨论过放宽此限制，但目前仍维持。

**Q: `__clone` 的执行时机？**

A: `clone` 先做浅拷贝创建新对象，然后在新对象上调用 `__clone`（不是在原对象上）。所以 `__clone` 中的 `$this` 是新克隆的对象。

**Q: `__sleep` 和 `__serialize` 能共存吗？**

A: 如果定义了 `__serialize`，`__sleep` 会被忽略。`__serialize`/`__unserialize` 是更现代的方式，优先使用。

## 小结

| 魔术方法 | 触发时机 | 典型用途 |
|---------|---------|---------|
| `__construct` | `new` | 初始化 |
| `__destruct` | 对象销毁 | 资源清理 |
| `__get`/`__set` | 属性访问/设置 | 代理、延迟加载 |
| `__call`/`__callStatic` | 方法调用 | 代理、Facade |
| `__toString` | 字符串上下文 | 格式化输出 |
| `__invoke` | 对象当函数 | callable 对象 |
| `__clone` | `clone` | 深拷贝 |
| `__sleep`/`__wakeup` | serialize/unserialize | 控制序列化 |
| `__debugInfo` | `var_dump` | 调试信息 |
| `__set_state` | `var_export` | 导出重建 |

魔术方法强大但不要滥用。每个魔术方法都有明确的触发场景和最佳实践，用对地方事半功倍。
