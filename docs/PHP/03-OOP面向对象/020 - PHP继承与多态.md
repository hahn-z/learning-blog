# PHP继承与多态

继承是 OOP 的三大特性之一，多态则是继承的价值体现。PHP 通过 `extends` 实现单继承，通过 `abstract`/`final` 控制继承行为，通过方法覆盖实现运行时多态。

## extends 继承

```php
<?php
class Animal
{
    public function __construct(
        protected string $name,
        protected string $sound = '',
    ) {}

    public function speak(): string
    {
        return "{$this->name} says {$this->sound}";
    }

    public function move(): string
    {
        return "{$this->name} moves";
    }
}

class Dog extends Animal
{
    public function __construct(string $name)
    {
        parent::__construct($name, 'Woof');
    }

    public function fetch(string $item): string
    {
        return "{$this->name} fetches the $item";
    }
}

$dog = new Dog('Rex');
echo $dog->speak(); // Rex says Woof
echo $dog->fetch('ball'); // Rex fetches the ball
```

**继承规则：** PHP 只支持单继承（一个类只能 extends 一个父类），但可以通过 Trait 实现水平代码复用。

## 方法覆盖（Override）

子类可以覆盖父类的方法，但必须遵守兼容性规则：

```php
<?php
class PaymentProcessor
{
    public function process(float $amount): string
    {
        return "Processing $amount via default gateway";
    }
}

class StripeProcessor extends PaymentProcessor
{
    // PHP 8.0+ 可用 #[Override] 属性标注（PHP 8.3 正式引入）
    #[\Override]
    public function process(float $amount): string
    {
        return "Processing $amount via Stripe";
    }
}

// 多态 — 同一接口，不同行为
function checkout(PaymentProcessor $processor, float $amount): void
{
    echo $processor->process($amount);
}

checkout(new PaymentProcessor(), 100); // via default gateway
checkout(new StripeProcessor(), 100);  // via Stripe
```

**方法覆盖的 LSP 兼容性规则：**
- 参数类型：子类可以**放宽**（逆变，但 PHP 不支持真正的逆变声明）
- 返回类型：子类可以**收窄**（协变）
- 访问修饰符：子类可以放宽（protected → public），不能收紧

```php
<?php
class Parent
{
    protected function calc(int $x): int|float { return $x; }
}

class Child extends Parent
{
    public function calc(int $x): int { return $x; }
    // ✅ public 放宽了 protected ✅
    // ✅ 返回 int 是 int|float 的子集（协变）✅
}
```

## final 关键字

`final` 阻止类被继承或方法被覆盖：

```php
<?php
final class Utility
{
    // 这个类不能被继承
}

// class MyUtility extends Utility {} // ❌ Fatal Error

class BaseService
{
    final public function getId(): string
    {
        return spl_object_hash($this);
    }

    public function process(): void { /* ... */ }
}

class MyService extends BaseService
{
    // public function getId(): string {} // ❌ Cannot override final method
    public function process(): void { /* ✅ 可以覆盖 */ }
}
```

**何时用 `final`：** (1) 工具类/值对象不应该被继承；(2) 核心算法不希望子类改变行为；(3) 安全相关的验证逻辑。框架中的 `final` 使用频率在增加（如 Symfony 6+ 大量使用）。

## abstract 抽象类与方法

```php
<?php
abstract class Shape
{
    public function __construct(
        protected string $color = 'black',
    ) {}

    // 抽象方法 — 子类必须实现
    abstract public function area(): float;
    abstract public function perimeter(): float;

    // 具体方法 — 子类可直接使用
    public function describe(): string
    {
        return sprintf(
            '%s shape: area=%.2f, perimeter=%.2f',
            $this->color,
            $this->area(),
            $this->perimeter()
        );
    }
}

class Circle extends Shape
{
    public function __construct(
        private float $radius,
        string $color = 'black',
    ) {
        parent::__construct($color);
    }

    public function area(): float
    {
        return pi() * $this->radius ** 2;
    }

    public function perimeter(): float
    {
        return 2 * pi() * $this->radius;
    }
}

class Rectangle extends Shape
{
    public function __construct(
        private float $width,
        private float $height,
        string $color = 'black',
    ) {
        parent::__construct($color);
    }

    public function area(): float
    {
        return $this->width * $this->height;
    }

    public function perimeter(): float
    {
        return 2 * ($this->width + $this->height);
    }
}

// 多态使用
$shapes = [
    new Circle(5, 'red'),
    new Rectangle(3, 4, 'blue'),
];

foreach ($shapes as $shape) {
    echo $shape->describe() . "\n";
}
```

## LSP 里氏替换原则

LSP 要求：子类对象必须能替换父类对象，而不改变程序的正确性。

```php
<?php
// 违反 LSP 的经典例子
class Bird
{
    public function fly(): string { return 'flying'; }
}

class Penguin extends Bird
{
    public function fly(): string
    {
        throw new RuntimeException('Penguins cannot fly!');
        // ❌ 子类抛出了父类没有的异常，违反 LSP
    }
}

function makeBirdFly(Bird $bird): string
{
    return $bird->fly();
}

makeBirdFly(new Penguin()); // 💥 RuntimeException

// 正确做法：重新设计继承层次
abstract class Bird {}
class FlyingBird extends Bird
{
    public function fly(): string { return 'flying'; }
}
class Penguin extends Bird {} // Penguin 不是 FlyingBird
```

## 面试常见追问

**Q: PHP 为什么不支持多继承？**

A: 多继承带来菱形继承问题（Diamond Problem）：两个父类有同名方法时子类继承哪个。PHP 选择单继承 + Trait 来平衡代码复用和复杂度。C++ 支持多继承但需要虚继承来解决歧义。

**Q: `abstract` 和 `interface` 的选择？**

A: 抽象类可以有属性和具体方法，适合有共同状态的"is-a"关系（如各种 Shape 共享 color 属性）。接口只定义行为契约，适合"can-do"能力描述（如 Renderable, Loggable）。PHP 可以实现多接口但只能继承一个抽象类。

**Q: `#[Override]` 属性有什么用？**

A: PHP 8.3 引入，明确标注"我要覆盖父类方法"。如果父类没有这个方法（拼写错误、父类方法被删除），PHP 会报错。类似 Java 的 `@Override` 注解，防止低级错误。

**Q: PHP 的多态是编译时还是运行时？**

A: 运行时多态（动态绑定）。`$obj->method()` 调用时，PHP 引擎在运行时查找对象的实际类中的方法，而不是变量类型声明中的类。

## 小结

继承建立 "is-a" 关系，多态让同一接口展现不同行为。`abstract` 强制子类实现关键方法，`final` 防止不当覆盖。遵守 LSP 保证继承体系的健壮性——子类应该增强父类行为，而不是破坏它。
