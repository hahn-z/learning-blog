# PSR规范全解

PSR（PHP Standards Recommendations）是PHP-FIG制定的互操作性标准。掌握核心PSR规范，是写出规范PHP代码的基础。

## PSR-1：基本编码规范

```php
<?php
// 1. 文件必须只使用 <?php 和 <?= 标签
// 2. 文件必须使用UTF-8无BOM编码
// 3. 文件应该只声明符号（类/函数/常量）或产生副作用，不同时做两件事

// 好的文件：只声明
namespace App\Service;
class UserService { }

// 坏的文件：声明+副作用混用
namespace App\Service;
class UserService { }
echo "side effect";  // 副作用

// 4. 命名空间和类必须遵循PSR-4自动加载
// 5. 类名使用StudlyCaps（大驼峰）
class UserAccount {}

// 6. 类常量全大写+下划线
class User {
    public const MAX_LOGIN_ATTEMPTS = 5;
    public const DEFAULT_ROLE = 'member';
}

// 7. 方法名使用camelCase（小驼峰）
function calculateTotal(int $amount, float $taxRate): float {}
```

## PSR-3：日志接口

```php
<?php
namespace Psr\Log;

interface LoggerInterface {
    public function emergency(string|\Stringable $message, array $context = []): void;
    public function alert(string|\Stringable $message, array $context = []): void;
    public function critical(string|\Stringable $message, array $context = []): void;
    public function error(string|\Stringable $message, array $context = []): void;
    public function warning(string|\Stringable $message, array $context = []): void;
    public function notice(string|\Stringable $message, array $context = []): void;
    public function info(string|\Stringable $message, array $context = []): void;
    public function debug(string|\Stringable $message, array $context = []): void;
    public function log($level, string|\Stringable $message, array $context = []): void;
}

// 实现示例
class FileLogger implements LoggerInterface {
    public function __construct(private string $logFile) {}
    
    public function error(string|\Stringable $message, array $context = []): void {
        $this->log('error', $message, $context);
    }
    
    public function log($level, string|\Stringable $message, array $context = []): void {
        $line = sprintf("[%s] [%s] %s %s\n",
            date('Y-m-d H:i:s'),
            strtoupper($level),
            $this->interpolate((string)$message, $context),
            $context ? json_encode($context) : ''
        );
        file_put_contents($this->logFile, $line, FILE_APPEND);
    }
    
    // 消息模板替换: "User {name} logged in"
    private function interpolate(string $message, array $context): string {
        return preg_replace_callback('/\{(\w+)\}/', function($m) use ($context) {
            return (string)($context[$m[1]] ?? $m[0]);
        }, $message);
    }
    
    // 其他方法委托给log()...
}
```

## PSR-4：自动加载

```
规则: 完全限定类名 → 文件路径映射

命名空间前缀 → 基础目录
\App\          → /var/www/app/
App\Http\Controllers\UserController
→ /var/www/app/Http/Controllers/UserController.php

要点:
1. 完全限定类名必须有顶级命名空间（Vendor\Prefix）
2. 类名和文件名一致（UserController → UserController.php）
3. 下划线在类名中没有特殊含义（不同于PSR-0）
```

## PSR-7：HTTP消息接口

```php
<?php
use Psr\Http\Message\{RequestInterface, ResponseInterface, ServerRequestInterface, StreamInterface};

// PSR-7的核心：所有HTTP消息都是不可变的（immutable）
// 每个修改方法返回新实例

interface RequestInterface extends MessageInterface {
    public function getRequestTarget(): string;
    public function withRequestTarget(string $requestTarget): RequestInterface;
    public function getMethod(): string;
    public function withMethod(string $method): RequestInterface;
    public function getUri(): UriInterface;
    public function withUri(UriInterface $uri, bool $preserveHost = false): RequestInterface;
}

// 中间件中使用PSR-7
function handle(ServerRequestInterface $request): ResponseInterface {
    $body = $request->getBody()->getContents();
    $data = json_decode($body, true);
    
    return new Response(201, ['Content-Type' => 'application/json'], 
        json_encode(['id' => 1]));
}
```

## PSR-11：容器接口

```php
<?php
namespace Psr\Container;

interface ContainerInterface {
    public function get(string $id): mixed;      // 获取服务
    public function has(string $id): bool;        // 服务是否存在
}

// 简单实现
class SimpleContainer implements ContainerInterface {
    private array $bindings = [];
    private array $instances = [];
    
    public function set(string $id, callable $factory): void {
        $this->bindings[$id] = $factory;
    }
    
    public function get(string $id): mixed {
        if (isset($this->instances[$id])) {
            return $this->instances[$id];
        }
        if (!$this->has($id)) {
            throw new NotFoundException("Service not found: $id");
        }
        $instance = ($this->bindings[$id])($this);
        $this->instances[$id] = $instance; // 单例
        return $instance;
    }
    
    public function has(string $id): bool {
        return isset($this->bindings[$id]) || isset($this->instances[$id]);
    }
}
```

## PSR-12：扩展编码规范

PSR-12是PSR-1/PSR-2的超集和现代化：

```php
<?php

declare(strict_types=1);  // 文件头部

namespace Vendor\Package;

use Vendor\Package\{ClassA as A, ClassB, ClassC};  // 分组use
use function Vendor\Package\functionName;           // 函数use
use const Vendor\Package\CONSTANT_NAME;             // 常量use

class ClassName extends ParentClass implements InterfaceA, InterfaceB
{
    use TraitA, TraitB {
        TraitA::method insteadof TraitB;
        TraitB::method as aliasMethod;
    }

    // 常量_visibility（PHP 7.1+）
    public const PUBLIC_CONST = 1;
    protected const PROTECTED_CONST = 2;

    // 属性类型声明
    private ?string $name = null;
    private int $age;
    private static int $count = 0;

    // 构造函数参数提升（PHP 8.0+）
    public function __construct(
        private readonly string $name,
        private readonly int $age,
    ) {
    }

    // 方法声明
    public function process(
        string $input,
        int $flags = 0,
        ?array $options = null,
    ): string {
        // 方法体
        if ($flags > 0) {
            return strtoupper($input);
        }

        return $input;
    }

    // 抽象方法
    abstract protected function doProcess(string $data): void;
}
```

## PSR-15：HTTP中间件

```php
<?php
namespace Psr\Http\Server;

use Psr\Http\Message\{ServerRequestInterface, ResponseInterface};

interface MiddlewareInterface {
    public function process(ServerRequestInterface $request, RequestHandlerInterface $handler): ResponseInterface;
}

interface RequestHandlerInterface {
    public function handle(ServerRequestInterface $request): ResponseInterface;
}

// 中间件管道实现
class MiddlewarePipeline implements RequestHandlerInterface {
    private array $middleware = [];
    private RequestHandlerInterface $fallback;
    
    public function __construct(RequestHandlerInterface $fallback) {
        $this->fallback = $fallback;
    }
    
    public function add(MiddlewareInterface $m): self {
        $this->middleware[] = $m;
        return $this;
    }
    
    public function handle(ServerRequestInterface $request): ResponseInterface {
        if (empty($this->middleware)) {
            return $this->fallback->handle($request);
        }
        $middleware = array_shift($this->middleware);
        return $middleware->process($request, $this);
    }
}

// 认证中间件
class AuthMiddleware implements MiddlewareInterface {
    public function process(ServerRequestInterface $request, RequestHandlerInterface $handler): ResponseInterface {
        $token = $request->getHeaderLine('Authorization');
        if (!$token) {
            return new Response(401, [], json_encode(['error' => 'Unauthorized']));
        }
        // 注入用户信息到请求
        $request = $request->withAttribute('user_id', $this->validateToken($token));
        return $handler->handle($request);
    }
}
```

## 面试常见追问

**Q: PSR-7为什么要设计成不可变的？**
A: 不可变保证消息在中间件链中传递时不被意外修改，每个中间件拿到的是独立副本。这避免了调试困难的副作用bug。代价是内存开销（每次withXxx都创建新对象）。

**Q: PSR-4和PSR-0的区别？**
A: PSR-0中类名的下划线会被转换为目录分隔符（`User_Account → User/Account.php`）。PSR-4取消了这一规则，下划线无特殊含义。PSR-4更简洁，PSR-0已废弃。

**Q: PSR-11容器和DI容器有什么区别？**
A: PSR-11只定义了get/has两个方法（服务定位器模式）。DI容器（依赖注入）通常提供自动装配（autowire）、绑定配置等额外功能。PSR-11是最小公共接口，DI容器可以实现它。

**Q: PSR-15中间件的执行顺序是怎样的？**
A: 洋葱模型。第一个中间件最先执行前置逻辑，最后执行后置逻辑。`$handler->handle($request)`是分界点——之前是前置，之后是后置。
