---# PHP数据库连接池设计

## 为什么PHP-FPM不需要传统连接池

PHP-FPM的运行模型是"一个请求一个进程"，请求结束时所有资源释放。这意味着：

1. 每个请求创建新连接 → 连接数 = PHP-FPM worker数（可控）
2. 连接在请求结束时自动关闭 → 不会泄漏
3. 应用层连接池没有意义 → 请求之间无法共享状态

**真正需要连接池的场景是Swoole/Workerman等常驻内存框架。**

## PDO持久连接

```php
<?php
// PDO::ATTR_PERSISTENT = true 让PHP-FPM在请求结束后不关闭连接
// 下一个请求复用同一进程内的连接
$pdo = new PDO($dsn, 'root', '', [
    PDO::ATTR_PERSISTENT => true,
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
]);

// 原理：
// PHP-FPM进程A → 请求1创建持久连接 → 请求1结束 → 连接保留在进程A
// PHP-FPM进程A → 请求2复用进程A的连接 → 无需重新TCP握手和认证

// 注意事项：
// 1. 持久连接不会在请求间重置状态（如临时表、变量、事务）
// 2. 如果上一个请求没有commit/rollback，下一个请求可能在一个事务中
// 3. 连接可能因为MySQL的wait_timeout断开，需要重连机制
```

### 持久连接安全封装

```php
<?php
class SafePersistentPDO
{
    private ?PDO $pdo = null;
    private string $dsn;
    private string $user;
    private string $pass;
    private array $options;

    public function __construct(string $dsn, string $user, string $pass, array $options = [])
    {
        $this->dsn = $dsn;
        $this->user = $user;
        $this->pass = $pass;
        $this->options = $options + [
            PDO::ATTR_PERSISTENT => true,
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        ];
    }

    public function getConnection(): PDO
    {
        if ($this->pdo === null) {
            $this->pdo = $this->createConnection();
        }

        // 验证连接是否有效
        try {
            $this->pdo->query('SELECT 1');
        } catch (PDOException) {
            // 连接已断开，重建
            $this->pdo = $this->createConnection();
        }

        // 确保不在事务中（防止上次请求泄漏）
        try {
            $this->pdo->rollBack();
        } catch (PDOException) {
            // 不在事务中，忽略
        }

        return $this->pdo;
    }

    private function createConnection(): PDO
    {
        return new PDO($this->dsn, $this->user, $this->pass, $this->options);
    }
}
```

## Swoole连接池

Swoole是常驻内存的PHP运行时，真正需要连接池来管理数据库连接：

```php
<?php
use Swoole\Coroutine\Channel;
use Swoole\Coroutine;

class SwooleConnectionPool
{
    private Channel $pool;
    private int $maxSize;
    private int $currentSize = 0;
    private string $dsn;
    private string $user;
    private string $pass;
    private array $options;

    public function __construct(string $dsn, string $user, string $pass, int $maxSize = 20, array $options = [])
    {
        $this->dsn = $dsn;
        $this->user = $user;
        $this->pass = $pass;
        $this->maxSize = $maxSize;
        $this->options = $options + [
            PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_EMULATE_PREPARES => false,
        ];
        $this->pool = new Channel($maxSize);
    }

    // 获取连接（协程安全）
    public function get(float $timeout = 5): PDO
    {
        // 从池中取
        if (!$this->pool->isEmpty()) {
            return $this->pool->pop();
        }

        // 池空但未达上限，创建新连接
        if ($this->currentSize < $this->maxSize) {
            $this->currentSize++;
            return $this->createConnection();
        }

        // 池满，等待其他协程归还
        $pdo = $this->pool->pop($timeout);
        if ($pdo === false) {
            throw new RuntimeException('获取数据库连接超时');
        }
        return $pdo;
    }

    // 归还连接
    public function put(PDO $pdo): void
    {
        if ($this->pool->isFull()) {
            $this->currentSize--;
            // 让连接自然关闭
        } else {
            $this->pool->push($pdo);
        }
    }

    // 执行查询（自动借还）
    public function execute(callable $callback): mixed
    {
        $pdo = $this->get();
        try {
            return $callback($pdo);
        } finally {
            $this->put($pdo);
        }
    }

    private function createConnection(): PDO
    {
        return new PDO($this->dsn, $this->user, $this->pass, $this->options);
    }
}

// 使用
Co\run(function () {
    $pool = new SwooleConnectionPool(
        'mysql:host=127.0.0.1;dbname=test;charset=utf8mb4',
        'root',
        '',
        20
    );

    // 并发100个协程查询
    $results = [];
    for ($i = 0; $i < 100; $i++) {
        Coroutine::create(function () use ($pool, &$results, $i) {
            $result = $pool->execute(function (PDO $pdo) use ($i) {
                $stmt = $pdo->prepare('SELECT * FROM users WHERE id = ?');
                $stmt->execute([$i]);
                return $stmt->fetch();
            });
            $results[$i] = $result;
        });
    }

    // 最多20个并发连接，其余协程等待
});
```

## 单例连接管理器

传统PHP-FPM项目中，一个请求内可能多处需要PDO，用单例避免重复创建：

```php
<?php
class DatabaseManager
{
    private static array $instances = [];

    public static function getConnection(string $name = 'default'): PDO
    {
        if (isset(self::$instances[$name])) {
            return self::$instances[$name];
        }

        $config = self::getConfig($name);

        $pdo = new PDO(
            $config['dsn'],
            $config['username'],
            $config['password'],
            [
                PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
                PDO::ATTR_EMULATE_PREPARES => false,
            ]
        );

        self::$instances[$name] = $pdo;
        return $pdo;
    }

    private static function getConfig(string $name): array
    {
        // 从配置文件/环境变量读取
        return [
            'dsn' => sprintf(
                'mysql:host=%s;port=%s;dbname=%s;charset=utf8mb4',
                getenv('DB_HOST') ?: '127.0.0.1',
                getenv('DB_PORT') ?: '3306',
                getenv('DB_NAME') ?: 'myapp'
            ),
            'username' => getenv('DB_USER') ?: 'root',
            'password' => getenv('DB_PASS') ?: '',
        ];
    }

    // 测试用：注入Mock连接
    public static function setConnection(string $name, PDO $pdo): void
    {
        self::$instances[$name] = $pdo;
    }

    // 重置（测试teardown）
    public static function reset(): void
    {
        self::$instances = [];
    }
}

// 使用
$pdo = DatabaseManager::getConnection();
$pdo->query('SELECT 1');

// 多数据库
$readDb = DatabaseManager::getConnection('read');
$writeDb = DatabaseManager::getConnection('write');
```

## 面试常见追问

**Q: 为什么PHP-FPM不推荐用连接池？**
A: PHP-FPM每个请求独立进程，请求结束后内存回收。连接池需要跨请求共享状态，在进程模型下无法实现。PHP-FPM的解决方案是`PDO::ATTR_PERSISTENT`（进程级持久连接），本质是"进程内缓存连接"而非"进程间共享连接池"。

**Q: Swoole连接池中连接断开怎么处理？**
A: 三种策略：1) `get()`时先`ping()`验证，断开则重建；2) 执行SQL捕获`PDOException`，如果是2006(MySQL server has gone away)或2013(Lost connection)，重建连接重试；3) 设置`maxIdleTime`，定期清理长时间空闲的连接。生产环境推荐方案2+3结合。

**Q: 连接池大小设置多少合适？**
A: 公式参考：`连接数 = (CPU核心数 * 2) + 有效磁盘数`。对于Web应用，通常`20-50`够用。关键约束是MySQL的`max_connections`（默认151）。Swoole场景下，连接池大小 = 协程并发数上限，根据业务压测调整。
