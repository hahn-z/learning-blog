# PDO完全入门与预处理语句

## PDO连接与DSN

```php
<?php
// MySQL DSN格式
$dsn = 'mysql:host=127.0.0.1;port=3306;dbname=myapp;charset=utf8mb4';

// PostgreSQL
// $dsn = 'pgsql:host=127.0.0.1;port=5432;dbname=myapp';

// SQLite
// $dsn = 'sqlite:/path/to/database.sqlite';

try {
    $pdo = new PDO($dsn, 'root', 'password', [
        PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,  // 异常模式（必开！）
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,        // 默认关联数组
        PDO::ATTR_EMULATE_PREPARES   => false,                    // 禁用模拟预处理
        PDO::ATTR_PERSISTENT         => false,                    // 非持久连接
        PDO::MYSQL_ATTR_INIT_COMMAND => "SET time_zone = '+08:00'", // MySQL时区
    ]);
} catch (PDOException $e) {
    // 生产环境不暴露数据库错误细节
    error_log('数据库连接失败: ' . $e->getMessage());
    throw new RuntimeException('服务暂时不可用');
}
```

### 关键属性详解

```php
<?php
// ATTR_ERRMODE - 错误处理模式
// PDO::ERRMODE_SILENT     — 默认，只设errorCode（不推荐）
// PDO::ERRMODE_WARNING    — 触发E_WARNING
// PDO::ERRMODE_EXCEPTION  — 抛出PDOException（推荐）

// ATTR_EMULATE_PREPARES - 模拟预处理
// true  — PHP本地拼接SQL，发送完整SQL给MySQL（某些场景有字符集问题）
// false — 使用MySQL原生预处理（推荐，更安全）

// ATTR_DEFAULT_FETCH_MODE - 默认获取模式
// PDO::FETCH_ASSOC  — 关联数组
// PDO::FETCH_NUM    — 索引数组
// PDO::FETCH_BOTH   — 两者都有
// PDO::FETCH_OBJ    — 匿名对象
// PDO::FETCH_CLASS  — 映射到指定类
```

## 预处理语句：防SQL注入的核心

### 为什么预处理能防SQL注入

预处理语句分两步执行：
1. **编译（Prepare）**：SQL模板发送到数据库，数据库解析语法结构
2. **执行（Execute）**：参数单独发送，数据库直接填入已编译的语句

因为编译阶段SQL结构已固定，参数不会被解析为SQL指令，所以注入无效。

```php
<?php
// ❌ SQL注入漏洞：直接拼接
$username = $_POST['username']; // 输入: ' OR '1'='1
$sql = "SELECT * FROM users WHERE username = '{$username}'";
// 实际执行: SELECT * FROM users WHERE username = '' OR '1'='1'
// 返回所有用户！

// ✅ 安全：预处理语句
$stmt = $pdo->prepare('SELECT * FROM users WHERE username = :username');
$stmt->execute([':username' => $username]);
// 实际执行: SELECT * FROM users WHERE username = '\' OR \'1\'=\'1'
// 参数被转义，作为字符串字面量处理

// 位置参数（?）vs 命名参数（:name）
// 位置参数
$stmt = $pdo->prepare('SELECT * FROM users WHERE id = ? AND status = ?');
$stmt->execute([$userId, 'active']);

// 命名参数（推荐，可读性好）
$stmt = $pdo->prepare('SELECT * FROM users WHERE id = :id AND status = :status');
$stmt->execute([':id' => $userId, ':status' => 'active']);
```

### bindParam vs bindValue

```php
<?php
$stmt = $pdo->prepare('INSERT INTO users (name, age, created_at) VALUES (:name, :age, :created_at)');

// bindValue：绑定值（立即求值）
$name = '张三';
$stmt->bindValue(':name', $name, PDO::PARAM_STR);

// bindParam：绑定变量引用（执行时才求值）
$age = 25;
$stmt->bindParam(':age', $age, PDO::PARAM_INT);

// 区别演示
$age = 25;
$stmt->bindParam(':age', $age, PDO::PARAM_INT);
$age = 30; // 修改了变量
$stmt->execute(); // 插入的age是30！bindParam是引用绑定

$age = 25;
$stmt->bindValue(':age', $age, PDO::PARAM_INT);
$age = 30;
$stmt->execute(); // 插入的age是25！bindValue在调用时就固定了

// bindParam的实用场景：循环插入
$stmt = $pdo->prepare('INSERT INTO logs (message) VALUES (:msg)');
$stmt->bindParam(':msg', $msg);
foreach ($messages as $msg) {
    $stmt->execute(); // 每次执行时读取$msg的当前值
}
```

### PDO参数类型

```php
<?php
// PDO::PARAM_STR   — 字符串（默认）
// PDO::PARAM_INT   — 整数
// PDO::PARAM_BOOL  — 布尔
// PDO::PARAM_NULL  — NULL
// PDO::PARAM_LOB   — 大对象（BLOB）

// 正确指定类型很重要
$stmt = $pdo->prepare('SELECT * FROM users WHERE id = :id AND active = :active');
$stmt->bindValue(':id', $id, PDO::PARAM_INT);
$stmt->bindValue(':active', true, PDO::PARAM_BOOL);
$stmt->execute();

// 插入BLOB
$stmt = $pdo->prepare('INSERT INTO files (name, content) VALUES (:name, :content)');
$fp = fopen('/tmp/image.png', 'rb');
$stmt->bindValue(':name', 'image.png');
$stmt->bindValue(':content', $fp, PDO::PARAM_LOB);
$stmt->execute();
```

## CRUD完整示例

```php
<?php
class UserRepository
{
    public function __construct(private PDO $pdo) {}

    public function findById(int $id): ?array
    {
        $stmt = $this->pdo->prepare('SELECT * FROM users WHERE id = :id');
        $stmt->execute([':id' => $id]);
        return $stmt->fetch() ?: null;
    }

    public function findByRole(string $role, int $page = 1, int $perPage = 20): array
    {
        $offset = ($page - 1) * $perPage;
        $stmt = $this->pdo->prepare(
            'SELECT * FROM users WHERE role = :role ORDER BY id DESC LIMIT :limit OFFSET :offset'
        );
        // LIMIT/OFFSET必须用PARAM_INT
        $stmt->bindValue(':role', $role);
        $stmt->bindValue(':limit', $perPage, PDO::PARAM_INT);
        $stmt->bindValue(':offset', $offset, PDO::PARAM_INT);
        $stmt->execute();
        return $stmt->fetchAll();
    }

    public function create(string $name, string $email, string $role = 'user'): int
    {
        $stmt = $this->pdo->prepare(
            'INSERT INTO users (name, email, role, created_at) VALUES (:name, :email, :role, NOW())'
        );
        $stmt->execute([
            ':name' => $name,
            ':email' => $email,
            ':role' => $role,
        ]);
        return (int)$this->pdo->lastInsertId();
    }

    public function update(int $id, array $data): bool
    {
        $sets = [];
        $params = [':id' => $id];
        foreach ($data as $key => $value) {
            $sets[] = "{$key} = :{$key}";
            $params[":{$key}"] = $value;
        }
        $sql = 'UPDATE users SET ' . implode(', ', $sets) . ' WHERE id = :id';
        return $this->pdo->prepare($sql)->execute($params);
    }

    public function delete(int $id): bool
    {
        $stmt = $this->pdo->prepare('DELETE FROM users WHERE id = :id');
        return $stmt->execute([':id' => $id]);
    }

    public function count(string $role = ''): int
    {
        $sql = 'SELECT COUNT(*) FROM users';
        $params = [];
        if ($role) {
            $sql .= ' WHERE role = :role';
            $params[':role'] = $role;
        }
        return (int)$this->pdo->prepare($sql)->execute($params)->fetchColumn();
    }
}
```

## FETCH模式详解

```php
<?php
$stmt = $pdo->prepare('SELECT id, name, email FROM users LIMIT 5');
$stmt->execute();

// FETCH_ASSOC — 关联数组
$row = $stmt->fetch(PDO::FETCH_ASSOC);
// ['id' => 1, 'name' => '张三', 'email' => 'z@test.com']

// FETCH_OBJ — 匿名对象
$row = $stmt->fetch(PDO::FETCH_OBJ);
// $row->id, $row->name

// FETCH_CLASS — 映射到类（最强大）
class User {
    public int $id;
    public string $name;
    public string $email;
    private string $password;

    // 构造函数在属性赋值之后调用
    public function __construct() {
        $this->id = (int)$this->id; // 类型转换
    }
}
$stmt->setFetchMode(PDO::FETCH_CLASS, User::class);
$users = $stmt->fetchAll();

// FETCH_COLUMN — 取单列的值
$emails = $pdo->query('SELECT email FROM users')->fetchAll(PDO::FETCH_COLUMN);
// ['z@test.com', 'l@test.com', ...]

// FETCH_KEY_PAIR — 键值对（第一列为key，第二列为value）
$nameMap = $pdo->query('SELECT id, name FROM users')->fetchAll(PDO::FETCH_KEY_PAIR);
// [1 => '张三', 2 => '李四']

// FETCH_GROUP — 按第一列分组
$grouped = $pdo->query('SELECT role, id, name FROM users')->fetchAll(PDO::FETCH_GROUP | PDO::FETCH_ASSOC);
// ['admin' => [['id'=>1,'name'=>'张三']], 'user' => [...]]
```

## 面试常见追问

**Q: 模拟预处理（EMULATE_PREPARES=true）有什么安全风险？**
A: 模拟预处理时，PHP在本地拼接SQL字符串再发送给MySQL。在特定字符集（如GBK）下，反斜杠可能被吞掉导致注入。原生预处理（`EMULATE_PREPARES=false`）让MySQL直接处理参数绑定，彻底避免此问题。PHP 8.1+中MySQL默认使用原生预处理。

**Q: 预处理语句能防止所有SQL注入吗？**
A: 不能。预处理只保护参数值，不保护表名、列名、ORDER BY等SQL结构部分。动态表名/列名需要白名单校验：
```php
$allowedSort = ['id', 'name', 'created_at'];
$sort = in_array($_GET['sort'], $allowedSort) ? $_GET['sort'] : 'id';
$sql = "SELECT * FROM users ORDER BY {$sort}"; // 安全，因为是白名单
```

**Q: PDO的lastInsertId()在高并发下可靠吗？**
A: 可靠。`lastInsertId()`返回的是**当前连接**最后插入的ID，不受其他连接的影响。每个PHP请求有独立的数据库连接，所以并发不会串。
