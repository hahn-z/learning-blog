# PHP文件安全与路径遍历防护

文件操作是PHP Web应用的高危区域。路径遍历可读取任意文件，文件上传漏洞可导致Webshell，文件包含漏洞可执行任意代码。

## 路径遍历攻击与防护

### 攻击原理

路径遍历利用`../`跳出预期目录：

```
/download.php?file=../../../../etc/passwd
/download.php?file=....//....//etc/passwd  (双写绕过)
/download.php?file=%2e%2e%2f%2e%2e%2fetc%2fpasswd  (URL编码)
```

### realpath + basename防护

```php
<?php
class SafeFileAccess {
    private string $baseDir;
    
    public function __construct(string $baseDir) {
        $this->baseDir = realpath($baseDir); // 解析为绝对路径，消除../
    }
    
    public function safeRead(string $userInput): ?string {
        // 1. 拼接完整路径
        $fullPath = $this->baseDir . '/' . $userInput;
        
        // 2. realpath解析真实路径（会解析符号链接和../）
        $realPath = realpath($fullPath);
        
        // 3. 验证真实路径是否在允许的目录内
        if ($realPath === false || !str_starts_with($realPath, $this->baseDir . '/')) {
            throw new SecurityException('非法文件路径');
        }
        
        // 4. 验证文件存在且可读
        if (!is_file($realPath) || !is_readable($realPath)) {
            return null;
        }
        
        return file_get_contents($realPath);
    }
    
    // 只获取文件名（去掉所有路径部分）
    public function safeDownload(string $userInput): void {
        $filename = basename($userInput); // 只取最后一段文件名
        $filepath = $this->baseDir . '/' . $filename;
        
        if (!file_exists($filepath)) {
            http_response_code(404);
            return;
        }
        
        // 设置安全的下载头
        header('Content-Type: application/octet-stream');
        header('Content-Disposition: attachment; filename="' . $filename . '"');
        readfile($filepath);
    }
}
```

## 文件上传安全

文件上传有三个维度需要验证：扩展名、MIME类型、文件内容。

```php
<?php
class SecureFileUpload {
    // 白名单扩展名
    private const ALLOWED_EXTENSIONS = ['jpg', 'jpeg', 'png', 'gif', 'webp'];
    
    // 白名单MIME类型
    private const ALLOWED_MIMES = [
        'image/jpeg', 'image/png', 'image/gif', 'image/webp'
    ];
    
    // 最大文件大小 5MB
    private const MAX_SIZE = 5 * 1024 * 1024;
    
    public function upload(array $file, string $saveDir): string {
        $this->validateUpload($file);
        $this->validateSize($file);
        $this->validateExtension($file);
        $this->validateMime($file);
        $this->validateImageContent($file);
        
        // 生成随机文件名（不使用原始文件名）
        $ext = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
        $newName = bin2hex(random_bytes(16)) . '.' . $ext;
        $savePath = rtrim($saveDir, '/') . '/' . $newName;
        
        // 移动到安全目录（不在web根目录下）
        if (!move_uploaded_file($file['tmp_name'], $savePath)) {
            throw new RuntimeException('文件保存失败');
        }
        
        return $newName;
    }
    
    // 使用finfo检测真实MIME（不信任客户端Content-Type）
    private function validateMime(array $file): void {
        $finfo = new finfo(FILEINFO_MIME_TYPE);
        $mimeType = $finfo->file($file['tmp_name']);
        
        if (!in_array($mimeType, self::ALLOWED_MIMES, true)) {
            throw new SecurityException("不允许的MIME类型: $mimeType");
        }
    }
    
    // 验证图片内容（防止图片马）
    private function validateImageContent(array $file): void {
        $imageInfo = @getimagesize($file['tmp_name']);
        if ($imageInfo === false) {
            throw new SecurityException('不是有效的图片文件');
        }
        
        // 二次渲染：解码后重新编码，去除隐藏payload
        $image = imagecreatefromstring(file_get_contents($file['tmp_name']));
        if ($image === false) {
            throw new SecurityException('图片解码失败');
        }
        imagedestroy($image);
    }
    
    private function validateExtension(array $file): void {
        $ext = strtolower(pathinfo($file['name'], PATHINFO_EXTENSION));
        if (!in_array($ext, self::ALLOWED_EXTENSIONS, true)) {
            throw new SecurityException("不允许的扩展名: $ext");
        }
    }
    
    private function validateSize(array $file): void {
        if ($file['size'] > self::MAX_SIZE) {
            throw new SecurityException('文件超过大小限制');
        }
    }
    
    private function validateUpload(array $file): void {
        if (!isset($file['error']) || $file['error'] !== UPLOAD_ERR_OK) {
            throw new SecurityException('上传错误: ' . ($file['error'] ?? 'unknown'));
        }
    }
}
```

## 文件包含漏洞

`include`/`require`如果参数可控，危害比文件读取更大——可以执行代码：

```php
<?php
// 危险！
$page = $_GET['page'];
include("/var/www/pages/" . $page . ".php");
// page=../../etc/passwd%00  (空字节截断，PHP<5.3.4)
// page=../../../../tmp/evil  (如果能上传evil.php到tmp)

// 安全方案：白名单
$allowedPages = ['home', 'about', 'contact', 'products'];
$page = $_GET['page'] ?? 'home';
if (!in_array($page, $allowedPages, true)) {
    $page = 'home';
}
include __DIR__ . "/pages/{$page}.php";

// 如果必须动态包含，固定目录+basename
$safeName = basename($page);
$path = __DIR__ . '/pages/' . $safeName . '.php';
if (file_exists($path)) {
    include $path;
}
```

## open_basedir配置

`open_basedir`在PHP层面限制文件访问范围：

```ini
; php.ini 配置
open_basedir = /var/www/html:/tmp:/var/www/uploads

; 每个虚拟主机单独限制（Nginx + PHP-FPM）
; php-fpm pool配置
php_admin_value[open_basedir] = /var/www/site-a:/tmp
```

## 面试常见追问

**Q: finfo检测MIME类型够安全吗？**
A: 不够。MIME基于文件头（magic bytes）判断，攻击者可以在合法图片头后附加PHP代码（图片马）。必须结合getimagesize验证和二次渲染。

**Q: 为什么上传文件不能用原始文件名？**
A: 1) 文件名可能含`../`路径遍历；2) 特殊字符可能导致系统命令注入；3) 同名文件覆盖。用`random_bytes`生成随机名是标准做法。

**Q: null byte截断现在还有效吗？**
A: PHP 5.3.4+已修复，`include("file.php%00")`不再截断。但老代码仍需注意，且其他语言可能仍有此问题。

**Q: 上传目录需要什么权限配置？**
A: 上传目录不应有执行权限。Nginx: `location /uploads/ { location ~ \.php$ { deny all; } }`。Apache: 在目录下放`.htaccess`禁止脚本执行。
